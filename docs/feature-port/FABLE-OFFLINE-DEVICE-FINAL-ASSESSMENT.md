# 7차 검수 결과와 최종 판정 범위

실제 Fable 5.1·xhigh 검수는 마지막3개 수정과 직접 회귀를 확인했고 차단 수준 결함은 없다고 판정했다. 완전 무결/실기기 안정성/정식 배포 승인이 아니다.

경고는 중요한 원인 하나를 우선한다. 설정 손상+GC실패에서는 재선택 안내, 설정 손상+실행 파일 부재에서는 엔진 오류가 먼저 나타나고 엔진 복구 후 다음 원인이 나타난다. 문구의 저장 공간 안내는 권한/디렉터리 오류까지 설명하지 못하며 일부 raw 오류/접두어는 남는다. 이번 내부판에서 경고 이력 UI나 전체 메시지 체계를 확대하지 않았다.

상태 조회 실패는 현재 메모리 상태를 유지한다. 첫 부팅에는 Offline 빌드 기본값으로 안전하게 기기 내 모드를 유지하는 것이며, 아직 읽지 못한 서버의 마지막 저장 선택까지 보존한다고 주장하지 않는다. 이후 명시적 조회/재시작에서 저장 선택을 읽는다.

refreshLocalAI 호출처 LocalAISettings.svelte는 configure try/catch/finally, import finally의 catch로 새 오류를 안내하고 working을 해제한다. 이전 UI 회귀와 코드 판독에 더해 APK28의 실제 상태 GET 무응답 시험에서 기존 채팅 접근과 기기 내 표시 유지, 응답 복원 후 모델 표시 복구를 확인했다. 이는 모델 상태 GET에 한정하며 스토리지 인증 전체에5초 제한이 있다고 주장하지 않는다.
