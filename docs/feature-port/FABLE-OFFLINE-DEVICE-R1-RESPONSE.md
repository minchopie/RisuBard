# 기기 내 AI 1차 공동 검수 대응

검수 원문은 `fable-offline-device-review-1.md`, 제출 소스와 실제 모델 응답은 `tmp/offline-native/fable-review-1-*` 및 `.json`에 보존했다. 모든 제안을 자동 적용하지 않고 소스·사용자 요구·실행 근거와 대조했다.

| 지적 | 대응·근거 |
|---|---|
| A1 상태 조회 실패가 전체 부팅 중단 | 수정. 오류를 상태에 남기고 DB 로드를 계속한다. 오프라인을 끄지는 않는다. APK23 실제 503 주입→재시작→기존 채팅 열기 통과. |
| A2 모델 없을 때 온라인 경로 사용 제안 | 적용하지 않음. Offline 설치 후 모델 선택이 필요하며 무단 온라인 대체 금지와 충돌한다. 실제 신규 설치 UI·SAF·카드 가져오기 사용 가능, 모델이 없는 생성은 선택 안내로 거부한다. |
| A3 서버 응답 제한 | 수정. JSON/messages/정수 검증, 서버 출력 상한, 우회 n_predict/max_completion_tokens 제거. 실제 소켓 시험으로 제한 확인. |
| A4 문맥 여유·템플릿 | 기존 P4가 프리셋 문맥/출력 예산을 사용함을 확인. 추가로 엔진의 실제 apply-template/tokenize 결과로 최종 출력 여유를 계산한다. 입력이 넘으면 명시적 오류, 텍스트 임의 삭제 없음. |
| A5 화면 닫기 시 임포트 취소 | 취소 동작 유지, 작업 중 안내를 추가. 보이지 않는 장기 백그라운드 임포트 기능을 새로 만들지 않는다. |
| A6 초기화 promise 예외 | 수정. 예외 처리로 Node 전체 종료를 막고 상태/작업 오류로 전파. 온라인으로 전환하지 않는다. |
| A7 고아 모델 누수 | 수정. 유효한 설정/ENOENT일 때만 이 서비스의 UUID 이름 미참조 모델을 정리. 설정 손상 때는 모델 보존. 중간 취소/손상 설정 회귀 추가. |
| A8 취소 오류 문구 | 한국어 안내로 수정. |
| A9 응답 중 설정 강제 변경 제안 | 적용하지 않음. 취소 시 relay 해제 후 설정 변경 가능. 진행 중인 다른 요청을 설정 저장이 임의 중단하지 않는다. 실제 APK23 취소→재요청 성공. 완전한 네이티브 hang/OS kill은 별도 미검증 경계. |
| A10 빈 HTTP 오류 본문 | 수정. JSON 파싱 실패에도 상태 코드가 있는 안내. |
| A11 실행 파일 오류 | 시작 전 실행 권한/존재 검사 및 명시적 안내. |
| A12 루프백 포트 선점 | 앱 private 디렉터리의 Unix 소켓으로 변경. 공유 TCP 포트 제거. 디렉터리0700 및 APK23 실제 네이티브 소켓/생성 확인. |
| A13 n_ctx 제한 분기 불능 추정 | 고정 llama.cpp의 n_ctx_slot()이 min(config, train)을 실제 반환함을 대조. 프로토타입에서도 TinyStories128 한도 확인. 기존 거부 검사 유지. |
| A14 과거 이미지 자동 제외 제안 | 적용하지 않음. 내용을 조용히 빠뜨리지 않고 이미지 미지원 안내를 유지한다. |
| A15 대용량 오류 업로드 | 미소비 오류 응답에는 Connection close 및 응답 후 요청 종료를 추가. pipeline이 이미 끊은 경우에는 기존 연결 종료 오류가 표시될 수 있다. 이전 선택 모델은 유지된다. |

미제시 코드로 분리된 B항목은 다음 근거를 2차에 제출했다.

- NodeStorage authFetch는 File/AbortSignal을 그대로 fetch에 전달하고 인증 거부에만 재인증한다. GGUF 토크나이저는 실제 로컬 API를 호출한다. native server는 실제 Node24.21.0으로 실행했다.
- Express JSON100mb, SSE 압축 제외, 서버 requestTimeout0. 기본100kb/5분 가설과 다르다.
- P4의 모델별 문맥·출력 예산 경로, 실제 도구 미지원 어댑터 분기, 실제 ELF LOAD 정렬 검사 코드를 제출했다.
- 정확한 engine flags/API/소유자 가드 연결은 x64 실제 APK로 확인했다. ARM64 실행·배터리/가속 성능·장시간 백그라운드는 미검증으로 유지한다.
- Google/DeepL·임베딩·TTS·검색·NAS/GitHub를 오프라인으로 바꿨다고 주장하지 않는다. 모델 샘플링 기본0.8은 별도 로컬 모델 설정이며 기존 온라인 DB 값은 그대로다.
- 유휴 120초 이후 실제 요청의 재로드·생성 성공, UI 취소 후 재생성, 설정 전환은 내부 에뮬레이터에서만 확인했다.

이 대응서는 전체 기능 이식·실기기·정식 배포 승인서가 아니다. 2차 검수 원문과 실제 최종 검사 결과를 함께 읽는다.
