# NAS 자동 동기화 사용 안내 (RisuBard, 2026-10-20 · 픽스처 검증 단계)

RisuBard가 설치된 내 기기들(태블릿·PC·휴대폰)이 같은 NAS(WebDAV) 폴더를 통해 대화·캐릭터·모듈·설정을 자동으로 맞춘다.
설정 → 시스템/백업 → **캐릭터·대화 옮기기** 화면 안의 **3. NAS 자동 동기화** 영역에서 켠다. 아직 실제 NAS·실기기 검증은 하지 않았다
(합성 자료·루프백 WebDAV 픽스처로만 확인). 기존 수동 전송(파일·NAS·GitHub·Wi-Fi·USB)은 그대로 쓸 수 있다.

## 처음 시작: 태블릿(권한 기기)부터

1. **2. 전송 방법 → NAS · WebDAV → 연결 설정**에 HTTPS 폴더 주소·계정·비밀번호를 저장한다 (기기 보안 저장소에만 저장).
2. **3. NAS 자동 동기화**에서 작업공간 이름을 정하고 역할을 **권한 기기**로 두고 켠다. 이 기기의 현재 자료가 작업공간의 기준이 된다.
3. 이후에는 저장이 끝나면 5초 뒤, 화면이 보이는 동안 30초마다, 앱으로 돌아올 때, 네트워크가 돌아올 때 자동으로
   스냅샷 → NAS 올림 → NAS 받음 → 적용 순서로 돈다. 보내기 직전에는 최대 10초 안에서 최신 확인을 한 번 더 한다.

## 다른 기기 합류(참여 기기)

1. 같은 NAS 연결 정보를 저장하고, 같은 작업공간 이름으로 역할 **참여 기기**로 켠다.
2. **동기화 키 요청 준비**를 누르고, 위 기기 목록(**내 기기 · 같은 Wi-Fi**의 등록된 기기) 또는 **USB**로 권한 기기에 보낸다.
   파일·NAS·GitHub·Quick Share로는 키 자료를 보낼 수 없다(의도적으로 거부).
3. 권한 기기가 요청을 받으면 그 기기용으로만 열리는 **동기화 키**를 만든다. Wi-Fi 등록 기기에서 온 요청이면 자동으로 되돌려 보내고,
   USB로 받은 요청은 권한 기기의 전송 화면에서 「동기화 키」를 **보낼 기기 선택** → USB로 보낸다.
4. 참여 기기가 키를 받으면 자동으로 설치된다. 이미 다른 키가 설치돼 있고 그 키로 올린 기록이 있으면 자동으로 바꾸지 않고
   **받은 키로 바꾸기** 확인을 기다린다(이전 키는 복구용으로 보관).
5. 처음 합류 때 설정이 겹치면(두 기기가 각자 쓰던 값) **기준 기기 값으로 맞추기**로 키를 보내준 기기의 값으로 맞출 수 있다.
   이 기기의 원래 값은 `nas-sync/recovery/bootstrap-…`에 봉인되어 보관된다.

## 오프라인·충돌·복구

- NAS가 안 되면 로컬 플레이는 그대로 이어진다. 보낼 변경은 기기 안 대기열에 남고 5초·15초·60초·최대 5분 간격으로 다시 시도한다.
- 같은 대화를 두 기기에서 따로 이어가면 덮어쓰지 않고 **가지(별도 대화)** 로 양쪽을 보존한다. 대화가 아닌 항목(설정·모듈·프리셋 등)이
  갈리면 현재 값을 유지한 채 **충돌** 목록에 양쪽 값(비밀값은 표시하지 않음)과 출처 기기를 보여 주고, 남길 쪽을 고르면 다음 주기에 반영된다.
- 삭제는 30일 논리 휴지통에 남는다(물리 삭제 없음). **복원**은 함께 지운 묶음을 그대로 되살린다. 열어 둔 대화를 다른 기기가 지웠으면
  대화 화면 위에 안내가 뜨고 **되살리기 / 삭제 적용**을 고를 수 있다(생성·가져오기·전송 중에는 버튼이 잠긴다).
- 저장이 중간에 끊긴 적용은 다음 시작 때 자동으로 마무리하거나(복구), 확인 후 보류한다. 적용 중에는 자동 저장이 잠깐 멈춘다.
- 앱 백업을 복원하거나 DB 스냅샷을 되돌리면 동기화가 이를 알아채고, 복원된 자료에 없는 항목을 삭제로 보지 않으며 다른 기기의
  최신 변경을 덮어쓰지 않는다(복원된 시점의 계보를 이어 간다).

## 보안·배치

- API 키·토큰 등 비밀값만 암호화돼 NAS에 올라가고(기기 금고 키로 봉인), 일반 플레이 자료는 개인 HTTPS WebDAV에 평문으로 올라간다.
- 기기 식별자·금고 키·기기 키는 Android `noBackupFilesDir`, Windows `%LOCALAPPDATA%\RisuBard\nas-sync\…`에 두어 어떤 백업에도
  들어가지 않는다. 키가 사라진 설치는 새 키를 만들지 않고 **키를 가진 다른 기기에서 다시 받을 때까지** 아무것도 올리지 않는다.
- 자동 동기화를 끄면 앞으로의 주기만 멈추고 자료·대기열은 그대로 남는다. 다시 켜면 이어서 동기화한다.

## 집 네트워크 / 바깥 네트워크 주소 (선택)

같은 NAS 폴더·계정을 집 안에서는 내부 주소로, 밖에서는 외부 주소로 쓰고 싶을 때 **연결 설정 → NAS**에 "집 네트워크용 내부 HTTPS 주소"를 추가로 적습니다. 비밀번호·암호화 키·동기화 작업공간은 하나뿐이며 주소만 바뀝니다. 두 주소 모두 유효한 인증서가 있는 HTTPS 이름이어야 합니다(우회 없음).

- **집 Wi-Fi 등록**: 집 Wi-Fi에 연결한 상태에서 **지금 연결된 Wi-Fi를 집으로 등록**을 누릅니다. 공유기의 2.4 GHz·5 GHz 이름이 다르면 각각 등록합니다(최대 16개). Android는 Wi-Fi 이름을 읽기 위해 **앱 사용 중 위치 권한**을 한 번 묻습니다(백그라운드 위치는 쓰지 않음). 권한을 거부하면 Wi-Fi 이름을 알 수 없어 항상 바깥 주소를 씁니다.
- **선택 규칙**: 등록된 Wi-Fi → 내부 주소. 다른 Wi-Fi, 이름을 알 수 없는 Wi-Fi, 모바일 데이터 → 외부 주소. 유선 PC(Windows)는 내부 주소가 응답하면 내부, 아니면 외부. VPN이 켜져 있어도 밑에 깔린 Wi-Fi 이름으로 판단합니다.
- **안정성**: 한 번의 올리기/받기/전송은 시작할 때 고른 주소를 끝까지 씁니다. 네트워크가 바뀌면 다음 번 동기화부터 새 주소를 씁니다. 상태 영역의 "NAS 경로" 줄에서 현재 선택과 이유를 볼 수 있습니다(Wi-Fi 이름은 설정 화면에만 표시).
- 내부 주소를 비워 두면 이전과 똑같이 주소 하나만 씁니다.
