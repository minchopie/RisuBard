# RisuBard v0.9.79

## [수정] NAS 동기화 — 합류 기기의 설정이 다른 기기 설정을 덮어쓰던 문제

- **공유 키를 받기 전 동기화에 합류한 기기(예: 새 폰)가 키를 받은 직후 자기 초기 설정(프롬프트 프리셋·API 연결·모델 프리셋·메모리·플러그인 저장소·정리함 등)을 다른 기기 설정의 "다음 판"으로 올려, 태블릿·PC의 설정이 그 값으로 바뀌던 문제**를 고쳤습니다. 이제 그 기기가 한 번도 적용하지 않은 설정 그룹은 별도 갈래로 올라가 「충돌」로 표시되고, 전송 화면의 「기준 기기 값으로 맞추기」로 어느 쪽을 쓸지 정합니다. 자동으로 덮어쓰지 않습니다.
- 이미 덮어쓰인 설정 그룹을 되돌리는 복구 경로를 추가했습니다(`/api/nas-sync/restore-revision`, 설정 그룹 전용). 지정한 과거 판의 내용을 현재 모든 판의 다음 판으로 다시 올려 모든 기기에 그대로 적용되며, 대화·캐릭터는 건드리지 않습니다. 확인(`confirmed`)·현재 판 목록 일치·이 기기 키로 열 수 있는지 검사를 모두 통과해야 실행됩니다.
- 키가 없어 플러그인 본문을 아직 받지 못한 기기에서 플러그인 사용 여부(활성화 그룹)만 먼저 적용하려다 저장 확인에 실패하던 문제를 고쳤습니다. 플러그인 본문이 도착할 때까지 활성화 그룹은 함께 기다립니다.
- 저장 파일 형식·NAS 통신 형식·Android 네이티브 코드는 유지됩니다.

0.9.78·0.9.77·0.9.76·0.9.75·0.9.74·0.9.73을 포함합니다.
