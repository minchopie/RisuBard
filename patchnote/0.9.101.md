# RisuBard 0.9.101 — 동기화 제목 조회 응답 개선

휴지통·충돌·개요의 제목과 복구 소유자를 찾을 때 같은 카드 이력을 반복해서 읽고 검증하던 작업을 줄입니다. 처음 읽는 자료의 기존 해시 검증은 읽기 전용 Node 작업 스레드에서 수행하고, 검증한 이름·대화 연결 정보는 판본 ID별로 재사용합니다.

동시에 들어온 조회는 진행 중인 읽기를 공유합니다. 요청 전송 실패나 작업 스레드 종료는 대기 요청에 정확히 반환하며, 다음 요청에서 재시도합니다. 이름 표시·삭제 작업 최근 3건·휴지통 복원·단일 저장·동기화 잠금과 복구 흐름은 유지합니다.

채팅·캐릭터·Wiki·저장 슬롯·설정·API·NAS 데이터 형식은 변경하지 않습니다. 서버 전체를 여러 프로세스로 바꾸는 기능은 아닙니다. 기존 대화 본문 비교 등 일부 동기 계산은 유지합니다.

기기 설치와 실제 여러 코어의 동시 사용은 별도 실기기 검사 대상입니다.
