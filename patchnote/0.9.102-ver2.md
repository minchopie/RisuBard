# 0.9.102-ver2

0.9.102-ver1(원작 v0.9.102 `450f46b772bf9a73d2ae916bf6cb52c3535745f2`)을 기준으로, 0.9.96-ver11의 Asset Maid 그림 기록 복구와 NAS 배포 다시 받기 기능을 옮겨 온 판이다.

- 캐릭터 카드를 업데이트할 때 Asset Maid의 그림 기록을 최종 그림에 맞게 갱신해 기존 참조를 유지한다. 이전 카드 업데이트로 Asset Maid에서 열리지 않던 캐릭터는 같은 카드를 다시 받아 복구할 수 있다.
- NAS 배포 목록에서 이미 적용했거나 건너뛴 항목, 이 기기에서 배포한 항목도 「다시 받기」로 다시 받을 수 있다.
- 앱 시작 시 NAS 배포를 확인하거나 설정 → 시스템 → 백업 화면을 열 때, 이 기기의 네트워크 보고(안드로이드 Wi-Fi 확인 또는 `/api/nas-sync/network`)가 3초를 넘기면 「The server has been updated or the network connection has been lost. Please refresh the page.」 창이 뜨던 문제를 고쳤다. 3초가 지나면 이전과 같은 방식으로 서버가 NAS 주소를 정해 계속 진행한다.
- NAS 동기화에서 리랭커 API 키와 리랭커 주소에 포함된 인증 정보를 비밀 봉투에 보관한다.

## 주의

- 런타임 지문은 ver1 및 0.9.96-ver9~ver11의 `33b30c76…`와 같을 것으로 본다(빌드 검사에서 확인). NAS 앱 코드 업데이트로 받는다.
- 세 기기(태블릿·폰·PC)를 모두 ver2로 올리기 전에는 위키 프롬프트 프리셋을 새로 만들거나 복제하지 마세요.
  .102에서 새로 만들거나 복제한 위키 프리셋을 .96 기기가 읽으면 옛 형식으로 낮춰진다. 기존 프리셋은 영향을 받지 않는다.
- ver2가 동기화한 리랭커 키 또는 주소의 비밀 참조를 .96 기기가 읽으면 리랭커 설정 적용이 보류된다. 0.9.96에는 리랭커 설정 자체가 없으며, .96 기기의 다른 설정은 각각의 동기화 기록으로 처리되므로 이 보류의 영향을 받지 않는다.
