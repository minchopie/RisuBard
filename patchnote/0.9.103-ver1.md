# RisuBard v0.9.103-ver1

0.9.102-ver2의 포크 기능을 원작 0.9.103에 옮기고 채팅 표시와 기기별 설정을 고쳤습니다.

## 원작 0.9.103에서 들어온 변경

- 환경설정 → 공통 설정 → 채팅 응답에 실험 옵션 두 개가 있습니다. 기본값은 둘 다 꺼짐입니다.
  - 「대화 뒤쪽 시스템 블록을 제자리에 유지」를 켜면 Claude·Gemini 방식의 후반 시스템 블록을 원래 위치에서 `System: `이 붙은 사용자 메시지로 보냅니다. OpenAI 호환 방식은 기존과 같습니다.
  - 「항상 활성화 로어를 채팅 기록 앞에 배치」를 켜면 프리셋의 로어북 블록이 채팅 기록 뒤에 있을 때, 위치를 따로 지정하지 않은 항상 활성화 로어를 페르소나 뒤로 옮겨 모델 요청 내용이 바뀝니다. 예전에 저장한 값이 켜짐이면 이 버전에서도 켜진 상태로 돌아옵니다.
- 사건 제목이 바뀐 턴을 재분석할 때 갱신된 인물 문서에서 정본 저장을 이어갑니다. 바드위키 창을 접었다 펼 수 있고, 편집기의 문서 정보와 도구 버튼 배치를 정리했습니다.
- 독자 게시판은 OOC 응답을 새 연재에서 제외합니다. 독자마다 작품별로 미판정 추측 최근 6개와 판정된 추측 최근 2개를 남깁니다.
- 모듈을 교체할 때 업데이트 전 사본을 새로 남기지 않으며, 같은 모듈의 옛 사본을 정리합니다. 앱이 켜진 중에 외부에서 그림 저장소에 추가한 그림도 요청하면 읽을 수 있습니다.
- 봇 메뉴가 열리면 사이드바 화살표는 메뉴 아래로 들어갑니다. 봇과 플러그인의 떠 있는 버튼과 패널은 채팅 영역의 가장자리를 따릅니다.
- 챗 목록과 프롬프트 토글의 접힘 상태를 쓰던 브라우저나 앱에서 기억합니다. 챗 목록 머리글에 현재 채팅 제목을 표시하고, 스킨 버튼과 미니멀 모드의 전체 이름 툴팁을 추가했습니다.

## 0.9.102-ver2 이후 포크에서 고친 내용

- 카드 업데이트 뒤에도 기존 채팅에서 쓰는 그림과 자유 생성 인물의 그림 참조를 유지합니다. 새 카드에 남은 빈 그림 칸과, 그림 참조를 병합할 때 대응하는 빈 칸을 유지합니다.
- 카드 버튼이나 스트리밍 종료로 메시지 상자를 교체할 때 이전 본문과 높이를 최대 3초 유지합니다. 번역 대기 표시나 편집 화면으로 넘어가면 이전 본문과 높이 고정을 해제합니다. 강한 스트리밍 최적화 모드의 원문은 서식이 준비될 때까지 표시합니다.
- 새 메시지가 추가되면 직전 마지막 메시지를 다시 표시하기 위해 카드 Lua의 `editDisplay`를 한 번 더 호출합니다. 채팅 변수를 쓰는 카드에서는 이 호출도 변수에 반영됩니다. 스트리밍이 끝나면 해당 답을 종료 상태로 다시 표시합니다. 문단이 늘어날 때 같은 앞부분과 대응이 명확한 뒤쪽 메뉴·미디어를 유지합니다.
- 카드 배경을 새로 계산하는 동안 직전 배경과 CSS를 유지하고, 화면 갱신 결과가 준비되면 배경을 다시 만듭니다. 카드 Lua의 `editDisplay`에서는 현재 스트리밍 중인 마지막 메시지를 `meta.streaming`으로 확인할 수 있습니다.
- 홈 화면의 렐름 표시 방식과 캐릭터별 스킨 선택을 기기마다 따로 기억합니다. 이전에 받은 값은 현재 기기의 값으로 쓰고, NAS에 이미 남은 값은 이력에 보관합니다. 구버전 기기에서 이후 올린 값도 이 버전에서는 적용하지 않습니다. 스킨 라이브러리는 계속 동기화됩니다.
- Android 뒤로 가기 훅 시험에서 사진 뷰어를 준비하는 순서를 고정했습니다.
- NAS 동기화의 「내 변경 묶기」에서 로컬 동기화 저장소에 이미 있는 에셋은 임시 복사를 생략합니다. 앱 시작 시 소유 프로세스가 종료된 작업 폴더와 1시간 이상 지난 옛 임시 폴더를 정리하고, 중단된 파일 확인을 유효한 체크포인트부터 이어갑니다. 오류의 단계와 코드를 진단 기록에 남깁니다.
- NAS 동기화가 「빠진 그림」으로 실패하면 해당 주기는 묶기에서 중단됩니다. 설정의 NAS 동기화 화면에는 확인 가능한 빠진 그림·인레이 파일 이름만 표시하며 항목 이름은 표시하지 않습니다. 해당 파일을 쓰는 모듈·캐릭터 등을 그림이 들어 있는 원본 파일에서 다시 가져오세요. 다음 동기화가 성공하면 목록이 사라집니다.
- 같은 배포 ID의 모듈이 이미 설치돼 있으면 NAS 콘텐츠 배포의 「다시 받기」가 모듈 가져오기를 생략합니다. 이 경우 그림이 들어 있는 모듈 파일을 직접 가져와야 할 수 있습니다.
- 일주일치 변경이 쌓인 경우 첫 동기화가 길어질 수 있습니다. 새 변경을 올리기 전에 NAS의 기존 블롭도 다시 확인합니다.

## 남은 확인

- 위키 프리셋 혼용과 지운 캐릭터의 플러그인 저장소 정리는 이번 수정 범위 밖입니다.
- 실제 Android 기기, 실사용 NAS, 설치본에서의 동작은 아직 확인하지 않았습니다.
