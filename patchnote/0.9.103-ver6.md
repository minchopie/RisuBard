# RisuBard v0.9.103-ver6

「캐싱 친화적 구조」를 켜고 바드위키 기억이 두 메시지로 들어갈 때, 두 메시지 앞에 똑같이 붙던 기억 사용 규칙 문단(약 1,376자)을 한 번만 보내도록 했습니다.

## 0.9.103-ver5 이후 포크에서 바꾼 내용

### 바드위키 기억 (캐싱 친화적 구조)

- 「항상 포함」 문서와 검색한 기억이 각각 한 메시지로 최신 사용자 메시지 앞에 들어갈 때, 두 번째 메시지 맨 앞의 같은 규칙 문단(`Narrative continuity:`로 시작)만 빼고 보냅니다. 첫 메시지의 규칙·응답 가이드·기억 본문과 두 번째 메시지의 기억 본문은 한 글자도 바꾸지 않고, 메시지 순서와 역할도 그대로입니다.
- 줄어든 만큼 토큰 계산도 함께 줄고, 프롬프트 미리보기에도 실제로 보낸 내용이 그대로 보입니다. 토큰 한도에 가까운 대화에서는 그만큼 지난 대화가 조금 더 남을 수 있습니다.
- 규칙 문단이 잘렸거나 문구가 다르거나, 기억 메시지가 하나뿐이거나, 규칙 뒤에 기억 본문이 없으면 아무것도 빼지 않습니다. 「캐싱 친화적 구조」를 끈 경우는 이전과 같습니다.

## 남은 확인

- 실제 모델의 응답 품질, 요금, 캐시 적중률 변화는 확인하지 않았습니다. 실제 태블릿 요청 한 건을 기기 밖에서 다시 돌려 규칙 한 벌(1,376자)만 빠지고 나머지는 그대로인 것만 확인했습니다.
- 실제 Android 기기, 설치본에서의 동작은 아직 확인하지 않았습니다.
