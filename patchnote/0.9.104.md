# RisuBard v0.9.104

NAS 동기화 지연·잠김 수정

- 새로 합류한 기기가 많은 변경을 한꺼번에 받을 때, 서로를 기다리는 변경을 한 번의 동기화에서 모두 받아들이도록 고칩니다. 이미 대기 중인 변경을 다시 확인할 때 같은 기록을 반복해서 다시 쓰지 않고, 대기 확인 사이에 앱 서버가 다른 요청에 응답할 수 있게 합니다. 스마트폰에서 동기화가 몇 시간 동안 CPU를 쓰며 화면이 멈추던 문제의 원인입니다.
- 받은 변경의 목록 검증에서 이미 검증된 기록의 해시를 변경마다 다시 계산하지 않도록 합니다. 새로 받는 변경은 지금과 같이 전부 검증합니다.
- 다른 기기에서 켠 플러그인을 받을 때 적용 결과 확인이 맞지 않아 앱이 잠기던 문제를 고칩니다.
- 업로드할 때 여러 변경이 함께 쓰는 파일은 한 번의 업로드 안에서 NAS 확인을 한 번만 하고, NAS 연결 설정도 한 번만 읽습니다. 버튼이 오래 비활성화되던 시간을 줄입니다.
- 동기화 화면을 열어 둔 동안 서버 응답이 늦으면 상태 확인 요청이 겹쳐 쌓이지 않게 합니다.

기존 대화·캐릭터·페르소나·Wiki·저장 슬롯·API 연결·설정·프리셋·모듈·플러그인을 보존하는 범위에서 최소한으로 수정합니다. 동기화 데이터 형식은 바뀌지 않습니다.
