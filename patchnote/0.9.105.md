# RisuBard v0.9.105

채팅 전송 준비 시간 단축

- Lua 스크립트가 쓰는 JSON 해독에서 문자열을 한 글자씩 읽고 이어 붙이던 부분을 다음 따옴표·역슬래시·제어문자까지 한 번에 건너뛰고 마지막에 한 번 합치도록 바꿉니다. 결과와 오류 문구는 그대로입니다. 긴 채팅을 읽는 카드·모듈 Lua가 빨라집니다.
- 로어북의 정규식 키를 매번 새로 만들지 않고 같은 키는 다시 씁니다. 키 맨 앞의 `(?!)|`와 맨 끝의 `|(?!)`처럼 절대 일치하지 않는 선택지는 검사할 때만 빼고 검사합니다. 어떤 로어가 켜지는지는 바뀌지 않으며 카드에 저장된 키 원문도 그대로입니다.

기존 대화·캐릭터·페르소나·Wiki·저장 슬롯·API 연결·설정·프리셋·모듈·플러그인을 보존하는 범위에서 최소한으로 수정합니다. 저장·동기화 데이터 형식은 바뀌지 않습니다.
