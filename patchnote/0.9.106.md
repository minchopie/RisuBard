# RisuBard v0.9.106

Android 응답 완료 알림, BardWiki 정리 단축

- Android 앱에서 설정 > 소리 및 알림 > 브라우저 알림을 켤 때 나던 `Notification is not defined` 오류를 고칩니다. Android 웹뷰에는 브라우저 알림 기능이 없어서, 앱이 이를 Android 알림으로 대신 처리합니다. 처음 켤 때 알림 권한을 묻고, 응답이 끝나면 Android 알림으로 알려 줍니다. 알림을 누르면 앱이 열립니다.
- 알림을 켠 상태에서 응답 생성 중에 앱을 벗어나면 "응답을 생성하고 있어요" 알림을 띄우고 응답이 끝날 때까지 앱을 깨워 둡니다. Android가 백그라운드 앱을 멈춰서 응답이 돌아온 뒤에야 알림이 오는 일을 막기 위한 것입니다. 앱으로 돌아오거나 응답이 끝나면 바로 내려갑니다. 브라우저와 PC 앱의 알림은 그대로입니다.
- BardWiki 정리 요청이 같은 모델·같은 형식으로 JSON 스키마 직접 지정을 거절당한 적이 있으면, 1시간 동안은 처음부터 프롬프트 스키마 방식으로 보냅니다. 거절당한 뒤 다시 보내던 요청과 같은 요청입니다. 응답 뒤 정리가 호출 한 번마다 0.6~0.9초 빨라지고 실패 요청이 줄어듭니다. 결과와 저장 내용은 바뀌지 않습니다.

기존 대화·캐릭터·페르소나·Wiki·저장 슬롯·API 연결·설정·프리셋·모듈·플러그인을 보존하는 범위에서 최소한으로 수정합니다. 저장·동기화 데이터 형식은 바뀌지 않습니다.
