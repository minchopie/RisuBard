# RisuBard v0.9.72

## [추가] NAS 자동 동기화

설정 → 시스템/백업 → 캐릭터·대화 옮기기 화면의 **3. NAS 자동 동기화**에서 켭니다. 저장된 NAS(WebDAV) 연결을 그대로 사용하며, 기기마다 역할(권한 기기 / 참여 기기)과 작업공간 이름을 정합니다.

- **자동 반영:** 저장이 끝나면 잠시 뒤 NAS로 올리고, 화면이 보일 때 주기적으로 다른 기기의 변경을 받아 적용합니다. 전송 중에는 기다리지 않고 바로 플레이할 수 있고, 보내기 직전에는 최대 10초만 최신 상태를 확인합니다.
- **같은 대화를 두 기기에서 이어 쓴 경우:** 덮어쓰거나 이어 붙이지 않고 별도 가지로 둘 다 보존합니다. 설정·프리셋처럼 대화가 아닌 항목이 충돌하면 현재 값을 유지한 채 목록에서 고릅니다.
- **삭제:** 30일 논리 휴지통에 남고 묶음째 복원할 수 있습니다. 열어 둔 대화를 다른 기기가 지웠으면 채팅 화면에서 되살리거나 삭제를 적용합니다.
- **동기화 키:** API 키 같은 자격정보만 암호화해 올립니다. 키는 등록된 Wi-Fi 기기나 USB 전송으로만 다른 기기에 전달되며, 파일·NAS·GitHub·공유 경로로는 나가지 않습니다. 기기 식별자와 키는 앱 백업에 들어가지 않습니다.
- **백업 복원 뒤:** 복원된 시점의 계보를 이어 가며, 복원 자료에 없는 항목을 삭제로 보지 않습니다.

자세한 사용법: `docs/feature-port/NAS-SYNC-USER-GUIDE.md`.
