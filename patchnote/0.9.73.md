# RisuBard v0.9.73

## [수정] Android 앱에서 백업 파일 저장

설정 → 시스템/백업의 **전체 백업 다운로드**와 서버 백업 다운로드가 Android 앱에서 아무 파일도 만들지 않던 문제를 고쳤습니다. 이제 저장 위치를 고르는 창이 열리고, 선택한 위치로 파일을 바로 저장합니다.

- 앱 안의 내부 서버 주소에서 오는 백업 다운로드만 처리하며, 다른 주소나 다른 경로는 이전과 같이 열지 않습니다.
- 저장 중 실패하면 만들다 만 파일을 지우고 실패 이유를 알려 줍니다. 기존 파일은 건드리지 않습니다.
- Windows·웹 브라우저 사용에는 변화가 없습니다.
