# RisuBard v0.9.75

## [수정] NAS 동기화 — 요청마다 새 연결을 열던 문제

- NAS(WebDAV)에 올리고 확인하는 각 단계(폴더 만들기, 올리기, 이름 바꾸기, 임시 파일 지우기)마다 서버 응답을 읽지 않고 끊어, 다음 요청이 매번 새 TCP·TLS 연결을 열었습니다. 큰 자료의 첫 동기화는 수천 번의 새 연결을 짧은 시간에 열게 됩니다.
- 이제 무시하는 응답을 끝까지 읽고 연결을 유지해 같은 연결을 다시 씁니다. 연결 15초·응답 없음 90초 제한, 올린 파일의 해시 검증, 충돌 처리, 임시 파일 정리는 그대로입니다.
- 캐릭터·대화 옮기기의 NAS 업로드도 같은 방식으로 연결을 유지합니다. GitHub 백업은 바뀌지 않았습니다.
- 실제 NAS에서 "서버에 15초 안에 연결하지 못했어요"가 나던 원인으로는 이 연결 반복이 확인되었고, NAS나 공유기가 그 연결을 제한했는지는 아직 확인 중입니다.

0.9.74(동기화 시간 제한 정리)와 0.9.73(Android 백업 저장)을 포함합니다.
