# RisuBard v0.9.76

## [보안] 봇의 Lua 스크립트가 브라우저 코드를 실행할 수 있던 문제

봇이나 모듈의 Lua 스크립트가 `simpleLLM`, `similarity` 같은 API에서 받은 값을 거슬러 올라가, 리스바드가 도는 브라우저에서 임의의 코드를 실행할 수 있었습니다. 악의적인 봇을 가져오기만 해도 저장된 데이터나 API 키가 노출될 수 있는 문제였습니다.

- 이제 Lua 스크립트는 API 결과를 일반 Lua 표로만 받습니다. 브라우저 쪽 객체에는 닿을 수 없습니다.
- 표준 Lua 문법으로 값을 읽고 쓰는 봇은 그대로 동작합니다.
- 제보와 수정: rsyumi 님 (PR #41)
