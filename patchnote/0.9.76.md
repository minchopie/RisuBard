# RisuBard v0.9.76

## [수정] NAS 동기화 적용이 "일부만 저장됨"으로 멈추던 문제

- 다른 기기의 변경을 적용해 저장하는 동안, 활성 프리셋(테마·봇 프리셋)이 이 기기의 화면 설정 값으로 다시 쓰여 서버 검증과 어긋나던 문제를 고쳤습니다. 적용 중에는 계획된 값이 그대로 저장되고, 테마 프리셋에 들어가던 기기별 화면 값(확대 배율·아이콘 크기·입력창/사이드바 크기 등)은 더 이상 동기화 대상이 아니며 기기마다 자기 값을 유지합니다.
- 동기화가 진행 중일 때 들어온 일반 저장은 실패 대신 잠시 기다렸다가 다시 보냅니다. 복구가 필요한 상태(적용 미완료)는 기다리지 않고 바로 알려 복구 절차로 넘어갑니다.
- 이전 판에서 "적용 결과 보류"로 남긴 기록은 그대로 보관되며, 설정 충돌은 목록에서 권한 기기 값으로 정리할 수 있습니다.

## [추가] 집 네트워크 / 바깥 네트워크 NAS 주소

- 연결 설정 → NAS에 **집 네트워크용 내부 HTTPS 주소**를 추가로 적고 **지금 연결된 Wi-Fi를 집으로 등록**하면, 등록한 Wi-Fi에서는 내부 주소, 그 밖에서는 기존 주소를 씁니다. 계정·비밀번호·암호화 키·동기화 작업공간은 하나입니다.
- Android는 Wi-Fi 이름을 읽기 위해 앱 사용 중 위치 권한을 한 번 묻습니다(백그라운드 위치 없음). 권한이 없거나 이름을 알 수 없으면 항상 바깥 주소를 씁니다. 유선 PC는 내부 주소가 응답하면 내부, 아니면 외부를 씁니다. VPN이 켜져 있어도 밑의 Wi-Fi 이름으로 판단합니다.
- 한 번의 올리기·받기·전송은 시작할 때 고른 주소를 끝까지 쓰고, 네트워크가 바뀌면 다음 번부터 반영합니다. 내부 주소를 비워 두면 이전과 똑같습니다.

0.9.75(연결 재사용)·0.9.74(시간 제한 정리)·0.9.73(Android 백업 저장)을 포함합니다.
