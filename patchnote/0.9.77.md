# RisuBard v0.9.77

## [개선] 공식 위키 프롬프트 프리셋 2026-10-21

위키 프롬프트 프리셋의 공식 기본 프리셋이 `공식 기본 프리셋 (2026-10-21)`로 바뀝니다.

- **추가된 내용:** 맨 앞에 `개요` 블록이 들어갑니다. 위키 작성 AI에게 이 세션이 성인 사이의 창작 롤플레이이며 등장인물은 모두 성인이라는 전제와, 웹소설 작가로서 이야기의 개연성과 몰입을 지키라는 원칙을 알려 줍니다. 나머지 블록과 켜고 끄는 선택은 이전 공식 프리셋과 같습니다.
- **이전 버전 보관:** 이전 공식 프리셋은 `공식 기본 프리셋 (2026-10-10)`이라는 이름으로 `과거 공식 프리셋` 폴더에 들어갑니다. 이전 버전으로 돌아가고 싶으면 그 프리셋을 고르면 됩니다.
- 공식 프리셋을 쓰던 채팅은 자동으로 새 버전을 쓰고, 직접 만든 프리셋은 바뀌지 않습니다.

## 바드위키 링크가 문서 ID로 적혀 연결되지 않던 문제

위키 작성 AI가 문서 제목 대신 내부 문서 ID로 링크를 적는 경우가 있었습니다. 예를 들어 `[[location.xxxx|검은 이끼 골짜기]]`처럼 적힌 링크는 해당 문서와 연결되지 않고 끊어진 링크로 남았습니다.

- 이제 실제 문서 ID로 적힌 링크도 그 문서로 연결됩니다. `|` 뒤의 표시 문구는 그대로 보입니다.
- 위키 편집기 미리보기, 끊어진 링크 개수, 연결된 문서 수, 아크 플롯 링크가 모두 같은 기준으로 연결을 판단합니다.
- 위키 작성 AI에게 링크 대상에는 문서 제목이나 별칭만 쓰고 문서 ID나 파일 경로는 쓰지 말라고 지시합니다.

## 위키 편집기 본문에서 바꾼 문서 제목이 저장 후 되돌아가던 문제

위키 편집기에서 본문 맨 위의 `## 제목` 줄만 고치고 저장하면, 위쪽 `이름` 칸의 옛 제목으로 덮여 원래 제목으로 돌아갔습니다.

- 이제 `이름` 칸은 그대로 두고 본문 제목 줄만 바꿔 저장하면 바뀐 제목이 문서 이름이 됩니다.
- `이름` 칸을 바꾼 경우에는 지금처럼 `이름` 칸이 우선합니다.

## 파이어폭스에서 채팅 본문의 가운데 클릭 자동 스크롤이 작동하지 않던 문제

파이어폭스에서 채팅 본문을 마우스 가운데 버튼으로 누르면 자동 스크롤 아이콘은 나타나지만, 마우스를 움직여도 채팅이 스크롤되지 않았습니다. 최신 메시지가 아래에 붙는 채팅 본문의 스크롤 방식을 파이어폭스가 자동 스크롤 대상으로 인식하지 못했기 때문입니다. 사이드바와 설정 창에서는 원래 정상이었습니다.

- 이제 파이어폭스에서도 채팅 본문을 가운데 클릭한 뒤 마우스를 위아래로 움직이면 그 방향으로 스크롤됩니다. 누른 자리에 위아래 화살표 표시가 나타납니다.
- 가운데 클릭 후 손을 떼면 다음 클릭이나 `Esc`까지 계속 스크롤하고, 누른 채 끌었다가 놓으면 바로 멈춥니다.
- 링크 위의 가운데 클릭, 본문 안 코드 블록처럼 따로 스크롤되는 영역은 브라우저 기본 동작을 그대로 씁니다. 크롬과 엣지는 바뀌지 않습니다.

## IP 주소로 접속했을 때 프롬프트 프리셋을 불러오지 못하던 문제

`http://192.168.0.10:6001`처럼 HTTPS가 아닌 IP 주소로 리스바드에 접속하면, 프롬프트 프리셋 파일(`.risup`)을 불러올 때 `window.crypto.subtle is undefined` 오류가 나며 실패했습니다. 브라우저가 HTTPS나 `localhost`가 아닌 주소에서는 프리셋 암호 해제에 쓰는 내장 암호화 기능을 막기 때문입니다. 도메인과 HTTPS로 접속하면 원래 정상이었습니다.

- 이제 브라우저가 내장 암호화 기능을 막는 주소에서도 리스바드가 같은 방식으로 직접 계산해 프리셋을 불러오고 내보냅니다. 같은 이유로 실패하던 암호화된 캐릭터 카드, 번역기 프리셋, 테마 프리셋 불러오기와 위키 블록 식별도 함께 고쳐졌습니다.
- 만들어지는 파일은 이전과 똑같아서 다른 환경에서 만든 프리셋과 그대로 주고받을 수 있습니다.
