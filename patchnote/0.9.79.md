# RisuBard v0.9.79

포켓리스 v1.16.0과 원본 RisuAI v2026.10.211에서 고친 문제 중 리스바드에도 있던 것과 새 기능을 옮겨 왔습니다.

## ⚠️ 업데이트 후 확인할 것

- **정규식 로어북이 처음으로 제대로 동작합니다.** 지금까지 `/패턴/플래그` 형식의 키는 사실상 매칭되지 않았습니다. "정규식 사용"을 켜 둔 기존 로어북이 갑자기 활성화되어 프롬프트 내용과 토큰 사용량이 달라질 수 있으니 확인하세요.
- **HypaV3에서 Voyage context-3 임베딩을 쓴다면** 업데이트 후 채팅마다 처음 한 번 요약 전체를 다시 임베딩합니다. 요약 분량만큼 API 비용이 들고 첫 요청이 늦어집니다. 다른 임베딩 모델은 영향이 없습니다.
- **채팅 메시지 안의 폼 제출이 막힙니다.** 페이지 이동이나 새로고침을 막기 위해서입니다. `<form method="dialog">` 닫기는 그대로 되고, `risu-form` 폼은 Lua로 전달됩니다.
- **V3 플러그인 권한을 한 번씩 다시 묻습니다.** 권한이 플러그인 이름 대신 코드에 묶였습니다.
- **`{{prefillsupported}}` 값이 실제 프리필 지원 여부를 따릅니다.** Claude 4.6 Opus와 4.6 Sonnet은 `0`을 돌려주므로, 이 값으로 분기하는 프리셋은 4.6에서 프리필 분기를 타지 않습니다.

## [새 기능] RisuAI 계정에서 가져오기 (시험 기능)

설정 → 시스템 → 백업 → 데이터 이전에 추가했습니다. risuai.xyz에서 "계정에 데이터 저장"을 켜 두었다면, RisuAI 로그인 창으로 로그인한 뒤 서버가 계정의 캐릭터, 채팅, 설정, 이미지를 직접 받아 옵니다. 포켓리스와 같은 방식으로 만들었지만 실제 RisuAI 계정으로는 아직 확인하지 못했습니다. 문제가 있으면 알려 주세요.

- 시작 전에 계정 내용과 예상 시간을 보여 주고 두 번 확인합니다. 지금 데이터를 계정 데이터로 통째로 바꾸며 되돌릴 수 없으니, 필요하면 먼저 전체 백업을 받아 두세요.
- 받는 동안에는 모든 기기에 진행 화면만 보이고 저장이 멈춥니다. RisuAI 서버 부담을 줄이려고 파일을 1초에 하나씩 받습니다.
- 서버가 다시 시작되거나 로그인이 만료돼도 같은 계정으로 다시 로그인하면 남은 것만 이어 받습니다. 교체 전에는 언제든 취소할 수 있고, 취소하면 지금 데이터가 그대로 남습니다.
- 채팅에 넣은 이미지(인레이)는 원본 RisuAI가 브라우저에만 저장하므로 가져오지 않습니다.

## [새 기능] 캐릭터 저장소 "사이드바 순서" 정렬

- 전체 캐릭터 보기에서 고르면 사이드바와 같은 순서로 폴더별 묶음을 보여 줍니다. 폴더 밖 캐릭터는 "미분류" 묶음으로 그 사이에 놓입니다.
- 묶음 머리줄에 폴더 색, 아이콘, 캐릭터 수가 나오고 스크롤해도 위에 고정됩니다.
- 카드를 폴더 묶음에 끌어 놓으면 그 폴더로 옮겨집니다. 빈 폴더도 묶음으로 보여 바로 끌어 놓을 수 있습니다.

## [새 기능] RisuRealm 제작자 차단

- 카드 팝업에서 제작자를 차단하면 그 제작자의 카드가 목록에서 빠지고 열거나 받을 수 없습니다.
- 차단 목록은 Realm 메뉴의 "차단한 제작자 관리"에서 보고 해제할 수 있습니다.

## [새 기능] Lua 폼 트리거와 보조 모델, 이미지 방향 선택

- 채팅 HTML의 `<form risu-form="이름">`을 제출하면 Lua `onFormSubmit(id, key, meta)`로 받습니다. 버튼 `risu-btn`과 같은 방식이며 결과는 시작한 채팅에 기록됩니다.
- Lua `axLLM`에 `{mode = 'emotion'|'memory'|'otherAx'|'submodel'|'translate'}`로 보조 모델을 고를 수 있습니다. 기본값은 `otherAx`입니다.
- Lua `generateImage`에 `{orientation = 'landscape'|'portrait'}`로 NovelAI 이미지의 가로세로 방향을 정할 수 있습니다.

## [새 기능] 팝업 코드 편집기 Lua 자동완성

- 트리거 Lua를 팝업 편집기에서 고칠 때 Lua 자동완성이 나옵니다.

## [새 기능] 페르소나 메모 칸 항상 표시

- 실험 기능을 켜지 않아도 페르소나 메모 칸이 보입니다. 구분용이라 프롬프트에는 들어가지 않습니다.

## [새 기능] 내장 모델 목록 갱신

- Claude Fable 5.1, Haiku 5.5, Opus 5.5, Sonnet 5.5를 추가하고 Opus 4.5 thinking 설정을 바로잡았습니다.

## [안정성] 재시작이나 백업 가져오기 직후 저장한 채팅 내용이 사라지던 문제

- 서버를 재시작하거나 백업을 가져온 직후에 저장한 채팅 내용이 첫 동기화 때 버려질 수 있었습니다. 재시작 직후 새로 만든 채팅은 내용이 통째로 비었습니다.
- 이제 디스크에 아직 쓰이지 않은 채팅 내용을 유지한 채 동기화합니다.

## [안정성] 다른 채팅으로 옮긴 사이 끝난 버튼 트리거 결과가 사라지던 문제

- 버튼 트리거를 기다리는 동안 다른 채팅으로 옮기면, 원래 채팅에 쓴 결과가 저장 대상에 오르지 않아 새로고침하면 사라졌습니다. 이제 결과를 쓴 채팅도 바로 저장합니다.

## [안정성] 빈 캐릭터 폴더가 새로고침하면 사라지던 문제

- 캐릭터를 넣기 전의 빈 폴더가 다음 접속 때 없어졌습니다. 이제 빈 폴더도 남습니다.

## [안정성] 손상된 저장 데이터나 중단된 가져오기로 서버가 꺼지던 문제

- 저장 데이터에 손상된 압축 블록이 있어도 서버가 꺼지지 않고 그 블록만 건너뛰며 경고를 남깁니다.
- 저장 폴더 가져오기나 서버 백업 복원이 중간에 끊겨도 서버가 꺼지지 않습니다.
- 백업 가져오기가 이미지 폴더 교체 단계에서 실패해도 이전 데이터가 가져온 데이터를 덮어쓰지 않습니다.

## [안정성] 원본 RisuAI 최신 백업의 플러그인 저장 데이터가 보이지 않던 문제

- 원본 RisuAI v2026.10.210 이후의 백업을 가져오면 새 저장 구조에 든 플러그인 저장 데이터가 보이지 않았습니다. 이제 가져올 때 복원하고, 복원하지 못한 항목이 있으면 가져오기 결과에 경고로 알려 줍니다.
- 원본 RisuAI의 새 저장 블록(SaveKV)을 조용히 버리지 않고 로그에 남깁니다.

## [보안] 조작된 백업 파일이 임시 폴더 밖에 파일을 쓸 수 있던 문제

- 백업 항목 이름에 `\`나 `..`를 넣어 이미지 임시 폴더 밖에 파일을 쓸 수 있었습니다. 이제 이런 항목은 거부합니다.

## [보안] V3 플러그인 격리 강화

- V3 플러그인 iframe이 다른 곳에서 보낸 위조 메시지를 받아들이지 않습니다.
- V3 플러그인이 `setDatabaseLite`로 확인 없이 플러그인 목록을 바꿀 수 없습니다.

## [보안] V3 플러그인 권한을 플러그인 코드에 묶음

- 허용한 권한이 플러그인 이름에 묶여 있어, 코드가 바뀌거나 같은 이름으로 다른 플러그인을 설치해도 권한이 그대로 넘어갔습니다. 이제 코드가 바뀌면 다시 묻습니다.

## [버그 수정] 정규식 로어북과 로어북 활성 표시

- 정규식 로어북 키(`/패턴/플래그`, `/패턴/`)가 매칭되지 않던 문제를 고쳤습니다.
- 한 로어북 항목의 "매칭 후 계속 활성화"와 "매칭 후 비활성화" 표시가 뒤 항목에도 잘못 기록되던 문제를 고쳤습니다. 이미 잘못 기록된 채팅에서는 해당 항목의 고정 상태가 남을 수 있습니다.

## [버그 수정] 번역기 언어가 "비활성화됨"인데 번역이 계속 돌던 문제

- 예전에 켜 둔 자동 번역이 남아 있으면, 번역기 언어를 끈 뒤에도 채팅을 열거나 입력할 때마다 `Failed to fetch` 오류가 날 수 있었습니다.
- 이제 "비활성화됨"이면 채팅, 추천 답변, 입력을 번역하지 않고 입력 번역 칸도 숨깁니다.

## [버그 수정] 메시지 안의 폼 제출로 페이지가 이동하던 문제

- 메시지 안의 `<form>`을 제출하면 페이지가 이동하거나 새로고침되었습니다. 이제 제출을 막습니다.

## [버그 수정] 메시지 편집과 입력 중 화면 문제

- 긴 메시지를 편집할 때 편집창 크기가 바뀌면서 화면이 위아래로 튀던 문제를 고쳤습니다.
- 모바일에서 입력창에 포커스가 남은 채 키보드를 닫으면 입력창이 브라우저 툴바 밑에 갇히던 문제를 고쳤습니다.
- 팝업 편집기처럼 직접 글을 쓰는 영역에서 단축키가 입력을 가로채던 문제를 고쳤습니다.
- 모바일에서 버튼을 탭할 때마다 오류 창이 뜰 수 있던 문제를 고쳤습니다.

## [버그 수정] Gemini 도구 호출과 동적 모델 목록

- Gemini 도구 호출 응답을 Gemini가 받지 않는 역할(`function`)로 보내던 문제를 고쳤습니다.
- 목록에서 불러온 동적 Gemini 모델이 404로 실패하던 문제를 고쳤습니다.

## [버그 수정] 적응형 사고만 지원하는 Claude 모델의 예산 모드 오류

- 적응형 사고만 지원하는 Claude 커스텀 모델에서 "예산" 모드를 고르면 오류가 났습니다. 이제 적응형 사고로 보내고 설정 화면도 적응형 옵션을 보여 줍니다.

## [버그 수정] `{{prefillsupported}}` 판정

- Anthropic 모델에서 모델 이름 대신 모델의 실제 프리필 지원 여부를 돌려줍니다.

## [버그 수정] HypaV3 컨텍스트 임베딩이 같은 문장끼리 벡터를 같이 쓰던 문제

- Voyage context-3 임베딩에서 같은 문장이 여러 위치에 있으면 벡터 하나를 같이 썼습니다. 이제 위치마다 따로 임베딩합니다.

## [버그 수정] 팝업 코드 편집기가 언어 기능을 불러오지 못하던 문제

- 빌드판에서 팝업 편집기의 언어 기능(워커)이 시작되지 않았습니다. 이제 워커를 별도 파일로 불러옵니다.

## [버그 수정] 세션 유지 "소리 사용"이 Chrome에서 동작하지 않던 문제

- 이제 들리지 않을 만큼 낮은 음을 반복 재생해 Chrome에서 실제로 탭을 활성 상태로 유지합니다. Android에서는 미디어 알림("RisuBard")이 뜨고 다른 음악 앱이 일시정지될 수 있습니다.

## [버그 수정] 캐릭터 카드 가져오기와 내보내기

- 에셋 이미지를 읽을 수 없는 캐릭터도 빈 이미지로 대신해 카드를 내보낼 수 있습니다.
- 카드의 온보딩 데이터를 가져오기와 V3 내보내기에서 보존합니다. 리스바드에는 온보딩 화면이 없지만, 내보낸 카드를 원본 RisuAI에서 열면 온보딩이 그대로 남습니다.

## [버그 수정] 플러그인 API

- 플러그인이 `setDatabase`에 플러그인 목록을 넘겨도 설치된 플러그인이 사라지지 않습니다.
- 플러그인 저장소에 저장한 `0`, `false`, 빈 문자열이 `null`로 바뀌지 않고 그대로 돌아옵니다.
- V3 `safeLocalStorage`의 `key()`, `length`, `keys()`가 오류 없이 동작합니다.
- V3 `getRootDocument()`에 등록한 스크롤 리스너가 화면 전체 스크롤에도 반응하고, 리스너 제거가 등록 옵션과 상관없이 확실히 동작합니다.

## [버그 수정] 오류 표시

- 채팅 메시지 파싱 오류를 스택과 함께 오류 창에 보여 줍니다.
- 너무 큰 요청에 일반 오류(500) 대신 "용량 초과"(413)로 응답합니다.

## [성능] 캐릭터가 많을 때 캐릭터 조회

- 캐릭터 하나를 조회하면서 데이터베이스 전체를 복사하던 비용을 줄였습니다. 캐릭터가 수천 개여도 저장 직전 스냅샷이 가벼워집니다.
