# RisuBard v0.9.80

## [추가] NAS 주소를 IP로 직접 적기

- **NAS 연결 설정에 「인증서 이름」(선택) 항목을 추가했습니다.** 바깥 주소·집 네트워크용 내부 주소를 도메인 이름 대신 IP 주소로 적을 수 있고, 그때 인증서 이름에 NAS 인증서의 호스트명을 적으면 연결은 IP로 가되 TLS 인증서 검증·SNI·Host는 그 이름으로 이루어집니다. 인증서 검증을 끄거나 완화하는 옵션은 없습니다.
- 인증서 이름은 NAS를 쓰는 모든 경로(자동 동기화의 올리기·받기·자료 다운로드, 수동 전송의 목록·올리기·내려받기, 유선 PC의 내부 주소 확인)에 같이 적용되며, 한 번의 작업 동안 주소와 이름이 함께 고정됩니다. 작업 중에 설정을 바꿔도 진행 중인 작업에는 섞이지 않습니다.
- 기존처럼 도메인 이름으로 적은 설정은 바뀐 것이 없고, 인증서 이름을 비워 두면 이전과 똑같이 동작합니다.
- 저장 파일 형식·NAS 통신 형식·Android 네이티브 코드는 유지됩니다.
