# RisuBard v0.9.84

이번 개인 포크 배포는 기존 0.9.83의 기능을 포함하며 NAS 동기화의 표시와 충돌 처리를 개선합니다. 원작 버전과 별도 계보입니다.

## 동기화 변경

- 자동 동기화를 먼저 보여 주고 파일·USB·Wi-Fi 등 수동 전송은 접을 수 있게 정리했습니다. 자료는 ID 대신 캐릭터·대화·페르소나 이름으로 표시합니다.
- 페르소나는 항목별로 변경 이력을 비교합니다. 다른 기기에서 추가한 별개 항목을 함께 보존하고 이 기기의 선택과 목록 순서를 유지합니다. 같은 항목을 양쪽에서 다르게 수정한 경우에만 선택을 요청합니다.
- userNote를 별개의 동기화 항목으로 적용하지 않습니다. 과거 이력은 삭제하지 않고 선택한 페르소나에서 입력 필드를 구성합니다. 기존 입력 필드와 페르소나 원본이 다르면 이름과 저장 안내를 표시합니다.
- 메시지 본문은 같은데 Wiki·슬롯·연결 자료가 다른 경우 불필요한 대화 복제를 만들지 않고 확인을 기다립니다. 실제 메시지가 갈라졌을 때에는 각 대화를 보존합니다.
- 마지막 동기화에 기록된 Wiki·저장 슬롯·참조 페이지 수와 업로드/수신 상태를 표시합니다. NAS 업로드와 상대 기기 적용 완료는 구분하며, 상대 기기의 완료를 확인한 것으로 표시하지 않습니다.
- 자동 동기화는 기존처럼 백그라운드에서 진행하고 플레이 화면을 강제로 전환하지 않습니다.

## 기존 데이터와 업데이트

**PC·태블릿·스마트폰을 모두 이번 버전으로 업데이트해 주세요.** 구버전과 섞어 쓰면 구버전이 페르소나 선택을 바꿀 수 있습니다. 별도의 Offline판이나 RisuAI USB를 이 APK로 바꾸는 배포가 아닙니다.

- Android: 일반 RisuBard 위에 APK를 업데이트 설치합니다. 패키지 ID `app.risubard.personal`과 기존 정식 서명을 유지합니다. 앱 삭제·데이터 초기화를 하지 않으면 기존 저장 영역의 API 설정·NAS 설정·대화·페르소나를 유지합니다.
- Windows: 실행 중인 RisuBard를 종료하고 기존 폴더를 먼저 백업합니다. 기존 `save` 폴더와 숨김 설정/키 파일은 보존한 채 앱 파일을 업데이트합니다. ZIP에는 사용자 데이터 폴더가 포함되지 않습니다. 새 폴더에 풀어 처음 실행하면 별도 빈 프로필이므로 기존 데이터가 자동 이전되는 것은 아닙니다.
- Windows의 NAS 동기화 연결은 같은 설치 폴더 경로·같은 Windows 계정에서 업데이트해야 이어집니다. 동기화 기기 정보와 키는 설치 폴더 밖 `%LOCALAPPDATA%\RisuBard\nas-sync`에 있으므로 설치 폴더 백업에 포함되지 않습니다. 경로 변경·다른 PC로 이전은 별도 재연결이 필요할 수 있습니다. 백업은 `server`·`dist` 등 교체되는 앱 파일 폴더 안이 아닌 별도 위치에 보관합니다.
- Windows의 앱 내 업데이트/`update.bat`는 기존 데이터 루트를 보존하는 경로를 사용합니다. 다른 PC로 복사한 암호화 자격정보까지 자동 복원되는 것은 보장하지 않습니다.
- 이 업데이트는 기존 데이터나 NAS 자료를 일괄 초기화·삭제하지 않습니다. 업데이트 전 앱 백업 기능으로 별도 백업을 남기는 것을 권장합니다.

## 검수 범위

Codex가 코드를 작성하고 실제 구독 Claude Code Opus 5.5 HIGH와 설계·반복 리뷰·시험 결과 대조를 진행했습니다. 로컬 관련 서버 47개, 클라이언트/마운트 화면 46개 통과. 원작 v0.9.76에 모듈을 격리 재적용한 검사에서 서버 181개 통과/1개 생략, 클라이언트 69개 통과, 타입 오류 0/기존 경고 8개 및 프로덕션 빌드 통과했습니다. 검사 집합은 서로 겹칩니다.

배포 파일의 추가 빌드·서명·해시·격리 서버 검사 결과는 첨부 검수 기록을 기준으로 합니다. 이번 버전의 실제 기기 설치, 실 NAS 자료의 양방향 동기화, 장기 플레이와 실제 생성 경합은 아직 검사하지 않았습니다. 마지막 Wiki 기록 표시는 현재 디렉터리의 실시간 동일성 검사나 다른 기기의 수신 확인 조회가 아닙니다.
