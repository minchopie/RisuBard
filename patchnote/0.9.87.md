# RisuBard v0.9.87

- NAS 다운로드에서 서버의 위키·저장 슬롯 적용 계획이 10초를 넘으면 계속 대기하던 문제를 수정했습니다. 화면과 저장을 잠그지 않는 서버 계산 뒤부터 클라이언트 적용 준비의 10초 제한을 적용합니다.
- 본문은 같고 위키 처리 기록만 다른 메시지를 다른 이야기로 판단해 대화를 복제하던 문제를 수정했습니다. 위키 처리 기록 자체는 그대로 보존하고, 차이는 상태 차이로 표시해 확인할 수 있게 합니다.
- 이미 생긴 대화 사본과 서로 다른 위키 기록은 자동 삭제하거나 덮어쓰지 않습니다. 기존 API·대화·페르소나·프리셋·모듈·기기 키와 자동 동기화 주기를 유지합니다.
