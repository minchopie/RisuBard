# RisuBard v0.9.90

- Windows 로그 파일·체크섬·백업 교체 중 잠깐의 공유 잠금 오류를 재시도합니다. 실행 중인 로그 작성자의 잠금을 시간 경과만으로 가져오지 않습니다.
- 일반 Android·Windows 포터블에서 앱 서버 시작 시 기존 NAS 연결로 새 앱 코드 패치를 확인합니다. 다운로드와 검증을 마치면 대화·설정을 열기 전에 적용합니다.
- NAS를 사용할 수 없거나 패치가 손상됐으면 기존 앱으로 실행합니다. 새 코드의 기동이 확인되지 않은 경우 다음 시작에서 이전 코드로 복구합니다.
- 기존 대화·캐릭터·페르소나·API·NAS 설정과 백업은 앱 코드 패치에 포함하거나 교체하지 않습니다.
- 앱 코드 패치는 별도 `app-update` 모듈입니다. 네이티브 앱·Node·의존성·패치 로더가 바뀌는 경우에는 기존 APK/PC 전체 업데이트가 필요합니다. 이번 APK/PC 버전을 한 번 설치한 뒤 호환 코드 패치를 자동으로 받을 수 있습니다.
