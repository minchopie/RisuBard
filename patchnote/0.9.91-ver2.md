# RisuBard v0.9.91-ver2

0.9.91-ver1에 한 가지를 더한 판입니다. 나머지는 0.9.91-ver1과 같습니다.

## [추가] 기기별 앱 비밀번호 끄기
- 데이터 폴더(PC는 `%LOCALAPPDATA%\RisuBard\portable\save`)에 빈 파일 `__password_off`가 있으면, 앱을 열 때 비밀번호를 묻지 않습니다.
- 파일을 지우면 다시 비밀번호를 묻습니다. 비밀번호 자체(`__password`)는 지우거나 바꾸지 않습니다.
- 켜 둔 동안에는 이 앱 서버에 닿는 모든 기기(같은 네트워크의 다른 기기, 원격 접속 주소 포함)가 비밀번호 없이 들어옵니다.
- 파일이 없는 기기는 지금과 똑같이 동작합니다.
