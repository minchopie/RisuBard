# RisuBard v0.9.92-ver1

원작 RisuBard **v0.9.92**(`d704513d`) 위에 개인 모듈을 다시 얹은 판입니다. 원작 0.9.92의 수정은 원작 그대로 들어 있습니다.

0.9.91-ver1~ver3에서 더한 것이 모두 이어집니다.
- 0.9.91-ver1: 페르소나 옮기기 (`patchnote/0.9.91-ver1.md`)
- 0.9.91-ver2: 기기별 앱 비밀번호 끄기 (`patchnote/0.9.91-ver2.md`)
- 0.9.91-ver3: 채팅 이름에 기기 표시 — 새 채팅 `(pc) Chat 3` / `(tablet) Chat 3` / `(phone) Chat 3`, 기본 이름 채팅과 동기화 사본은 목록에만 기기 표시 (`patchnote/0.9.91-ver3.md`)

## 추가: 프롬프트 프리셋도 NAS 배포 알림으로
설정 > 시스템 > 백업 > 캐릭터·페르소나 배포 (NAS)에서 프롬프트 프리셋 파일(.risup·.risupreset·.preset.json)도 올릴 수 있습니다. 다른 기기는 캐릭터·페르소나처럼 「새 프롬프트 프리셋이 올라왔어요. 지금 가져올까요?」를 묻습니다.
- 같은 이름의 프리셋이 있으면 그 프리셋을 새 내용으로 바꿉니다(id 유지 → 채팅·봇 연결 유지). 내보낸 프리셋에 비어 있는 이 기기의 API 키·프록시 키·주소는 그대로 둡니다. 지금 쓰는 프리셋이면 새 내용으로 다시 불러옵니다.
- 이름이 다르면 새로 추가합니다(이름에 버전이 들어 있으면 새 판은 새 프리셋으로 추가됨).
- 0.9.92-ver1보다 오래된 앱은 프리셋 배포를 알아보지 못하고 건너뜁니다.

## 알려진 한계
- 원작 0.9.92의 새 설정(앱 스킨 목록·사용 중인 스킨, 보조 모델 기본 방식)은 NAS 동기화에서 이전 판처럼 각각 따로 동기화됩니다(이전 판 기기와 섞여 있어도 충돌하지 않게). 그래서 스킨 목록이 아직 안 넘어온 기기에서 사용 중인 스킨만 먼저 바뀌면, 목록이 넘어올 때까지 기본 모양으로 보일 수 있습니다.

0.9.91-ver3은 따로 배포하지 않고 이 판에 합쳤습니다.
