# 0.9.92-ver10

## [변경] 모델에 요청 중일 때는 NAS 자동 동기화를 멈춤

- 사용자: 「모델에 요청중일때는 동기화 정지하게 해줘.」
- 이전: 답변을 받는 동안 올리기 방향 주기만 미루고, 받기 방향 주기는 계속 돌았다(받기만 하고 적용은 미룸). 이미 돌던 주기도 끝까지 갔다.
- 이제(`nasSyncCoordinator.ts`, transfer-sync):
  - 요청 중(기존 판정 `activityBlocksSync`: 보내는 중·답변 생성 중·가져오기 중·스트리밍·위키 재생성)에는 자동 주기가 시작되지 않는다(올리기·받기 모두).
  - 이미 돌던 주기는 단계 사이(네트워크 보고·상태·정리·묶기·올리기·받기·확인 직후)에서 멈춘다. 이미 보낸 요청은 응답까지 받고 다음 단계만 시작하지 않는다. 서버에서 시작된 올리기·받기는 서버에서 끝나고 받은 내용은 보관된다.
  - 걸린 적용(무장된 적용)은 끊지 않는다. 걸기 전의 적용 준비는 기존 재확인이 계획을 풀고 미룬다.
  - 요청이 끝나면(`isAnyGenerating`이 꺼지면) 저장 뒤와 같은 5초 뒤에 다시 동기화한다. 적용 준비 중에 요청이 시작돼 적용이 물러난 경우도 같다. 그 밖의 이유(가져오기·스트리밍 잔여)로 미뤄진 경우는 기존 30초 간격 확인이 다시 시작한다.
  - 설정의 수동 버튼은 이전과 같다(요청 중 올리기는 미룸, 받기는 받기만).
- 기존 장치만 썼다: 결과값 `deferred`, `schedule`, 단계 사이 검사 `boundary()`. 시험 +3, 기존 시험 1개(「생성 중에도 올리기·받기가 돈다」)는 새 동작으로 교체.
