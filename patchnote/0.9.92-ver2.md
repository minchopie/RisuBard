# RisuBard v0.9.92-ver2

0.9.92-ver1(원작 RisuBard **v0.9.92** `d704513d` 위의 개인 모듈) 그대로에 아래 하나를 더한 판입니다.

## 추가: 앱 코드 업데이트를 쓰는 중에 받아 두고, 태블릿은 탭 없이 바로 적용
지금까지 NAS에 올린 앱 코드 업데이트는 앱을 켤 때만 확인했고, 2초 안에 못 받으면 그다음에 켤 때 적용됐습니다.
- 앱을 쓰는 동안 앱 서버가 NAS를 확인합니다(켜고 1분 30초 뒤, 그 뒤 30분마다). 새 코드가 있으면 뒤에서 받아 둡니다. 받아 둔 코드는 다음에 서버가 시작할 때 네트워크를 기다리지 않고 바로 적용됩니다.
- 받아 둔 새 버전이 있고 답장 생성·전송·가져오기·다른 창이 없을 때 「새 버전이 준비됐어요. 지금 적용할까요?」를 묻습니다. 버전마다 앱을 켤 때 한 번만 묻습니다.
  - **지금 적용**(Android 앱): 먼저 저장하고(앱이 백그라운드로 갈 때와 같은 저장), 앱 안의 서버를 다시 시작합니다. 서버가 새 코드를 적용하고 화면이 다시 연결됩니다. 다시 시도를 누를 필요가 없습니다.
  - **나중에**: 다음에 앱을 켤 때 적용됩니다.
- PC 앱은 「새 버전을 받아 뒀어요. 다시 켜면 적용돼요」만 알립니다.
- 앱 코드가 아닌 부분(안드로이드 네이티브·런타임)이 바뀐 판은 지금처럼 전체 APK·PC 패키지가 필요합니다.

## 한 번은 전체 설치가 필요합니다
이 판은 Android 네이티브 코드(서버 다시 시작)를 바꿉니다. 그래서 태블릿·폰은 이 APK를, PC는 이 PC 패키지를 **한 번** 설치해야 합니다. 그다음 NAS 앱 코드 업데이트부터 위처럼 동작합니다.
- 0.9.92-ver1 이하 앱은 NAS의 0.9.92-ver2 코드를 「전체 패키지 필요」로 보고 받지 않습니다.
