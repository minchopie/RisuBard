# 0.9.92-ver5

## [변경] 앱을 열면 메인 화면에서 바로 NAS 새 배포를 묻기

- 사용자 요청: 「앱열고 로딩끝나서 메인화면 나올때 바로 물어보고 다운받을수있게 하면 안돼?」
- 이전: 메인 화면이 뜨고 8초 뒤 한 번만 확인했다. 그 순간 앱이 바쁘면(시작 때 NAS 동기화, 다른 알림창, 생성 중, 가져오기 진행) 건너뛰고, 다음 확인은 앱을 나갔다가 돌아올 때였다.
- 지금: 메인 화면이 뜨고 1.5초 뒤 확인한다. 바쁘면 3초마다 다시 시도해, 한가해지는 순간 「새 ○○가 올라왔어요. 지금 가져올까요?」를 묻는다(시작 뒤 3분까지). 「네」를 누르면 바로 받아 적용하는 것은 그대로다.
- 그대로인 것: 묻는 문구·순서, 한 번 답한 판은 다시 묻지 않음, 앱으로 돌아올 때 확인(10분 간격), 설정의 확인 버튼.
- 모듈: `content-updates`(`src/ts/content-updates/contentUpdates.ts`, 시험, `docs/content-updates/README.md`).
