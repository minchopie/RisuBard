# 0.9.92-ver7

## [추가] NAS 동기화 진행률 표시

- 사용자: 「nas동기화가 얼마나 진행되었는지 표시되게 하고 싶어. 지금 얼마나 진행되었는지 표시가 안되서 답답해.」 → 선택: 퍼센트 막대(단계+개수+용량), 설정과 메인 화면 모두, 동기화 중에만. 「기존의 함수를 최대한 재활용해서 최소한의 변경으로」.
- 표시: 「NAS 동기화 · NAS에서 받는 중 ▮▮▮▯▯ 42% · 파일 12/40 · 48/115 MB · 1분 20초」. 단계는 상태 확인 → 내 변경을 묶는 중 → NAS에 올리는 중 → NAS에서 받는 중 → 받은 변경 확인 중 → 받은 변경 적용 중. 올리기·받기에서만 퍼센트(용량 기준, 크기 기록이 없는 파일이 끼면 개수 기준)가 나오고, 다른 단계는 움직이는 막대와 경과 시간.
- 위치: 설정 > NAS 자동 동기화 화면, 그리고 메인 화면 아래쪽 상태 줄(기존 「동기화 변경을 저장하는 중」 줄과 같은 모양, 화면을 가리지 않음). 동기화가 돌 때만 보이고, 무장된 적용 중에는 기존 줄이 대신 보인다.
- 서버(`nas-sync-remote.cjs`): 올리기는 올릴 파일 수·용량을 먼저 세고(이미 올린 것으로 기록됐지만 NAS 사본이 없거나 손상돼 다시 올리는 파일은 발견될 때 더함), 받기는 NAS 목록 묶음(256개 단위)마다 새 커밋 기록을 미리 한 번 읽어 받을 파일 수·용량을 더한 뒤, 그 기록으로 이전과 똑같이 하나씩 받고·받아들인다(읽기 실패 지점과 받아들이는 순서는 이전과 같음). 대기 중 커밋 재다운로드·복구 다운로드도 시작할 때 더한다. 파일 내용 흐름에 바이트 수만 센다. 받기에 실패한 파일(404)은 완료로 세지 않는다. `GET /api/nas-sync/progress`(동기화 실행 순서를 기다리지 않음). 진행 정보는 표시용이고 아무 동작도 이 값을 읽지 않는다.
- 클라이언트: 조정자가 현재 단계를 상태에 둔다. `NasSyncProgress.svelte`가 동기화 중에만 1초마다 진행을 읽는다(요청 5초 제한, 주기가 끝난 뒤 늦게 온 응답은 버림).
- 한계: 받기의 전체 용량은 묶음을 읽어 갈수록 늘어난다(여러 기기·묶음이면 처음엔 작게 보임). 재시도로 같은 바이트를 두 번 보내면 100%에서 멈춰 보일 수 있다. 받은 변경 적용 단계는 개수 없이 경과 시간만.
- 모듈: `transfer-sync`(`nas-sync-remote.cjs`, `nas-sync-service.cjs` 경로 1줄, `nasSync.ts`, `nasSyncCoordinator.ts`, 새 `NasSyncProgress.svelte`, `TransferPanel.svelte` 2줄, `App.svelte` 6줄(v0.9.92 호환 패치에도 같은 6줄), 시험).
