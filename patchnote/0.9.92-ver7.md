# 0.9.92-ver7

## [추가] NAS 동기화 진행률 표시

- 사용자: 「nas동기화가 얼마나 진행되었는지 표시되게 하고 싶어. 지금 얼마나 진행되었는지 표시가 안되서 답답해.」 → 선택: 퍼센트 막대(단계+개수+용량), 설정과 메인 화면 모두, 동기화 중에만. 「기존의 함수를 최대한 재활용해서 최소한의 변경으로」.
- 표시: 「NAS 동기화 · NAS에서 받는 중 ▮▮▮▯▯ 42% · 파일 12/40 · 48/115 MB · 1분 20초」. 단계는 상태 확인 → 내 변경을 묶는 중 → NAS에 올리는 중 → NAS 목록 확인 중 → NAS에서 받는 중 → 받은 변경 확인 중 → 받은 변경 적용 중. 올리기·받기에서만 퍼센트(용량 기준)가 나오고, 다른 단계는 움직이는 막대와 경과 시간.
- 위치: 설정 > NAS 자동 동기화 화면, 그리고 메인 화면 아래쪽 상태 줄(기존 「동기화 변경을 저장하는 중」 줄과 같은 모양, 화면을 가리지 않음). 동기화가 돌 때만 보이고, 무장된 적용 중에는 기존 줄이 대신 보인다.
- 서버(`nas-sync-remote.cjs`): 올리기는 올릴 파일 수·용량을 먼저 세고, 받기는 NAS 목록(작은 커밋 기록)을 먼저 다 읽은 뒤 받을 파일 수·용량을 세고 같은 순서로 받는다(이전: 기록 하나 읽고 바로 그 파일들 받기). 파일을 쓰고 읽는 흐름에 바이트 수만 센다. `GET /api/nas-sync/progress`(동기화 실행 순서를 기다리지 않음). 진행 정보는 표시용이고 아무 동작도 이 값을 읽지 않는다.
- 클라이언트: 조정자가 현재 단계를 상태에 둔다. `NasSyncProgress.svelte`가 동기화 중에만 1초마다 진행을 읽는다.
- 한계: 받기의 전체 용량은 목록을 다 읽은 뒤부터 정확하다(그 전엔 「NAS 목록 확인 중」). 같은 파일을 다시 올리는 경우(NAS 사본 손상)는 처음 센 총량보다 많을 수 있어 100%에서 멈춘다. 받은 변경 적용 단계는 개수 없이 경과 시간만.
- 모듈: `transfer-sync`(`nas-sync-remote.cjs`, `nas-sync-service.cjs` 경로 1줄, `nasSync.ts`, `nasSyncCoordinator.ts`, 새 `NasSyncProgress.svelte`, `TransferPanel.svelte` 2줄, `App.svelte` 4줄, 시험).
