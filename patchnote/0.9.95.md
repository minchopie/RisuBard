# RisuBard 0.9.95 — NAS 자료를 앱으로 직접 받기

- NAS·GitHub 파일 목록의 ‘앱으로 받기’가 기존 내부 수신함과 공통 가져오기를 통해 앱에 반영됩니다. 다운로드 폴더 저장/별도 가져오기는 필요하지 않습니다.
- 생성·가져오기 중에는 영속 수신함에서 기다리고, 같은 이름의 캐릭터가 여러 개면 팝업 없이 수신 목록에서 대상을 선택합니다.
- 자동 동기화의 순간적인 잠금으로 수동 원격 전송이 즉시 실패하던 경로를 제한적 대기/재시도로 연결했습니다. 네이티브 브리지 오류가 NAS 수신 처리까지 막지 않습니다.
- 기존 대화·캐릭터·API·설정·Wiki·저장 슬롯·화면과 파일/USB/공유 호환 흐름을 유지합니다. 변경은 기존 transfer-sync 모듈 안에 있습니다.

기존 NAS 코드 업데이트 모듈과 호환되는 런타임입니다. 실제 기기 적용·보존 결과는 별도 검수 기록을 따릅니다.
