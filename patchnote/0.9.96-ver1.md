# 0.9.96-ver1

## [호환] 원작 v0.9.96 위에 개인 기능 13개 모듈을 다시 얹은 로컬 후보

- 대상: 원작 안정판 v0.9.96 `97ea0351120b2a6decba8985e6c8c3cef6517ddf`. 이전 검증 대상 v0.9.92 `d704513d…`와의 원작 차이는 62경로이고, 그중 포크 호스트는 8경로(`package.json`, `DefaultChatScreen.svelte`, `PluginSettings.svelte`, `SideChatList.svelte`, `src/main.ts`, `globalApi.svelte.ts`, `request.ts`, `database.svelte.ts`)다.
- 어댑터: .92 선택 10개 가운데 `package.json` 버전 줄이 겹친 distribution만 `compat/v0.9.96/distribution.patch`로 새로 두었다(원작 `0.9.96` → `0.9.96-ver1`). 나머지 9개(.84·.86·.89·.90·.92 어댑터와 legacy-local-ai 기준 패치)는 원작 변경 영역과 겹치지 않아 그대로 쓴다. 호환 대상은 v0.9.96 하나만 등록한다.
- 원작 .93~.96 개선은 그대로 남는다: 스트리밍 응답 즉시 표시(`Chats.svelte`의 messageData 동기 추적), 플러그인 프로바이더 스트리밍 토글(`request.ts`), 버튼 효과음(`uiSound`), 사이드바 미니멀 모드, 독자 게시판 외전 탭, 모듈·플러그인 목록 압축, 둥근 스킨 카드 자르기 제거(`messageEdgeClip` 삭제), 시작 메뉴·빌드 경고 정리. 바뀐 호스트 6경로에 원작 원문 probe 8건을 더했다.
- 원작이 새로 추가한 `patchnote/0.9.93~0.9.96.md`는 원작 파일 그대로 두고, 포크의 동명 판본 문서는 payloadTargets로 `docs/fork-modules/history/patchnote/`에 보존한다.
- 개인 기능은 바꾸지 않았다: NAS 동기화(바쁨 대기·취소, 같은 내용 억제, 묶음 저장 소유·재시도, 바이트 진행, 해시·rootKey 재사용, 요청 중 자동 동기화 정지와 5초 재개, 수동 버튼), 파일 내보내기, 복구, API·설정·Wiki·슬롯·프로토콜, 콘텐츠 배포 알림. 미해결 스크롤 문제와 coordinator stop/start 경합은 손대지 않았다.
- 검증: 작성 환경에서는 명령 실행 권한이 없어 generate·structural verify·full을 돌리지 못했다. Codex가 독립 실행하고 결과를 기록한다. 인계 기록은 evidence `AUTHOR-HANDOFF.md`.
