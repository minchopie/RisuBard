# 0.9.96-ver7

- 대상: 원작 안정판 v0.9.96 `97ea0351120b2a6decba8985e6c8c3cef6517ddf`. 0.9.96-ver6 위에 「서버 끄기」 스위치 하나만 넣었다(앱 코드만).

## 새로 넣은 것: 설정 > 전송의 「서버 끄기 (이 PC)」
- PC에서는 탭을 닫아도 RisuBard 서버가 창 없이 계속 돌고, NAS에서 받아 둔 새 앱 코드는 서버가 다시 켜질 때만 적용됩니다. 지금까지는 작업 관리자 말고 끌 방법이 없었습니다.
- 설정 > 전송의 「캐릭터·페르소나 배포」 아래에 「서버 끄기」 버튼이 생겼습니다. 누르면 한 번 확인한 뒤, 보내지 않은 입력과 저장을 서버 파일까지 마치고 서버를 끕니다. 끄는 방법은 시작 메뉴의 「중지」와 같은 정상 종료입니다(남은 저장을 마무리하고 잠금을 풀고 종료).
- 꺼지면 화면에 「서버가 꺼졌습니다. 다시 켜려면 RisuBard를 실행하세요.」가 남습니다. 다시 실행하면 NAS에서 받아 둔 새 앱 코드가 있으면 그때 적용됩니다.
- 답변을 만드는 중, 채팅을 보내는 중, 전송·NAS 동기화 진행 중, 가져오기 진행·복구 대기, 다른 알림 창이 열린 경우에는 끄지 않고 이유를 버튼 아래에 보여 줍니다. 서버 쪽에서도 계정 가져오기·전송 정리·NAS 동기화 적용·답변 생성 중이면 거절합니다.
- 이 PC의 화면(localhost)에서만 보입니다. 안드로이드 앱(앱 안에 서버가 들어 있음)과, 다른 기기의 브라우저로 이 PC 서버를 연 화면에는 나오지 않습니다.
- 「서버 다시 시작」은 넣지 않았습니다. PC에는 서버가 스스로 다시 뜨는 기존 경로가 없습니다(RisuBard.exe 또는 업데이트 설치기가 서버를 띄움).

- 실제 기기 적용은 아직 확인하지 않았다(빌드·검사·격리 서버 시험만).
