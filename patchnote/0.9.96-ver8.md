# 0.9.96-ver8

- 대상: 원작 안정판 v0.9.96 `97ea0351120b2a6decba8985e6c8c3cef6517ddf`. 0.9.96-ver7(서버 끄기 스위치) 위에 「설치된 봇 업데이트」 합치기 두 가지를 더했다(앱 코드만). ver7의 서버 끄기 스위치도 이 판에 함께 들어 있다(0.9.96-ver7 패치노트).

## 고친 것 1: 카드 형식 사본 때문에 로어 항목이 '바뀐 것'으로 잡히던 것
- 카드를 가져올 때 앱은 로어 항목마다 `risu_id`·`risu_loreCache`·`risu_bookVersion`을 항목 값(id·loreCache·bookVersion)과 함께 `extentions` 안에도 한 번 더 넣습니다. 원작 비교는 id·loreCache는 빼고 bookVersion은 맞춰서 보지만, `extentions` 안의 같은 값은 그대로 비교했습니다.
- 그래서 앱에서 내보낸 카드(이 값이 들어 있음)로 업데이트하면, 바뀌지 않은 로어도 '새 판이 고친 항목'으로 잡히고(기준 기록이 있을 때), 기준 기록이 없으면 전부 '고를 항목'이 됐습니다. 이제 이 세 값은 비교에서 뺍니다. 다른 확장 값의 변화는 그대로 잡힙니다.

## 고친 것 2: 업데이트하면 Asset Maid 레퍼런스 이미지 지정이 풀리던 것
- Asset Maid는 인물·폼의 레퍼런스 지정을 카드 로어 한 항목(`__ASSET_MAID_DATA__`)에 넣습니다. 새 판에도 이 항목이 있으면 업데이트 화면은 항목 하나를 통째로 내 것/새 판 중에서 고르게 해서, 새 판을 고르면 레퍼런스가 모두 사라졌습니다.
- 이제 이 항목이 양쪽에서 다를 때(내가 고치고 새 판도 바꿈, 또는 처음 설치 기록이 없어 누가 고쳤는지 모를 때) 내 레퍼런스가 하나라도 새 판으로 옮겨지면, 이 항목은 처음부터 「직접 고침」으로 골라져 있습니다. 내용은 새 판 본문에 내 레퍼런스를 같은 인물(로어 지문, 그다음 같은 로어 제목으로 하나로 좁혀질 때만)·같은 폼에 옮겨 붙인 것입니다. 「모두 새 버전」을 눌러도 이 항목은 바뀌지 않습니다(원작의 「직접 고침」 규칙). 기준 파일을 불러와 다시 비교하면, 손대지 않은 미리 고른 값은 새 비교에 맞게 다시 만들어집니다.
- 그 미리 고른 값을 그대로 적용하면: 레퍼런스가 가리키는 내 그림과 Asset Maid 자르기 그림(`__asset_maid_crop_*`)은 업데이트 뒤에도 카드에 남고(그 그림을 「새 버전」으로 골라 빠지게 했어도 다시 붙음), 그림 번호(`asset:N`)·로어 번호(`lore:N`)와 지문은 업데이트 뒤 순서에 맞게 다시 매깁니다. 새 판 본문에 원래 있던 레퍼런스도 같은 방식으로 번호를 맞춥니다.
- 이 항목을 「내 버전 유지」·「새 버전 적용」으로 직접 고르거나 글을 고쳐 쓰면, 원작 그대로 그 선택이 적용되고 위 보정은 하지 않습니다.
- 새 판에 같은 인물(또는 하나로 좁혀지지 않음)이나 같은 폼이 없어 옮기지 못한 레퍼런스는 버리지 않고 알림(보류 목록)과 앱 기록에 남깁니다.
- 다른 로어·대화 유지·옛 카드 휴지통 사본은 그대로입니다.

- 실제 기기 적용은 아직 확인하지 않았다(사본 데이터 재현·검사만).
