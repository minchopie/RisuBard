# 0.9.96-ver9

- 대상: 원작 안정판 v0.9.96 `97ea0351120b2a6decba8985e6c8c3cef6517ddf`. 0.9.96-ver8 위에 안드로이드 뒤로가기 하나만 바꿨다.
- **안드로이드는 새 APK를 직접 설치해야 한다.** 뒤로가기 키를 받는 곳이 앱 껍데기(네이티브)라서 NAS 앱 코드 업데이트로는 바뀌지 않는다.
- **런타임 지문이 바뀌었다**(`d00269c8…` → `33b30c76…`). 안드로이드 껍데기 소스가 지문에 들어가기 때문이다. 그래서 이 판의 NAS 앱 코드는 이전 APK·이전 Windows 패키지에는 적용되지 않는다(이전 판 기기는 「전체 패키지 필요」 상태로 지금 판에 머문다). 휴대폰·태블릿은 이 판 APK, PC는 이 판 Windows ZIP을 한 번 설치해야 이후의 NAS 앱 코드 업데이트를 다시 받는다.
- PC(Windows)·브라우저 접속에서는 동작이 바뀌지 않는다(뒤로가기 처리가 설치되지 않음).

## 바뀐 것: 안드로이드 뒤로가기 = 이전 화면
지금까지 안드로이드 앱에서 뒤로가기(버튼이나 제스처)를 누르면 어느 화면에서든 앱이 꺼졌습니다(앱 껍데기가 뒤로가기를 받지 않아 안드로이드 기본 동작 = 앱 나가기). 이제는 **지금 열려 있는 것 중 맨 위의 것 하나만** 닫고 이전 화면으로 갑니다. 닫을 것이 없는 첫 화면(홈)에서는 지금처럼 앱을 나갑니다.

닫는 순서(위에서부터 하나씩):
- 알림·확인 창: 「아니오」·「취소」 버튼과 같은 뜻으로 닫습니다. 「예」·「확인(실행)」으로 처리하지 않습니다. 「확인」 버튼 하나뿐인 안내 창은 닫힙니다. 플러그인 위험 안내는 「설치하지 않음」과 같습니다.
- 오른쪽 클릭 메뉴 같은 작은 팝업, 이미지 뷰어(확대한 그림 → 뷰어 순)
- 열린 창(대화상자)과 목록 창(프리셋·페르소나·채팅 목록 등): 그 창의 닫기(X) 버튼과 같습니다. 겹쳐 있으면 맨 위의 것만 닫습니다.
- 크게 펼친 입력창: 작게 줄입니다(입력한 글은 그대로)
- BardWiki의 「설정」 팝업 → BardWiki
- 채팅·설정 옆에 붙은 패널: 로어북 작업 공간, BardWiki, 독자 게시판, 캐릭터 비서, 프롬프트 비서(각 패널의 「닫기」와 같음)
- 설정: 모듈 세부 → 모듈 목록 → (좁은 화면) 설정 항목 목록 → 설정 닫기
- 좁은 화면에서 열린 왼쪽 메뉴(사이드바), 모바일 화면의 메뉴 탭, 캐릭터 갤러리, 넓은 화면의 캐릭터 그리드
- 채팅 화면 → 홈(헤더의 「뒤로」 버튼과 같음. 보내지 않은 입력은 원래처럼 채팅별 임시 저장에 남습니다)
- 홈의 놀이터 도구 → 놀이터 → 홈, Realm → 홈, 모바일 화면의 검색·설정 탭 → 홈 탭

뒤로가기가 아무것도 닫지 않는 때(앱도 나가지 않음):
- 저장·가져오기·NAS 동기화 적용 중(화면이 잠긴 동안, 앱을 켜는 중의 복구 포함), 계정 가져오기 화면, 기다림·진행률 창, 불러오는 중 덮개
- 답을 만드는 중이거나 보내기를 준비하는 중인 채팅에서 홈으로 나가기
- 고를 것을 묻는 창(닫기 버튼이 없는 창, 선택 목록)
- 닫기 버튼이 꺼져 있는 창(저장 중 등)

- 키보드가 떠 있으면 안드로이드가 먼저 키보드를 닫습니다(그다음 누름부터 위 순서).
- 앱이 아직 켜지는 중인 첫 화면이나 화면이 1.5초 안에 답하지 못하면 지금처럼 앱을 나갑니다.
- 「한 번 더 누르면 종료」는 넣지 않았습니다(홈에서 한 번에 나감, 지금과 같음).
- 드롭다운 목록·글자 입력 자동완성 같은 작은 펼침은 따로 닫지 않습니다(뒤로가기는 그 아래 화면을 한 단계 돌립니다).
- 이전 APK에서는 지금처럼 앱을 나갑니다(이 판 APK에는 이 판 앱 코드가 들어 있음). 이 판 APK가 혹시 이전 앱 코드를 쓰게 되더라도 지금처럼 나갈 뿐 깨지지 않습니다.

- 실제 기기 적용은 아직 확인하지 않았다(빌드·검사·PC 화면 흉내 시험만).
