# RisuBard 0.9.96 — 실제 NAS 전송 경합 후속

실제 외부망 시험에서 자동 동기화의 저장 잠금이 30초 넘게 유지될 때 파일 목록 조회까지 실패하는 경우를 확인했습니다. 앱 DB를 변경하지 않는 NAS·GitHub 묶음의 설정 조회·파일 목록·업로드·다운로드를 DB 쓰기 잠금과 분리했습니다. 기존 인증·세션 검사는 유지하고, 대화 내보내기/적용·연결 설정 변경·구 JSON 백업은 기존 저장 잠금을 유지합니다.

0.9.95의 ‘앱으로 받기’, 영속 수신 대기, 기존 데이터·설정 보존 기능을 포함합니다. 변경은 기존 transfer-sync 모듈 안에 있습니다.
