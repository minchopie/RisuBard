# RisuBard 0.9.99 — BardWiki 서브 호출 캐시 접두 공유

BardWiki 자동 작성의 메모리 작성기·정식 위키 갱신 호출이 같은 고정 system과 같은 확정 대화(confirmedMessages) 블록으로 시작하도록 요청 순서를 바꿉니다. 호출별 지시·스키마·재시도 안내·입력 자료는 그 뒤에 붙습니다. 지시와 자료의 내용은 그대로이고 위치만 바뀝니다. 구조화 출력 스키마를 프롬프트로 다시 보낼 때도 스키마 안내를 마지막 user 메시지 뒤에 붙입니다. 마지막 메시지가 user가 아니면 이전처럼 맨 앞에 둡니다.

Gemini 암묵 캐시(직접 또는 OpenRouter)에서 같은 턴의 두 번째 이후 호출이 확정 대화 부분을 다시 쓸 수 있게 하려는 변경입니다. 실제 캐시 적중과 할인은 실제 호출로 확인하기 전까지 미검증입니다. 확정 대화가 없는 요청은 기존 구성 그대로입니다. 사용자 대화·Wiki·슬롯·API와 설정의 저장 형식은 변경하지 않습니다.
