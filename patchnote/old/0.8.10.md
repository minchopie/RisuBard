# RisuBard v0.8.10

## BardWiki 리부트

- 현재 대화의 첫 확정 AI 응답부터 최신 응답까지 BardWiki를 다시 만드는 `위키 리부트` 기능을 추가했습니다. 위키 툴바의 텍스트 버튼은 진행 상태에 따라 `리부트 정지`, `리부트 계속`, `정지 대기 중…`, `마무리 중…`으로 바뀝니다.
- 리부트 시작 전에 기존 위키를 다시 만들 것인지 확인한 뒤, 1턴씩 또는 2턴씩 갱신할지 선택할 수 있습니다. 두 방식의 장단점은 선택지와 툴팁에서 확인할 수 있으며 현재 설정된 AI 분석 토큰 상한도 함께 표시됩니다.
- 2턴 갱신은 두 응답의 의미 분석을 한 요청으로 합쳐 반복 프롬프트와 분석 호출 수를 줄이면서, 각 응답의 이벤트 문서는 서로 분리해 기록합니다. 정본 갱신은 별도 호출이 필요할 수 있고, 입력이 설정된 분석 토큰 상한을 넘을 것으로 예상되면 문서 단위로 자동 분할됩니다.
- 리부트 화면에서는 빈 임시 위키부터 문서가 한 배치씩 쌓이는 과정을 볼 수 있습니다. 전체 작업이 끝난 뒤에만 기존 위키를 완성된 임시 위키로 원자적으로 교체하므로, 중간 실패가 기존 정본을 손상시키지 않습니다.
- 진행 상태, 대상 응답, 완료된 응답과 배치 영수증을 대화 데이터에 저장합니다. 안전 정지를 요청하면 현재 배치를 마친 뒤 멈추며, 앱을 종료했다가 다시 열어도 이어서 진행할 수 있습니다.
- 배치 도중 강제 종료된 경우 완료 영수증이 있으면 다음 배치부터 계속하고, 불완전한 쓰기만 이전 스냅샷으로 되돌린 뒤 다시 시도합니다. 정지된 리부트는 계속하거나 취소할 수 있습니다.
- 리부트가 끝나거나 취소되기 전에는 새 응답 생성, 재생성, 이어쓰기와 위키 직접 편집을 막아 대화와 위키의 기준 시점이 어긋나지 않게 했습니다.
- 리부트뿐 아니라 자동 분석, 추가 분석과 직접 위키 명령을 포함한 모든 BardWiki 생성 작업 중에는 메시지 입력창의 BardWiki 버튼이 회전합니다. 여러 작업이 겹쳐도 마지막 작업이 끝날 때까지 표시가 유지됩니다.

## BardWiki 문서와 정본 갱신 개선

- 캐릭터 문서의 연대기에는 관련 이벤트 근거를 유지하되, `관련 문서` 목록에 등장한 모든 이벤트가 다시 나열되지 않도록 정리했습니다. 긴 대화에서도 캐릭터 문서의 링크 목록이 무제한으로 불어나는 현상을 줄입니다.
- 여러 정본 후보는 가능한 경우 한 번에 갱신합니다. 합친 정본 입력이 분석 토큰 상한을 넘을 것으로 예상될 때만 안전한 문서 묶음으로 나누며, 각 묶음은 원래 이벤트 근거를 유지합니다.
- 2턴 리부트에서도 턴별 이벤트의 출처 메시지 ID를 따로 보존하고, 공유 정본 변경은 한 배치 영수증으로 관리해 복구와 되돌리기의 경계를 명확히 했습니다.

## 세이브 / 로드 바로가기

- 기존 채팅 가장자리의 저장·불러오기 버튼을 `save`, `load` 제목이 있는 하나의 플로팅 블록으로 바꿨습니다. 캐릭터 사이드바에 있던 중복 버튼은 제거하고, 메시지 입력 메뉴와 플로팅 바로가기에서 같은 저장·불러오기 동작을 사용합니다.
- 플로팅 블록의 빈 영역을 누른 채 드래그해 위치를 옮길 수 있습니다. 놓은 위치는 메인 채팅 입력창을 기준으로 가장 가까운 가로·세로 변에 앵커되며, BardWiki 같은 보조 패널이 열리거나 채팅 폭이 달라져도 같은 상대 위치와 화면 안쪽 배치를 유지합니다.
- 블록 오른쪽의 닫기 버튼을 누르면 `세이브/로드 버튼을 끌까요? Bardwiki / 공통 옵션에서 다시 켤 수 있습니다.`라는 확인 창을 표시합니다.
- BardWiki 공통 옵션에 `세이브 / 로드 바로가기 버튼 보이기` 체크박스를 추가했습니다. 숨긴 뒤에도 이 옵션으로 다시 표시할 수 있으며, 드래그한 앵커 위치는 영속 저장됩니다.

## 다이얼로그 표시 순서

- 확인 창, 선택 창과 로딩 창을 BardWiki 도크와 생성 통계 플로팅 창보다 높은 최상위 계층에 배치했습니다. BardWiki 자체의 기존 표시 순위는 유지합니다.
- 드롭다운과 선택 목록은 일반 다이얼로그 위에 표시하되 최상위 확인 창 아래에 머물도록 계층을 분리했습니다. 토스트 알림은 확인 작업을 가리지 않습니다.

## 퍼스트 메시지 스튜디오 — 작업 중

> 이 기능은 아직 개발 중이며, v0.8.10의 완성 기능으로 간주하지 않습니다. 구성 방식과 데이터 형식은 추가 작업 중 변경될 수 있습니다.

- 캐릭터의 첫 메시지에 단계형 선택 화면을 만들 수 있는 범용 스튜디오 기반을 추가했습니다. 화면과 선택지 추가·삭제·순서 변경, 다국어 문구, 다음 화면 연결, 직접 입력과 완료 조건을 설정할 수 있습니다.
- 변수 이름, 표시 이름, 기본값과 선택 가능한 값들을 등록하고, 등록한 값 목록을 현재 화면의 선택지로 바로 만들 수 있습니다. 선택 결과는 기존 채팅 변수에 저장됩니다.
- 창의 강조색, 배경색, 내용 배경, 글자색, 선택지 열 수와 모서리 형태를 조정할 수 있습니다. 기본 표시 요소는 창 제목, 진행 단계와 이전·초기화 버튼만 제공합니다.
- 특정 작품이나 봇의 전용 템플릿, TV 형태의 외장, 상태 램프, 화면 효과와 다이얼은 기본 스튜디오에서 제거했습니다. 특수한 표현은 범용 기본 기능과 분리했습니다.
- 고급 코드 영역에서 해당 스튜디오 창에만 적용되는 사용자 CSS와 추가 HTML을 편집할 수 있습니다. 추가 HTML은 `{{variable_name}}` 형식으로 변수를 표시할 수 있으며, 실행 가능한 스크립트와 위험한 이벤트 속성은 제거됩니다.
- 스튜디오 프로젝트를 캐릭터 카드 확장 데이터에 보존하고, 미완료된 첫 메시지에서는 같은 런타임 화면을 표시하는 저장·채팅 연동 기반을 마련했습니다.
- 편집 중 선택한 언어의 문구를 완전히 지워도 다른 언어의 기본 문구가 다시 채워지지 않도록 수정했습니다. 실행 화면의 번역 대체 동작은 그대로 유지됩니다.
- `프로젝트 설정`을 어느 편집 탭에서 눌러도 창 제목, 완료 변수와 현재 화면 변수 설정이 즉시 열리도록 수정했습니다.
