# RisuBard v0.8.11

## 모델 프리셋 표시와 요청 바인딩 수정

- 실제 요청과 작업 화면에 표시되는 모델 이름이 같은 모델 모드와 바인딩 규칙을 사용하도록 수정했습니다. 모델 프리셋 모드로 고정했는데도 작업 로그에 레거시 모델명이 표시되거나, 반대로 레거시 모드에서 프리셋 이름이 표시되던 문제를 해결했습니다.
- BardWiki 자동 분석, 정본 갱신과 위키 리부트 같은 내부 요청은 현재 화면에 열린 채팅이 아니라 요청이 속한 채팅의 모델 프리셋 바인딩을 우선해서 사용합니다. 백그라운드 작업 중 다른 채팅으로 이동해도 원래 채팅의 메인·보조 모델 설정을 유지합니다.
- 직접 지정된 비채팅 작업 바인딩은 기존처럼 가장 높은 우선순위를 유지합니다.

## 퍼스트 메시지 스튜디오 — 작업 중

> 이 기능은 계속 개발 중이며, 구성 방식과 데이터 형식은 추가 작업 중 변경될 수 있습니다.

- 프로젝트 설정에 있던 별도의 한국어·일본어·영어 편집 행을 제거했습니다. 편집기와 실제 실행 화면은 현재 RisuBard의 앱 언어를 기본으로 사용하며, 한국어와 일본어 이외의 앱 언어에서는 영어를 사용합니다. 기존 캐릭터가 `cv_lang` 변수로 언어를 명시한 경우에는 그 설정을 우선합니다.
- 변수 이름을 바꾸면 선택지 효과, 직접 입력 대상과 표시용 변수에 남아 있던 기존 이름도 함께 갱신됩니다. 이름만 바꾼 뒤 연결이 끊겨 선택 결과가 저장되지 않던 문제를 막았습니다.
- 실시간 미리보기에서 두 번째 이후 화면을 열어 둔 채 제목·설명·선택지 등을 편집해도 첫 화면으로 돌아가지 않도록 수정했습니다. 현재 단계, 직접 입력값과 이동 기록을 가능한 범위에서 유지합니다.
- 편집 중 현재 화면을 삭제한 경우에는 남아 있는 시작 화면으로 안전하게 돌아갑니다.
- 미리보기에서는 내비게이션 버튼을 숨긴 스킨에서도 `처음부터` 버튼을 사용할 수 있어, 편집 흐름을 즉시 다시 시험할 수 있습니다.
