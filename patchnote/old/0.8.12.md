# RisuBard v0.8.12

## 퍼스트 메시지 스튜디오 — 베타

> 퍼스트 메시지 스튜디오가 베타 단계에 들어섰습니다. 주요 제작·공유 기능을 사용할 수 있으며, 베타 기간에는 사용성과 호환성을 계속 다듬어 나갈 예정입니다.

프로젝트 공유와 다시 불러오기, 다국어 편집과 UI 자동번역, 변수 조건에 따른 시나리오, 선택지별 화자·설명·삽화를 추가했습니다. 일반 Risu 호환 카드로 사용할 수 있으면서 RisuBard에서는 원본 프로젝트를 다시 열어 계속 편집할 수 있으며, 편집기와 미리보기 흐름도 더 안정적으로 다듬었습니다.

## 세이브와 채팅

세이브 슬롯은 새 채팅을 만들지 않고 현재 채팅을 저장 시점으로 되돌립니다. 전역 토글 값을 채팅별로 고정할 수 있으며, 저장하지 않은 대화가 사라질 때는 먼저 확인합니다.

## 모델과 플러그인

Gemini 3.7 Flash와 NovelAI Diffusion V5 Curated를 추가하고 OpenAI 추론 설정, 모델 표시와 요청 추적을 개선했습니다. 플러그인 업데이트가 브라우저 요청 실패 시 서버 경로로 자동 재시도하도록 수정했으며, V3 플러그인에 화면 절전 방지, 인레이 접근 권한과 채팅 출력 완료 이벤트를 추가했습니다.

## 호환성과 안정성

캐릭터 카드와 모듈을 내보내고 다시 가져올 때 확장 설정이 더 정확히 유지됩니다. 대형 세이브, Lua 스크립트 메모리, 자산 정리, CSS 렌더링, 파일 선택과 기존 데이터 보정도 개선했습니다. 색상 테마는 실제 팔레트를 보며 선택할 수 있습니다.
