# RisuBard v0.8.13

## BardWiki 분석 제한 해제

긴 대화에서 `Analysis context exceeds 128000 characters` 오류로 위키 분석이 중단되던 문제를 수정하고, 다음 고정 상한을 해제했습니다.

- **원문 길이**: 요청 내용을 추리기 전에 검사하던 64,000자·128,000자 제한
- **분석 메시지**: 분석 대상 12개·참고 대화 100개 제한
- **분석·검색 토큰 설정**: 32,768토큰 상한
- **최근 메시지 설정**: 100개 상한
- **추가 검색**: 4회 상한
- **정본 갱신 대상**: 8개 상한
- **기타 개수 제한**: 추가 분석·대량 메시지 삭제에 남아 있던 제한

기본값은 그대로이며, 설정값을 직접 늘릴 수 있습니다. 긴 입력은 설정한 요청 예산에 맞춰 처리하고, 모델의 실제 입력·출력 한도와 데이터 무결성 검증은 유지합니다.

- **설정 보존**: 큰 값도 저장·통신 과정에서 거부되거나 앱 재실행 시 초기화되지 않도록 수정했습니다.
- **갱신·되돌리기**: 대상이 많아도 모든 변경·경고를 기록하고, 저장 후 되돌릴 때 문서가 누락되지 않도록 수정했습니다.
- **도움말**: 분석 토큰 설정의 설명을 실제 동작에 맞게 수정했습니다.

## BardWiki 주요 인물 후보 선정

- **신규 등록 기준 분리**: 상태 변화가 없어도 확정된 대화에 지속적인 역할·관계·능력·목표·지식이 드러난 주요 인물은 새 문서 후보에 포함합니다.
- **인물별 점검**: 지휘자·동료·대립자 등 실제 참여자를 각각 확인합니다. 다른 문서에 이름이 있어도 개별 인물 문서를 생략하지 않습니다.
- **등록 우선순위**: 주요 대상의 최초 등록과 중요한 지속 변화를 사소한 행적 갱신보다 우선합니다.
- **불필요한 등록 억제**: 반복 갱신, 별칭 중복, 이름만 언급된 대상, 근거 없는 원작 설정의 등록은 계속 억제합니다.

## 채팅 바인딩 표시

- **채팅별 설정 강조**: 고정한 페르소나·프롬프트를 채팅별 토글과 같은 파란색으로 표시해 전역 설정과 구분합니다.
- **빈 이미지 정리**: 페르소나 이미지가 없을 때의 검은 핀 타일을 제거했습니다. 설정한 이미지는 유지합니다.

## 채팅 저장 슬롯 선택

- **저장 위치 선택**: 불러오기와 같은 슬롯 목록에서 새로 저장하거나 기존 슬롯을 덮어씁니다.
- **덮어쓰기 확인**: 확인 후 슬롯 이름은 유지하고 채팅·변수·Memory Wiki·저장 시간·턴 수·미리보기를 갱신합니다.
- **저장 실패 보호**: 중복 저장을 막고, 새 저장본이 완성된 뒤 기존 슬롯을 교체합니다. 작성·교체 실패 시 기존 슬롯을 보존합니다.
- **저장/불러오기 전환**: 창 제목 위 버튼으로 전환하며 현재 모드를 강조합니다. 창을 닫을 필요 없이 슬롯 선택과 미리보기를 유지합니다.
- **실수 방지**: 모드 전환만으로 저장·불러오기를 실행하지 않으며, 작업 중에는 전환을 잠급니다.

## 세이브와 프롬프트 설정 분리

프롬프트 설정은 세이브와 분리해, 불러오기 후에도 현재 설정을 유지합니다.

- **새 저장·덮어쓰기에서 제외**: 작가·문체·언어·서술 시점·답변 길이 등 프롬프트 옵션, 채팅별 토글 고정, 프롬프트 프리셋 연결·파라미터 적용 설정
- **기존 세이브도 적용**: 옛 프롬프트 설정은 무시합니다. 현재의 빈 값·비활성화·고정 해제 상태도 유지하며, 파일 변환이나 재저장은 필요 없습니다.
- **기존처럼 복원**: 대화 기록·Memory Wiki·스토리 진행 변수·프롬프트 외 로컬 변수·페르소나 및 모델 바인딩

## 페르소나 빌더 로어북 검색

- **필요한 항목만 주입**: 캐릭터 로어북 전체 대신, 매 생성 요청의 사용자 입력·현재 초안에 맞는 항목만 검색해 넣습니다. 수정 사항은 다음 요청에 반영됩니다.
- **기존 검색 기능 유지**: 채팅과 같은 검색 엔진으로 보조 키워드·단어 매칭·상시 활성·재귀 검색·토큰 예산을 적용합니다.
- **채팅과 분리**: 실제 채팅 기록·채팅 전용 로어북은 검색하지 않고, 채팅의 로어북 활성 상태도 바꾸지 않습니다. 별도 선택한 모듈 로어북의 주입 방식은 유지합니다.

## CBS 조건 보기

- **조건 보기 추가**: 로어북·팝업 편집기에서 중첩된 `if`·`or`·`equal` 구문을 조건식과 본문으로 나눠 봅니다. 조건을 실행하지 않고 모든 분기를 표시합니다.
- **조건식 구분**: 비교식에 배경·테두리, `OR`·`AND`·`NOT`에 별도 강조를 적용합니다. 중첩 조건은 테두리로 묶고, 좁은 화면에서는 줄바꿈합니다.
- **원문 보존**: 본문 편집 시 CBS 구문을 유지하며, 조건식은 `원문` 보기에서 수정합니다.
- **간결한 화면**: 설명과 주의사항은 툴팁으로 옮겼습니다.

## CBS 변수 사이드바

- **변수 자동 수집**: 원문의 고정된 변수 이름과 비교·대입 값 후보를 찾습니다. 변수 검색·전체 변수 보기·후보 외 값 직접 입력을 지원합니다.
- **값 수정**: 캐릭터·챗 정보가 있으면 현재 챗 값 또는 캐릭터 기본값을 선택해 수정합니다. 체크 버튼·Enter로 적용하며, 조건식 원문은 바꾸지 않습니다.
- **오른쪽 사이드바**: 본문과 따로 스크롤하고, 검색·저장 대상 선택은 상단에 고정합니다.
- **접기·펼치기**: 입력 중인 값을 유지합니다. 좁은 영역에서는 기본으로 접히며 `변수` 버튼으로 엽니다.

## 로어북 편집기 배치·크기 조절

- **한 줄 배치**: 이름·기본 키·보조 키·순서를 같은 행에 배치했습니다.
- **키 입력칸 확장**: 기본 키·보조 키 이름 옆 버튼으로 아래에 전체 너비의 여러 줄 입력칸을 펼칩니다. 높이도 조절할 수 있습니다.
- **영역별 크기 조절**: 목록·설정·변수 영역 사이에 조절 핸들을 추가하고 최소 폭을 낮췄습니다.
- **창 크기 조절**: 가장자리·모서리에서 조절하며 화면 중앙을 유지합니다.
- **조작 방법**: 드래그·방향키로 조절하고, 더블클릭·Home으로 초기화합니다.
