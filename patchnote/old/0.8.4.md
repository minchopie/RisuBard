# RisuBard v0.8.4

## 주요 변경 사항

- BardWiki가 질문의 표현과 과거 기록의 문구가 정확히 일치하지 않아도 관련 사건을 더 잘 찾도록 한국어 복합어와 간접 단서 탐색을 개선했습니다. 인물·장소·물건·행동의 관계를 따라가며 과거 사건의 구체적인 근거를 회수합니다.
- 새 기본 Wiki Prompt Preset에 `퍼즐·단서 추적기`를 추가했습니다. 퍼즐의 문양, 순서, 좌우 배치, 짝, 빈칸, 장치 위치와 시도 결과를 보존하며, 확인된 관찰과 추론한 규칙·정답을 구분해 기록합니다.
- 같은 프리셋에 `퍼즐·관계 추론` 응답 보조 블록을 추가했습니다. 관련 BardWiki 문서가 실제로 회수된 답변에서만 단서 사이의 관계를 검토하며, 추론을 확정 사실처럼 단정하지 않도록 제한합니다.
- Wiki Prompt Preset 편집기를 `위키 작성 블록`과 `응답 보조 블록`으로 분리했습니다. 응답 보조 지침은 메모리 분석이나 정본 작성 규칙에 섞이지 않습니다.
- 잠긴 핵심 계약과 동적 주입 블록의 실제 내용을 읽고 복사할 수 있게 했습니다. 프롬프트 본문 입력란과 읽기 전용 계약란은 아래쪽 핸들로 높이를 조절할 수 있습니다.
- 각 사용자 프롬프트 블록에 `프롬프팅 도움말`을 추가했습니다. 플로팅 리퍼런스에서 `establishedEvents`, `stateChanges`, `characterKnowledge`, `persistentFacts`, `openContinuity`, `canonicalUpdateCandidates`의 의미와 근거·추론 경계, 퍼즐 작성 예시를 확인할 수 있습니다.
- 기존 사용자 Wiki Prompt Preset은 자동으로 덮어쓰지 않습니다. 새 퍼즐 블록은 새로 생성되는 기본 프리셋에 포함되며, 기존 프리셋에서는 같은 목적의 사용자 블록을 직접 추가할 수 있습니다.
- 메인 화면에서 RisuRealm 브라우저를 바로 열도록 바꾸고 Related Links 영역을 제거했습니다. 최신 테마 토큰을 적용한 카드·상세 창·검색 화면과 한국어 UI를 제공합니다.
- 캐릭터 검색은 Enter 키로 바로 실행됩니다. 태그 입력창은 포커스 시 전체 태그를 알파벳순으로 보여 주며, 공백으로 구분한 각 태그에 자동완성·방향키·Tab·Enter 선택과 중복 제외를 지원합니다.
- RisuRealm 캐릭터 설명의 URL을 자동으로 링크화했습니다. 상세 창에서 텍스트를 드래그해도 창이 닫히지 않으며 다운로드 버튼과 설명을 더 명확하게 표시합니다.
