# RisuBard v0.8.7

## 주요 변경 사항

- 프롬프트 프리셋, 모듈, 플러그인의 기본 목록에 폴더 정리 기능을 통합했습니다. 별도 관리자 창을 열지 않고 폴더를 만들고 이름을 바꾸거나 삭제할 수 있으며, 전체·미분류 보기, 검색, 폴더별 항목 수, 다중 선택과 일괄 이동, 드래그 이동, 폴더·항목 순서 변경을 지원합니다.
- 폴더로 필터링한 상태에서도 기존 목록의 모든 동작을 그대로 사용할 수 있습니다. 프리셋 선택·편집·복제·내보내기·삭제, 모듈 활성화·페르소나 할당·편집, 플러그인 업데이트·활성화·권한 초기화·인자 편집 등을 각 항목에서 바로 실행할 수 있습니다.
- 폴더 정보는 원본 프리셋·모듈·플러그인과 분리해 저장합니다. 폴더를 삭제해도 안의 항목은 삭제되지 않고 미분류로 돌아가며, 정리 작업은 활성 프롬프트 프리셋이나 모듈·플러그인의 실행 상태를 변경하지 않습니다.
- 모듈을 페르소나별로 활성화할 수 있습니다. 모듈 설정에서 검색 가능한 페르소나 할당 창을 열어 사용할 페르소나를 선택할 수 있으며, 현재 활성 페르소나에 할당된 모듈만 기존 전역·채팅·캐릭터 모듈에 추가됩니다.
- LLM 번역 사용 시 언어 설정에 번역 캐시 관리자가 표시됩니다. 캐시를 검색하고 100개 단위로 탐색하며, 번역값 편집·복사·개별 삭제·가져오기·내보내기·전체 삭제를 할 수 있습니다.
- 홈 화면 상단에서 `RisuBard` 이름과 현재 앱 버전을 바로 확인할 수 있습니다.

## 안정성 및 호환성

- 기존 프리셋·모듈·플러그인 데이터 형식을 유지하면서 구버전 데이터에도 안전한 정리 메타데이터와 페르소나 ID를 자동으로 보정합니다.
- 플러그인 업데이트가 브라우저 캐시의 오래된 소스를 다시 설치하지 않도록 캐시를 우회하고, 내려받은 소스가 실제 설치 데이터에 반영되어 저장까지 끝났는지 확인한 뒤 성공 또는 실패 결과를 표시합니다.
- 페르소나 전환이나 모듈 내용 교체 후에도 이전 모듈 캐시가 남지 않도록 모듈 해석 캐시 갱신을 보강했습니다.
- 번역 요청이 진행 중인 상태에서 캐시를 편집하거나 삭제해도 늦게 완료된 요청이 이전 값을 되살리지 않도록 처리했습니다.
- 여러 창이나 원격 접속에서 같은 번역 캐시를 동시에 변경할 때 다른 항목을 덮어쓰거나 삭제하지 않도록 항목별 충돌 감지를 추가했습니다. 일부 삭제가 실패한 경우에도 실제 저장 상태와 메모리 캐시를 다시 맞춥니다.
- 대용량 로컬 백업을 복원할 때 백업 전체를 서버 메모리에 올리지 않고 디스크 기반으로 스트리밍해, 복원 중 메모리가 급증하거나 서버가 종료되는 문제를 개선했습니다.
- 서버에 저장한 백업을 복원할 때 후처리가 길어져도 연결이 끊기지 않도록 진행 응답과 keepalive 처리를 보강했습니다.
- 일반 저장소 요청에 인증 API 요청 제한이 중복 적용되어 `getItem` 오류나 429 응답이 발생하던 문제를 수정했습니다.
