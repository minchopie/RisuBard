# RisuBard v0.8.8

## 플러그인 호환성

- 자체 생성 정보 창을 제공하는 플러그인은 제공자 등록 시 `overrideRequestStatus: true`를 명시해 RisuBard의 고급 요청 상태 창을 끌 수 있습니다. 옵션을 켜지 않은 플러그인은 기존처럼 RisuBard 창을 사용하므로 일반 제공자에서 생성 정보가 사라지지 않습니다.
- 기존 `hostRequestStatus` 옵션은 호환을 위해 유지하며, 새 플러그인에서 사용할 양방향 예제와 적용 범위를 제작자 문서에 추가했습니다.

## UI 수정

- BardWiki 메모리 도움말을 최상위 다이얼로그 계층으로 옮겨 메모리 도크에 가리지 않고 화면 중앙에 온전히 표시되도록 수정했습니다.
