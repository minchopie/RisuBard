# RisuBard v0.9.0

v0.8.12 이후의 변경을 모았습니다. 이번 버전은 테마 편집과 관리 창의 사용성, CBS 편집 지원, BardWiki 분석과 세이브/로드를 개선합니다.

## 테마와 글자색

- 테마의 UI 색상과 본문·대사 등 글자색을 직접 편집하고 미리 볼 수 있습니다. 기본 테마에서 색상을 수정하면 현재 팔레트를 유지한 사용자 테마로 전환합니다.
- 밝은 테마와 어두운 테마 모두에서 읽기 어려운 글자색을 표시할 때 보정합니다. 저장한 색은 보존하며, 자동 대비 보정을 끄면 입력한 색 그대로 사용할 수 있습니다.
- 채팅 배경·테두리와 버튼·입력란·모달·툴팁·편집기의 색상을 테마에 맞게 정리했습니다. 색상 설정의 저장·불러오기와 테마 전환도 보완했습니다.

## 관리 창과 편집기

- 프리셋·모듈·플러그인 관리 화면의 배치를 좁은 영역에 맞추고, 목록과 편집 영역의 크기를 조절할 수 있게 했습니다.
- 로어북의 이름·기본 키·보조 키·순서를 한 줄에 배치했습니다. 키 입력칸을 여러 줄로 펼치고, 목록·설정·변수 영역과 창 크기를 조절할 수 있습니다.
- 로어북과 팝업 편집기에 **CBS 조건 보기**를 추가했습니다. 중첩 조건을 조건식과 본문으로 나누어 표시하며, 조건을 실행하지 않고 모든 분기를 보여 줍니다.
- **CBS 변수 사이드바**에서 원문의 변수와 값 후보를 찾고, 현재 채팅 값 또는 캐릭터 기본값을 수정할 수 있습니다. 조건식 원문은 유지합니다.
- 채팅 메시지 편집을 `Ctrl+Enter` 또는 `Cmd+Enter`로 저장할 수 있습니다.

## BardWiki

- 긴 대화에서 `Analysis context exceeds 128000 characters` 오류를 일으키던 앱 내부 고정 상한을 해제했습니다. 원문 길이, 분석·참고 메시지 수, 분석·검색 토큰 설정, 추가 검색과 정본 갱신 대상 수 등을 필요한 만큼 설정할 수 있습니다.
- **기본값과 모델 자체의 한도는 유지합니다.** 긴 입력은 설정한 요청 예산에 맞춰 처리하며, 데이터 무결성 검증도 유지합니다.
- 큰 설정값이 저장·통신·재실행 과정에서 거부되거나 초기화되지 않도록 보완했습니다. 갱신 대상이 많을 때의 변경 기록과 되돌리기도 개선했습니다.
- 주요 인물의 최초 등록과 기존 문서 갱신 기준을 분리했습니다. 지속적인 역할·관계·능력·목표·지식이 확인된 주요 인물을 개별 점검하면서, 반복 기록·별칭 중복·근거 없는 설정 등록은 억제합니다.

## 세이브/로드와 채팅 설정

- 슬롯 목록에서 새로 저장하거나 기존 슬롯을 확인 후 덮어쓸 수 있습니다. 새 저장본 작성이 완료되기 전에는 기존 슬롯을 보존합니다.
- 창을 닫지 않고 저장·불러오기 모드를 전환하며, 선택한 슬롯과 미리보기를 유지합니다. 작업 중에는 모드 전환을 잠급니다.
- 세이브를 불러와도 현재의 작가·문체·언어·서술 시점·답변 길이 등 프롬프트 옵션과 채팅별 토글·프롬프트 프리셋 설정을 유지합니다. 기존 세이브에도 적용하며 별도 변환은 필요 없습니다.
- 대화 기록·Memory Wiki·스토리 진행 변수·프롬프트 외 로컬 변수와 페르소나·모델 바인딩은 기존처럼 복원합니다.
- 채팅에 고정한 페르소나·프롬프트를 전역 설정과 구분해 표시하고, 이미지가 없는 페르소나의 검은 핀 타일을 제거했습니다.

## 페르소나 빌더와 플러그인

- 페르소나 빌더는 캐릭터 로어북 전체 대신 매 요청의 사용자 입력과 현재 초안에 맞는 항목을 검색해 주입합니다. 기존 키워드·상시 활성·재귀 검색·토큰 예산을 적용하며 실제 채팅 기록과 로어북 활성 상태는 변경하지 않습니다.
- 페르소나 빌더에 가려진 입력란의 **컵케이크 확장 버튼이 클릭되는 문제**를 수정했습니다. V3 플러그인의 요소 이벤트를 문서 전체가 아닌 해당 요소에 연결하고, 정상 클릭·키보드 처리와 플러그인 재로딩 시 이벤트 해제를 함께 보완했습니다.
