# RisuBard v0.9.10

이번 버전은 **BardWiki 자동 작업의 비용 제어와 즉시 취소 기능을 복구하는 핫픽스**입니다.

## BardWiki 자동 작성 제어 복구

- 채팅 입력창의 `AUTO` 스위치를 복구하고 저장된 자동 작성 설정을 실제 응답 후 처리 경로에 다시 연결했습니다.
- `AUTO`를 끄면 이후 응답에서 BardWiki 자동 분석과 정본 갱신 모델 호출을 시작하지 않습니다.
- 수동 BardWiki 열기와 추가 분석 기능은 자동 작성 설정과 독립적으로 계속 사용할 수 있습니다.

## 실행 중인 BardWiki 작업 취소

- BardWiki 버튼이 회전하는 동안 위쪽에 `바드위키 작업 취소` 버튼을 표시합니다.
- 취소 신호를 실제 모델 요청까지 전달해 진행 중인 요청과 후속 재시도·정본 갱신을 중단합니다.
- 리부트 중 취소하면 작업을 실패 처리하지 않고 다시 계속할 수 있는 일시정지 상태로 보존합니다.
- 노란 BardWiki 열기 버튼을 오른쪽으로 5px 겹쳐 `AUTO` 컨트롤의 왼쪽 경계가 드러나지 않도록 정리했습니다.
