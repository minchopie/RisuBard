# RisuBard v0.9.11

이번 버전은 **오래된 이야기의 세부사항까지 되찾는 BardWiki**, **위키를 직접 정리하는 BARDCHAT**, **모바일에서도 이어지는 창작·공유 작업공간**에 집중했습니다.

## [기능] BardWiki 장기 기억

- **아크플로터:** 이야기에서 확정된 사건을 `스토리 아크 플롯`으로 자동 압축해 수백 턴 뒤에도 필요한 과거 사건으로 돌아갈 경로를 유지합니다. 기본으로 켜져 있으며 기존 채팅도 다음 사건이 기록될 때부터 사용하고, 이전 이름으로 만든 플롯도 이어 쓰며, 별도의 응답 형식을 요구하지 않습니다.
- **작품 길이 프리셋:** `단편소설`, `중편소설`, `대하소설` 기본 프리셋과 사용자 프리셋을 제공합니다. 갱신 간격과 플롯 용량을 직접 조절하고 사용자 프리셋을 저장·덮어쓰기·삭제할 수 있습니다.
- **오래된 원문 회상:** 최근 위키 분석에 포함되지 않은 대화도 현재 질문과 직접 대조해, 요약에서 빠진 이름·물건·대사 같은 세부사항을 다시 찾습니다. 임베딩이나 보조 AI 호출을 추가하지 않으며 정확한 사실은 원문과 사건 기록을 우선합니다.
- **별칭 기반 식별:** BardWiki 문서의 제목과 별칭을 함께 검색합니다. 이름 변경이나 문서 결합 뒤에도 이전 이름을 보존하며, 같은 별칭이 여러 문서에 겹치면 임의로 연결하지 않습니다.
- **분석 상태 확인:** `추가 분석` 안내에서 마지막으로 분석한 AI 응답과 완료 시각을 확인할 수 있습니다.
- **위키 갱신 자동 복구:** 공급자 타임아웃이나 일시 오류로 정보 문서 갱신이 실패해도 사건 기록을 보존하고 다음 턴에 자동으로 다시 시도합니다. 위키 리부트는 실패한 배치를 완료 처리하지 않고 안전하게 멈춰 `리부트 계속`으로 같은 배치를 복구합니다.
- **오류 진단 개선:** 플러그인 오류가 빈 `{}`로 표시되던 문제를 고쳤습니다. 채팅 요청 증거 보고서에는 응답 본문이나 인증 정보를 노출하지 않으면서 HTTP 상태와 `타임아웃`, `호출 제한`, `인증`, `서버`, `네트워크` 오류 유형을 기록합니다.
- **삭제 결과 반영:** 확정된 메시지를 삭제해 연결된 사건이 제거되면 열려 있는 Memory Wiki 화면도 즉시 갱신됩니다.

## [기능] BARDCHAT 위키 관리

- **관리자 작업공간:** 기존 BardWiki 관리자 터미널을 `BARDCHAT - AI에게 지시를 내리세요`로 정리했습니다.
- **컨텍스트 선택:** `위키`, `챗`, `시스템`, `캐릭터`, `페르소나`, 로어북 중 관리자 AI에게 전달할 자료를 채팅별로 선택할 수 있습니다. 기본값은 `위키`만 사용해 불필요한 토큰 소비를 줄입니다.
- **위키 명령어:** 항목 결합·분리·요약·링크 재연결·중복 정리·이름 변경·연대기 정리 등의 템플릿을 현재 지시문에 `삽입`하거나 전체 `교체`할 수 있습니다. 여러 문서를 다루는 작업은 앞선 쓰기가 실패하면 삭제 같은 후속 처리를 중단합니다.
- **위키 편집 화면:** 데스크톱에서는 문서 트리를 고정하고, 좁은 화면에서는 필요할 때 여는 서랍으로 전환합니다. BARDCHAT도 편집기 아래에 고정되어 언제든 다시 펼칠 수 있습니다.
- **위키 작업 복구:** 플러그인 모델이 위키 작업 형식을 지키지 않으면 필요한 형식을 포함해 한 번 더 요청합니다.
- **오류 정보 보호:** 모델 응답을 검사할 때 오류 안내에 원문 전체가 노출되지 않도록 보강했습니다.

## [기능] 아카라이브 챗 로그

- **공유 범위 선택:** 공유용 챗 로그를 만들 때 `챗 전체`, `페이지 범위`, `턴 범위` 중 출력 구간을 고르고 사용자 메시지 포함 여부와 예상 글자·이미지 수를 미리 확인할 수 있습니다.
- **출력 모양 조절:** 폰트 크기, 문단 간격, 이미지 너비와 타이틀 이미지 형식을 미리 조정할 수 있습니다. 일반 문장은 편집 가능한 HTML로 유지하고 특수 배경·상태창·플로팅 버튼은 이미지로 보존합니다.
- **챗 로그 작업창:** 창 크기와 사이드바 접힘을 조절하고 마지막 크기를 기억합니다. 좁은 화면에서는 한 열로 전환하며, 실제 내용이 준비되기 전에 빈 로그가 만들어지는 문제도 방지했습니다.

## [UI] 채팅·설정 화면

- **첫 메시지 유지:** 모든 채팅 페이지 위에 채팅의 첫 메시지를 표시하고, 이에 연결된 선택 버튼과 사이드 패널도 다음 페이지에서 유지합니다. 2페이지부터는 첫 메시지를 기본으로 접어 둡니다.
- **모바일 설정 관리:** 모듈과 플러그인을 좁은 인라인 영역 대신 설정 상세 화면 전체에서 조작할 수 있습니다.
- **모바일 창 정리:** 세이브/로드, 부분 편집, 프리셋·페르소나·채팅 목록 창이 화면 밖으로 밀리지 않으며 주요 조작 버튼도 항상 화면 안에 남습니다.
- **봇 카드 조작:** 고정된 봇 카드에 마우스를 올릴 때 이미지가 깜빡이거나 클릭이 무시되던 문제를 수정했습니다.
- **캐릭터 엑스포트:** `공유/엑스포트` 창에서 Character Card 버전과 포맷을 다시 선택할 수 있게 했습니다.

## [성능] 백업 복원

- **대용량 복원 속도:** 불필요하게 임시 파일을 다시 처리하던 작업을 제거해 HDD를 포함한 저속 저장장치의 복원 병목을 줄였습니다.
- **진행 상태와 안전성:** 업로드 뒤 `백업 검증 → 복원 적용 → 마무리` 단계를 표시하며, 검증을 마친 백업만 적용합니다.
