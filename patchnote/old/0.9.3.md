# RisuBard v0.9.3

v0.9.2 이후의 변경을 모았습니다. 이번 버전은 **확정된 원본 응답 편집과 위키 이동 개선**, **위키 리부트 시작점 선택**, **아카라이브 챗 저장기**에 초점을 맞췄습니다.

## 확정된 원본 응답 편집과 위키 이동

- BardWiki 근거로 이미 확정된 원본 AI 응답도 채팅의 수정 버튼으로 직접 고칠 수 있습니다.
  - 원본을 수정해도 기존 BardWiki 문서는 자동으로 바뀌지 않습니다. 필요한 사건을 직접 수정하거나, 영향을 받은 구간부터 위키 리부트를 실행할 수 있습니다.
- `지금까지의 이야기`에서 사건 카드를 편집기로 바로 열 수 있으며, 원문 이동은 별도 버튼으로 구분했습니다.
- RisuBard 편집기 도구 모음에도 `원문으로 이동` 버튼을 추가했습니다.
  - `지금까지의 이야기`와 편집기 어디에서 이동하더라도 BardWiki 사이드바는 열린 상태를 유지합니다.

## 위키 리부트 시작점 선택

- 위키 리부트 선택창 위쪽에 시작 챗 인덱스 입력란을 추가했습니다.
  - 기본값 `0`은 전체 대화를 다시 처리합니다.
  - 중간에 문제가 생긴 경우 해당 메시지의 인덱스부터 이어서 리부트할 수 있습니다.
  - 존재하지 않는 인덱스에서는 리부트를 시작하지 않습니다.

## 아카라이브 챗 저장기

- 각 메시지의 `아카라이브 챗 저장기` 버튼으로 렌더링된 챗을 이미지와 함께 아카라이브 편집기에 붙여넣을 수 있습니다.
  - CSS 배경 이미지를 실제 이미지로 변환하고, 본문 순서를 유지한 채 클립보드용 HTML에 포함합니다.
  - 편집 버튼 같은 상호작용 요소와 아카라이브에서 지원하지 않는 레이아웃 속성은 제거하거나 호환 가능한 구조로 바꿉니다.
- `환경설정 > RisuBard > 공통 설정`에 모든 캐릭터와 챗이 공유하는 추출 설정을 추가했습니다.
  - 삽화 너비, 본문 글자 크기와 문단 사이 간격을 조절할 수 있습니다.
  - 타이틀 이미지 표시 여부와 `큰 타원형 | 정사각형 | 썸네일 + 타이틀` 형식을 선택할 수 있습니다.
- 대사, 생각, `§효과음§`과 명시적인 선택지 블록을 아카라이브 호환 인라인 스타일로 변환합니다.
  - 현재 밝기 모드에 맞는 색상 계열을 사용하며, 기존 소악마 모듈의 의미별 색상이 있으면 보존합니다.
- 아카라이브가 붙여넣은 이미지를 다시 업로드하는 과정에서도 설정한 크기가 유지되도록 이미지의 `max-width`에 너비를 기록합니다.
  - 삽화는 중앙 정렬 문단으로 감싸 왼쪽으로 치우치지 않도록 했습니다.
- 삽화 너비, 글자 크기와 개행 간격의 숫자를 직접 입력할 때 값이 상한으로 튀던 문제를 수정했습니다.
