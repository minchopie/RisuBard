		<p style="margin:0;color:#29415a;font-size:16px;line-height:1.9;">여러 프롬프트에서 자주 쓰는 블록만 모아 두고, 현재 프롬프트의 원하는 위치에 적용할 수 있어. 프롬프트를 바꿀 때마다 같은 블록을 복사해 붙여 넣던 작업을 줄였어.</p>

			<p style="margin:0;color:#173e69;font-size:17px;font-weight:850;line-height:1.7;">블록 추출 → 위치 지정 → 주입 프리셋 저장 → 요청 시 자동 적용</p>
			<p style="margin:9px 0 0;font-size:15px;line-height:1.85;">예를 들어 제목에 <code>📙</code>가 들어간 블록만 모은 뒤, 대상 블록의 앞이나 뒤에 넣거나 해당 블록을 교체하도록 설정할 수 있어.</p>
		</div>
		<ul style="padding-left:22px;font-size:15px;line-height:1.85;">
			<li style="margin:10px 0;"><strong>필요한 블록 추출:</strong> 설치된 프롬프트에서 제목에 지정한 문자열이 들어간 블록을 추출해. 검색 기본값은 <code>📙</code>야. 새 묶음을 만들거나 현재 묶음 뒤에 추가할 수 있어.</li>
			<li style="margin:10px 0;"><strong>독립된 묶음 편집:</strong> 추출 블록은 원본 프리셋과 분리해 보관해. 묶음 이름 변경·삭제와 블록 추가·복제·삭제, 제목·내용·타입·특수 타입·역할 편집, 1칸·5칸 단위 순서 이동을 지원해.</li>
			<li style="margin:10px 0;"><strong>주입 위치 기억:</strong> 블록마다 <code>건너뛰기</code> 또는 대상 블록의 <code>앞·교체·뒤</code>를 지정할 수 있어. 묶음이나 활성 프롬프트를 바꿔도 매핑을 유지하고, 대상 블록이 없으면 해당 항목을 표시해.</li>
			<li style="margin:10px 0;"><strong>주입 프리셋 저장:</strong> 추출 블록과 참조 토글 포함 여부, 삽입 방식·대상을 별도 프리셋으로 저장하고 관리할 수 있어. 선택한 주입 프리셋은 현재 프롬프트로 요청을 보낼 때 자동 적용돼.</li>
			<li style="margin:10px 0;"><strong>결과 확인과 편집:</strong> <code>블록 주입 프리뷰 + 에디터</code>에서 원본·주입 블록을 접어 보거나 직접 편집할 수 있어. 합성 결과를 새 프롬프트로 저장하거나, 확인 후 원본에 덮어쓸 수도 있어.</li>
			<li style="margin:10px 0;"><strong>작업 공간 조절:</strong> 도구·매핑 목록·프리뷰 사이의 너비를 조절하고 상단 영역을 접을 수 있어. 좁은 창에서는 조작 요소가 줄바꿈되며, 최종 블록 순서도 스크롤해 확인할 수 있어.</li>
		</ul>

			<li style="margin:10px 0;"><strong>챗별 설정 관리:</strong> 현재 챗의 설정을 작동 방식·검색·분석/응답·정본 작성으로 나눠 관리해. 챗 규모에 맞춘 도움말을 확인하고 현재 값을 전역 기본값으로 적용하거나 창 크기를 조절해 기억할 수 있어.</li>
