# RisuBard v0.9.34

로어북 작업에 필요한 과거 AI 응답을 턴 번호로 골라 참고할 수 있게 했습니다. RisuRealm 제작자 검색을 추가하고, BardWiki 생성과 저장 안정성 및 성능을 개선했습니다.

## [기능] 로어 빌더 메시지 참조

- **AI 응답 턴 선택:** 로어북과 Grimoire의 `로어 빌더`에서 `메시지` 컨텍스트를 켜고 `5`, `-3`, `10-13`처럼 입력해 특정 AI 응답, 최근 응답 묶음 또는 연속 범위를 주입할 수 있습니다. 사용자 메시지와 댓글·비활성 메시지는 제외됩니다.

## [기능] RisuRealm 제작자 검색

- **제작자 이름 검색:** 홈 화면의 RisuRealm 검색에서 제작자 이름도 함께 찾으며, 캐릭터 항목의 제작자 이름을 누르면 해당 제작자의 캐릭터를 바로 검색합니다.

## [편의성] BardWiki 병렬 생성

- **분석 대기 제거:** 자동 확정, 추가 분석이나 관리자 작업이 진행 중이어도 새 응답과 재생성을 바로 시작할 수 있습니다. 진행 중인 위키 변경은 저장 완료 뒤 시작하는 요청부터 반영되며, 전체 위키를 교체하는 `위키 리부트` 중에는 안전을 위해 생성을 계속 차단합니다.

## [편의성] 모바일 RisuRealm 상세

- **다운로드 버튼 접근성:** 세로 공간이 짧은 모바일 화면에서도 캐릭터 상세 창이 화면 안에 맞춰지고 전체 내용을 스크롤해 하단 `다운로드 후 채팅` 버튼까지 누를 수 있습니다.

## [안정성] BardWiki 긴 절 보호

- **불완전한 응답 차단:** 정본 절의 4,000자 고정 상한을 없앴습니다. 공급자가 출력 한도 종료를 보고하거나 응답 구조가 불완전하면 기존 문서를 덮어쓰지 않고 자동으로 재시도하며 경고를 표시합니다.

## [안정성] 중복 서버 차단

- **데이터 폴더 잠금:** 같은 사용자 데이터 폴더를 이미 사용 중인 RisuBard 서버가 있으면 두 번째 서버가 데이터 파일을 열기 전에 시작을 중단해 저장 충돌과 채팅 롤백을 방지합니다.

## [안정성] 재생성 단축키

- **최신 응답 재생성:** 설정한 `재생성` 단축키가 다음 swipe로 이동하지 않고 최신 AI 응답을 새로 생성하도록 수정했습니다.

## [안정성] 자동 번역

- **상태 변경 오류 수정:** 캐시된 메시지만 자동 번역하도록 설정했을 때 번역 상태가 바뀌며 메시지 렌더링 오류가 발생하던 문제를 수정했습니다.

## [성능] 저장 지연 감소

- **불필요한 파일 처리 생략:** 내용이 같은 정규 파일을 매번 임시 저장소에 다시 쓰거나 동일 여부를 확인하려고 본문을 반복해서 읽지 않도록 했습니다. 대형 저장 데이터의 인코딩 결과를 메모리에서 통째로 다시 복사하는 작업과 게시할 파일이 없을 때의 빈 복구 기록도 생략합니다. 저장 도중 외부 변경이 감지되면 새 파일을 게시하기 전에 안전하게 중단합니다.

## [성능] Gemma 토크나이저

- **중복 로드 방지:** 여러 메시지의 토큰 수를 동시에 계산할 때 토크나이저를 중복 로드하지 않도록 해 과도한 메모리 사용과 로드 실패를 방지합니다.

## [다국어] BardWiki 현지화 제목

- **현지화 제목 인식:** 일본어·중국어 등 선택한 작성 언어의 위키 절 제목과 스토리 아크 제목을 인식해 `지금까지의 이야기`, 관련 문서, 아크 플롯이 정상적으로 표시됩니다.

## [문서] 저장 구조 관찰 판정

- **점진 전환 근거 확정:** 실사용 저장 로그와 이전 V2 코드를 대조해 현재 저장 비용과 과거 전환 실패 원인을 분리하고, 정본 권한을 유지한 채 가장 큰 쓰기 증폭부터 줄이는 다음 후보를 공식 위키에 기록했습니다.
