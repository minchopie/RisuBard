# RisuBard v0.9.36

플러그인에서 BardWiki를 안전하게 활용할 수 있는 API를 추가하고, 저장 진단과 프리셋 저장 경로를 개선했습니다. 페르소나 빌더의 원본 편집 흐름을 다듬고 BardWiki 분석과 세이브가 멈추는 문제도 방지했습니다.

## [기능] BardWiki 플러그인 연동

- **기존 장기기억 플러그인 지원:** Hypa V3, Hypa V2 또는 Supa 장기기억 필드를 읽는 플러그인이 별도 수정 없이 BardWiki 문서와 설정된 범위의 최근 메시지를 받을 수 있습니다. 가상 장기기억은 플러그인 응답에서만 제공되며 실제 채팅 데이터에는 저장되지 않습니다.
- **BardWiki 플러그인 API:** 플러그인이 현재 채팅의 BardWiki 컨텍스트와 문서를 읽고, 별도 쓰기 권한을 받은 뒤 문서를 생성, 수정, 휴지통 이동할 수 있는 API와 개발자 레퍼런스를 추가했습니다.

## [편의성] 페르소나 빌더 원본 편집 개선

- **원본 이력 탐색:** 원본을 직접 수정하고 이전과 다음 버튼으로 원본 이력을 오갈 수 있습니다. 결과물을 페르소나에 복사하면 원본도 즉시 같은 내용으로 갱신됩니다.

## [성능] 프리셋 저장 경로 최적화

- **프리셋만 직접 저장:** 프롬프트 프리셋만 바뀐 저장은 해당 프리셋 파일과 목록만 갱신합니다. 이 경로가 실패하면 같은 저장 안에서 기존 전체 동기화로 자동 전환하며 `database.bin` 호환 저장도 계속 유지합니다.

## [안정성] BardWiki 분석과 정본 관리

- **분석 멈춤 방지:** BardWiki 분석 취소가 문서 읽기와 조회, 사건 및 정본 저장 요청까지 전달됩니다. 분석이나 수동 세이브 요청이 응답 없이 멈추면 10분 뒤 자동으로 종료되어 다시 시도할 수 있습니다.
- **아크 플롯 사건 탐색:** 아크 플롯이 새 사건 묶음을 반영할 때 대표 사건 링크가 빠진 결과를 저장하지 않고 다시 작성하도록 개선했습니다. 이미 링크 없이 저장된 플롯도 다음 확정 사건 분석에서 복구합니다.
- **사건 제목 보존:** 정본을 작성할 때 사건 문서의 제목을 줄이거나 바꾸지 않고 그대로 링크하도록 지시를 강화했습니다. 문장에 맞는 표현이 필요하면 실제 링크 대상은 유지하고 표시 이름만 분리합니다.

## [안정성] 세이브와 사이드바 설정 분리

- **현재 설정 유지:** 채팅을 세이브하거나 로드해도 현재 채팅의 페르소나와 프롬프트, 모델 모드, 주 모델과 보조 모델 프리셋 바인딩, 채팅별 프리셋 토글을 유지합니다. 기존 세이브에 들어 있는 설정도 로드할 때 덮어쓰지 않습니다.

## [안정성] 캐릭터 UI 버튼 클릭 개선

- **FAB 클릭 복구:** Firefox에서 캐릭터가 제공하는 FAB를 눌러도 간헐적으로 메뉴가 열리지 않던 문제를 해결했습니다.

## [호환성] 플러그인 설정 화면 개선

- **플러그인 화면 표시:** 일부 브라우저에서 플러그인 초기화가 막히거나 설정 화면이 열리지 않던 문제를 줄이도록 로딩 방식을 개선했습니다. iframe 스타일이 플러그인 화면의 열기와 닫기 요청을 덮어쓰지 않도록 수정했습니다.

## [시스템] 개인정보 없는 저장 진단

- **개발자 보고서:** 환경설정의 데이터 및 시스템 아래에 개발자 페이지를 추가했습니다. 저장 성능과 프리셋 직접 쓰기 결과를 확인하고, 이름이나 메시지, 경로와 식별자를 담지 않은 진단 보고서를 다운로드하거나 클립보드에 복사할 수 있습니다.
- **저장 결과 사전 검증:** 기존 저장 방식은 그대로 유지하면서 파일별 저장 결과가 같은 의미로 재구성되는지 백그라운드에서 검사합니다. 검사가 실패하거나 저장과 겹치면 사용자 세이브에는 영향을 주지 않고 진단 통계에만 반영됩니다.
- **저장 의미 보존:** 비어 있는 설정 객체와 비정상 채팅 ID, 메시지 필드가 없는 채팅도 파일별 저장 뒤 원래 세이브와 같은 형태로 복원합니다.
