# RisuBard v0.9.37

바드위키를 새 챗으로 이어가거나 선택한 항목만 파일로 옮길 수 있습니다. 위키 검색과 정리 속도를 개선하고, 재시작 후 저장 누락과 프리셋 편집 반영 문제를 수정했습니다.

## [기능] 위키 이어가기와 선택 이동

- **위키로 새 챗 시작:** `이 위키로 새 챗 시작`으로 메시지 내역 없이 기존 정본과 사건, 아크 플롯을 이어받아 대화를 시작할 수 있습니다. 새 챗에서도 같은 인물 정본을 계속 갱신하며 이전 챗의 원문은 포함하지 않습니다.
- **선택 내보내기와 들여오기:** 위키 항목을 클릭하거나 드래그해 선택한 뒤 파일로 내보내고, 파일 선택 또는 BardWiki에 드래그해 들여올 수 있습니다. 사건과 아크 플롯은 새 챗 시작으로만 이동하며 기존 항목과 충돌하는 들여오기는 덮어쓰지 않습니다.
- **도구 위치 정리:** `추가 분석` 옆의 `위키 도구` 메뉴에 리부트와 이동 도구를 모았습니다. `찾기/바꾸기`는 입력창 위 메인 리본의 돋보기로 옮겼으며 리본 숨기기는 환경설정에서 조절할 수 있습니다.

## [기능] 위키 검색 단서와 작중 시간

- **검색 키워드와 시간 기록:** 바드위키 사건과 정본에 검색 키워드와 작중 상대 시간을 기록하고 편집기에서도 표시합니다. 새 대화의 첫 확정 사건을 0일로 삼아 근거가 있는 시간 경과만 계산하며, 불명확한 시간은 미상으로 표시합니다.
- **행동 단서 검색:** 이름 없는 회상에서도 `춤` 같은 짧은 행동 단서를 검색하고, 아크 플롯의 관련 문장에 연결된 사건과 원문을 우선 회수하도록 개선했습니다.

## [편의성] 로어 항목 생성과 복제

- **그리모어 활성화 설정:** 오른쪽 활성화 규칙 위에 `숨김`과 `항상 활성화` 체크박스를 한 줄로 배치했습니다. 기존 `항상 필수` 규칙은 `항상 활성화`로 이름을 바꾸고 체크박스와 연동하며, 저장된 규칙은 그대로 호환됩니다.
- **편집 툴바 정리:** 새 로어, 새 폴더, 로어 복제, 항목 삭제, 가져오기, 내보내기를 목록 왼쪽 세로 아이콘 툴바에 모았습니다. `이동, 복제 및 삭제` 섹션을 없애고 숨김과 활성화 설정은 편집기 상단에 배치해 본문 편집 공간을 넓혔습니다.
- **선택 위치에 생성:** 로어북과 Grimoire 편집기에서 항목을 선택하고 `새 로어`를 누르면 같은 계층의 바로 아래에 새 항목을 만듭니다. `로어 복제`는 원본의 설정과 내용을 복사하고 이름에 다음 번호를 붙여 원본 바로 아래에 배치합니다.

## [UI] 바드위키 패널 배치

- **좁은 테마의 패널 표시:** Waifulike 등 폭이 제한된 테마에서도 바드위키가 채팅 칸 바깥의 독립 패널로 열리도록 수정했습니다. 위키 폭 조절은 전체 채팅 작업 영역을 기준으로 하며, 모바일에서는 작업 영역 위에 겹쳐 열립니다.

## [UI] 프리셋 모듈 활성화 표시

- **활성화 이유 표시:** 프롬프트 프리셋이 자동 활성화한 모듈은 모듈 목록의 글로벌 아이콘을 노란색 발광으로 표시합니다. 툴팁에서 활성화 이유를 확인할 수 있으며 수동 글로벌 설정은 별도로 유지됩니다.

## [안정성] 리롤 변수 상태 보존

- **상태 기반 리롤:** `재생성`과 swipe 전환 시 응답 스크립트가 바꾼 채팅 변수를 해당 후보의 상태로 함께 복원해, 리롤할 때마다 수치가 누적되는 문제를 해결했습니다.

## [안정성] 페르소나 바인딩 변경

- **페르소나 내용 보존:** 채팅에 바인딩된 페르소나와 전역 선택이 다를 때, 변경창을 열거나 다른 페르소나를 선택하면 이름, 이미지, 설명과 메모가 기존 페르소나 내용으로 덮어써질 수 있던 문제를 수정했습니다.

## [안정성] 저장 실패와 재시작 복구

- **저장 실패 후 재시도:** 통신 실패나 저장 보류 뒤 재시도할 때 프리셋 복제와 편집 등의 변경을 저장된 것으로 잘못 판단해 누락할 수 있던 문제를 수정했습니다. 실패 후에는 현재 상태를 전체 저장 경로로 다시 전송합니다.
- **재시작 후 저장 유지:** 서버가 시작할 때 자체적으로 정리한 사이드바 시각을 외부 파일 수정으로 오인하여 저장을 거부하거나 화면을 다시 불러올 수 있던 문제를 수정했습니다.
- **저장 충돌 처리:** 외부 파일 변경을 감지해도 자동으로 새로고침하거나 미저장 편집을 버리지 않습니다. 충돌 화면에서 현재 편집을 우선 저장하거나 미저장 편집을 내려받을 수 있습니다. 취소한 뒤에는 저장되지 않은 상태를 명시하고, 확인 없이 전체 저장으로 우회하지 않습니다.

- **캐릭터 복제 저장:** 개발 중 화면 갱신 뒤 남은 저장 루프가 현재 탭을 다른 탭으로 오인해 캐릭터 복제가 실패하던 문제를 해결했습니다.
- **외부 파일 수정 동기화:** 실행 중 캐릭터, 페르소나, 로어북 등 정본 파일을 외부에서 안전하게 수정하면 사이드바 인덱스와 호환 저장본을 자동으로 다시 맞춥니다. 누락되거나 오래됐거나 체크섬이 맞지 않는 사이드바 인덱스도 시작할 때 정본에서 복구합니다.

## [안정성] Docker 재시작

- **컨테이너 종료 시 잠금 정리:** Docker 종료 신호가 서버에 직접 전달되도록 수정해, 정상 종료 후 남은 저장소 잠금 때문에 다음 실행이 차단되는 문제를 해결했습니다. 종료 중에는 저장이 끝날 때까지 잠금을 유지합니다.

## [성능] 프리셋 저장 경로

- **프리셋 직접 저장:** 프리셋 편집과 함께 활성 선택이나 정리 설정이 바뀌어도 관련 설정과 프리셋 파일만 원자적으로 저장합니다. 캐릭터나 모듈 변경이 섞인 경우에는 기존 전체 동기화를 유지합니다.
- **편집 즉시 프리셋 반영:** 프롬프트 블록, 순서, 파라미터와 고급 설정 변경이 활성 화면에만 남지 않고 선택된 프리셋에도 바로 반영됩니다. 연속 입력은 기존 저장 대기 시간 동안 한 번으로 합쳐지며, 같은 지연 구조를 사용하던 테마 프리셋도 함께 수정했습니다.
- **저장 진단 정확도:** 값이 비어 있는 선택적 채팅 메타데이터 때문에 정상 저장이 파일 불일치로 집계되던 문제를 수정했습니다.

## [성능] 위키 정리 요청 통합

- **일반 정리 시간 단축:** 일반 위키 정리의 의미 분석과 정본 갱신을 AI 요청 2회에서 1회로 통합했습니다. 필요한 정본 전문이 없거나 수정안 검증에 실패하면 기존 갱신 경로로 보완하며, 위키 리부트와 아크 플롯 체크포인트 갱신은 기존 분리 경로를 사용합니다.
