# RisuBard v0.9.4

이번 버전은 **아카라이브 챗 저장기의 연속 붙여넣기를 더 쉽게 만드는 핫픽스**입니다.

## 아카라이브 챗 저장기 붙여넣기 핫픽스

- 챗을 추출하면 카드 바로 아래에 **빈 줄 1개를 자동으로 추가**합니다.
  - 아카라이브 게시판에 붙여넣은 뒤 별도로 줄을 만들 필요 없이, 생성된 빈칸에 다음 턴을 바로 이어 붙여넣을 수 있습니다.
  - 챗 카드 안의 본문, 이미지 순서와 기존 스타일은 그대로 유지됩니다.

## 채팅 위치 유지

- 이전 페이지나 과거 메시지를 보다가 환경설정에 들어간 뒤 돌아와도, 해당 캐릭터와 챗에서 보던 페이지와 스크롤 위치를 복원합니다.
  - 더 이상 화면 복귀 시 최신 페이지 최하단으로 강제 이동하지 않습니다.
