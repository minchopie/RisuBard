# RisuBard v0.9.41

전체 캐릭터의 V3 시험 전환과 외부 파일 편집 자동 반영을 지원하고, 에셋이 많은 환경의 재시작 후 저장 지연을 줄였습니다. 스트리밍 중 읽던 위치를 안정화하고 바드위키 검색과 갱신을 보강했습니다.

## [기능] 전체 캐릭터 V3 시험 전환

- **전체 전환과 재개:** 개발자 설정에서 삭제되지 않은 캐릭터를 하나씩 전환합니다. 이미 전환된 캐릭터는 건너뛰고, 실패한 대상과 에셋 검증은 다시 실행할 때 재시도합니다.
- **진행 확인과 중단:** 캐릭터별 처리 결과를 확인하고 중단할 수 있습니다. 화면을 나가면 진행 중 요청까지만 처리하며, 다시 실행하면 서버에 저장된 상태를 확인해 이어갑니다. 기존 캐릭터별 되돌리기도 사용할 수 있습니다.
- **전환 범위:** 공유 에셋, 바드위키와 모듈의 위치 및 기존 백업 형식은 유지합니다. 시험 전환 전에는 백업을 보관해 주세요.
- **신규 캐릭터 V3 기본 배치:** 새로 생성하거나 새 ID로 가져온 캐릭터는 처음부터 이름 기반 V3 폴더에 저장합니다. 기존 캐릭터와 전체 백업 복원의 구조는 유지합니다. 앱에서 추가하거나 교체하고 제거한 에셋도 V3 폴더에 반영하며, 제거한 복사본은 휴지통에 보관합니다. 공유 에셋 원본과 다른 캐릭터의 표시는 유지합니다.

## [기능] 외부 파일 편집 자동 반영

- **설명과 로어북:** 캐릭터 `metadata.json`의 설명과 로어북, 전역 로어북 JSON을 외부 편집기로 저장하면 열린 앱에 자동 반영됩니다. 파일 감시 알림이 누락돼도 동기화 요청에서 메타데이터 변경을 확인해 편집 내용과 잘못된 JSON을 감지합니다.
- **에셋 폴더:** 캐릭터의 `assets` 폴더에 파일을 추가하거나 교체하고 제거하면 해당 캐릭터의 에셋 참조와 표시도 갱신됩니다. 새 파일은 추가 에셋으로 등록됩니다.
- **채팅별 로어북 삭제 수정:** 채팅 폴더의 `metadata.json`에서 `localLore`를 비우거나 항목을 삭제하면 열린 채팅에도 바로 반영합니다. 채팅 메타데이터를 외부에서 저장할 때 무결성 오류로 읽기가 막히던 문제와, 파일 저장 직후의 짧은 대기 상태가 `getItem Error`로 표시되던 경로를 수정했습니다. 기존 ID 구조와 V3 모두 적용되며 메시지와 스트리밍 상태는 유지합니다.
- **편집 내용 보호:** 진행 중인 채팅과 다른 항목의 앱 편집을 유지합니다. 같은 항목이 충돌하면 외부 파일을 적용하고 앱의 값을 복구 기록에 보존합니다. 잘못된 JSON은 알림 후 수정될 때까지 저장과 새 전송을 보류합니다.
- **동시 편집과 재시도 강화:** 서버가 수신한 앱 편집과 외부 편집이 겹쳐도 앱 수정본을 서버 복구 파일에 보존합니다. 반영 중 저장 실패나 서버 재시작이 발생하면 미완료 반영을 다시 시도하며, 복구 기록은 전체 백업에도 포함됩니다. V3 전환 후 대표 이미지 수정이 추가 에셋으로 잘못 등록되는 문제도 수정했습니다.

## [편의성] 바드위키 설정을 봇에 고정

- **현재 챗 설정을 봇에 고정:** `이 봇에 고정`을 체크하면 현재 바드위키 옵션을 같은 봇의 기존 챗과 새 챗에서 공통으로 사용합니다. 고정 중 변경한 값도 함께 반영되며, 해제하면 현재 챗의 값은 유지하고 다른 챗은 기존 개별 설정으로 돌아갑니다.

## [편의성] Realm에서 모듈 바로 가져오기

- **모듈 가져오기:** 캐릭터 설명에 Proton Drive 공유 링크가 하나 있으면 다운로드 버튼 옆에서 모듈을 바로 가져올 수 있습니다. 단일 `.risum` 파일은 진행률을 표시하며 다운로드 후 자동으로 임포트하고, 폴더나 다른 파일 및 비밀번호가 필요한 링크는 원본 열기를 안내합니다. 설명의 기존 링크도 그대로 사용할 수 있습니다.

## [UI] 사이드 네비게이터 위치 조절

- **사이드 네비게이터 위치 개선:** 이동 버튼의 너비를 절반으로 줄이고 화면 중앙 높이에 배치했습니다. 환경설정의 환경 > 접근성 > 스크롤에서 `사이드 네비게이터를 고정` 바로 아래의 `네비게이터 위치 오프셋 (px)`으로 위아래 위치를 조절할 수 있습니다.

## [안정성] 스트리밍 중 읽던 내용과 위치 유지

- **본문과 그림 유지:** 응답 생성 중 이미 표시한 글, 이미지와 인레이를 유지하고 변경된 부분을 갱신해 화면이 덜컥거리거나 그림이 다시 나타나는 현상을 줄였습니다.
- **읽던 문단 위치 유지:** `콘텐츠 갱신 중 읽던 위치 유지`를 켜면 긴 메시지에서도 읽던 문단이나 그림을 기준으로 위치를 보정합니다. 직접 스크롤한 새 위치를 유지하며, 출력 완료와 후처리 시에도 메시지 맨 위로 돌아가지 않도록 개선했습니다.

## [안정성] 바드위키 갱신과 명령 처리

- **메시지의 정본 변경 기록 유지:** 같은 턴을 추가 분석하거나 재분석했을 때 새 변경이 없다는 이유로 이전 갱신 목록이 사라지는 문제를 수정했습니다. 이미 반영한 문서는 유지하고 같은 문서의 후속 변경은 최신 결과로 합칩니다.
- **2턴 리부트의 사건 링크 수정:** 여러 사건을 한 줄로 요약할 때도 각 사건 문서의 링크를 따로 유지하도록 개선했습니다. 두 제목이 하나의 링크로 묶인 경우, 실제 문서와 충돌하지 않고 각 대상을 확실히 식별할 수 있으면 저장 전에 개별 링크로 보정합니다.
- **BARDCHAT 명령 응답 복구:** AI가 버전 번호를 문자열로 반환하거나 본문 문자열 안에 실제 개행과 탭을 넣어도 제한적으로 복구한 뒤 명령 전체를 검증합니다. 잘린 응답과 잘못된 명령은 저장하지 않으며, JSON 형식 오류를 출력 토큰 부족으로 안내하지 않습니다. 재시도에도 구체적인 검증 오류와 문자열 작성 규칙을 전달합니다.
- **위키 이름 변경 저장:** 이름 변경 뒤 서버가 정리한 본문과 저장 상태를 즉시 반영해, 다시 저장할 때 충돌 오류가 나는 문제를 수정했습니다. 다른 변경과 실제로 충돌하면 편집 내용을 유지하고 복구 방법을 안내합니다.
- **인물 최초 등록 누락 보완:** 확정 대화에 이름이 나오고 분석에서 지식이 기록된 인물이 정본 생성 후보에서 빠지면 기존 검증과 저장 경로로 보완합니다. 기존 이름과 별칭으로 등록된 인물은 중복 생성하지 않습니다.

## [안정성] 바드위키 검색 근거 보강

- **기억의 맥락 보존:** 긴 문서에서 근거를 발췌할 때 상위 제목을 함께 유지해 소문, 추측, 과거 기록이 확정 사실이나 현재 상태처럼 전달되는 경우를 줄였습니다. 인물의 과거 기록 아래에 있는 하위 절도 같은 과거 기록으로 구분합니다.
- **현재 상태와 회상 근거 함께 전달:** 일반 장면 진행에서 인물의 과거 문단이 의미 검색에 잡혀도 현재 상태를 함께 제공하도록 보강했습니다. 검색된 근거를 먼저 보존하고 기존 자료별 토큰 상한의 남는 공간에 현재 상태를 보충하며, 명시적인 과거 회상은 검색 근거를 우선합니다.
- **선택형 바드짱 재정렬 보완:** 임베딩 점수가 재정렬 순서를 뒤섞는 문제를 수정하고, 실제 전달한 후보만 재정렬 결과로 인정합니다. 바드짱을 켠 경우 기존 제외 설정을 따른 최근 문맥을 최대 1,024자 참고해 지시어 해석을 돕습니다. 호출 횟수와 기본 꺼짐 설정은 유지합니다.
- **본문 근거 우선:** 제목만 있는 조각이 실제 사건이나 인물 상태 본문을 대신해 검색되는 경우를 줄였습니다. 제목은 본문의 검색 맥락으로 유지하며, 기존 본문 임베딩 캐시는 재사용합니다.

## [안정성] 업데이트 시 개인 파일 보존

- **설치 폴더에 추가한 자료 보존:** 배치 업데이터와 Unix 업데이트가 설치 폴더 전체를 정리하던 문제를 수정했습니다. 새 배포에 포함된 항목만 교체하며, 설치 폴더 바로 아래에 별도로 추가한 폴더와 파일은 유지합니다. `save`, `backups`와 사용자 설정 파일도 보존합니다.
- **기존 버전에서 처음 업데이트할 때:** 교체 작업은 기존 업데이터가 실행하므로 새 버전을 받는 것만으로 첫 업데이트가 보호되지는 않습니다. 기존 업데이터를 먼저 수정본으로 교체하거나, 새 버전을 별도 폴더에 설치해 주세요. `server`, `dist`, `node_modules` 등 프로그램 폴더 내부는 교체 대상입니다.

## [성능] V3 저장과 시작 지연 개선

- **재시작 후 저장 지연 수정:** 에셋이 많은 V3 캐릭터가 있을 때 재시작이나 인덱스 재로딩 뒤 저장이 수십 초 멈추며 바드위키 조회도 지연되던 문제를 수정했습니다. 변경 없는 에셋은 기존 검증 결과를 재사용하고, 외부 편집과 새 파일 및 삭제 전 충돌 검증은 유지합니다.
- **시작 지연 수정:** 이전 V3 전환에서 남은 미등록 에셋 복사본을 새 파일로 오인해 시작 화면에서 오래 대기하던 문제를 수정했습니다. 실제 새 에셋도 묶어서 등록해 파일마다 전체 저장 색인을 다시 쓰지 않습니다.

## [성능] 바드위키 검색 처리 경량화

- **검색 처리 경량화:** 같은 문서의 여러 문단 중 가장 관련 있는 근거를 먼저 고른 뒤 정렬해 불필요한 정렬을 줄였습니다. 추가 AI 호출 없이 기존 검색 점수, 후보 수와 컨텍스트 토큰 상한을 유지합니다.

## [호환성] Windows 별칭 경로의 외부 편집 감시

- **별칭 경로 시작 오류 수정:** Windows의 짧은 별칭 경로에 사용자 데이터를 둘 때 파일 감시기 내부 오류로 서버가 종료될 수 있는 문제를 수정했습니다. 실제 경로를 확인한 뒤 감시를 시작합니다.

## [시스템] 저장 진단의 현재 상태 구분

- **현재 실행과 누적 기록 분리:** 저장 진단 파일에서 현재 서버 실행의 결과와 과거 누적 기록을 구분합니다. 이전 버전에서 발생한 오류가 현재 실행의 오류로 합산되지 않으며, 과거 기록은 `history`에 보존합니다.
