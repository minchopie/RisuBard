# RisuBard v0.9.42

기기 전환 시 미저장 대화를 보호하고, 위키 정본 갱신 실패의 자동 복구를 보강했습니다. 저장과 배포에 영향을 주는 변경을 릴리스 전에 확인하는 검증 절차도 추가했습니다.

## [안정성] 기기 전환 시 미저장 대화 보호

- **새로고침 전 확인:** 다른 탭이나 기기로 저장 권한이 넘어가도 자동으로 새로고침하지 않습니다. 저장 중단을 알리고 미저장 편집을 JSON으로 내려받을 수 있으며, 최신 내용으로 다시 불러오기는 별도 확인 후 진행합니다. 응답 생성이나 저장이 진행 중일 때는 다시 불러오기를 막습니다.
- **저장 중단 안내:** 기기 충돌을 알리지 않은 채 저장만 반복하던 문제를 수정했습니다. 중단된 창에서는 새 응답 전송을 막고, 수동 새로고침이나 창 닫기에도 브라우저의 이탈 확인을 요청합니다.
- **느린 응답 처리:** 사용자 입력 후 응답이나 연결이 오래 걸려도 해당 창의 조작 여부를 유지해, 휴대폰 저장이 자동 작업으로 오인되는 경우를 줄였습니다.

## [안정성] 위키 정본의 중복 절 자동 복구

- **정본 갱신 실패 복구:** 기존 인물 문서 등에 `Current State` 같은 절 제목이 중복되어 갱신이 계속 실패하던 문제를 수정했습니다. 중복 절의 본문을 보존해 하나로 모은 뒤 갱신하며, 해당 절을 교체하거나 삭제하는 변경은 중복 절 전체에 적용합니다.
- **문서별 복구:** 기존 문서의 구조를 먼저 점검하고, 여러 문서의 갱신안 중 잘못된 항목만 다시 요청합니다. 한 문서가 실패해도 검증된 다른 문서의 변경은 반영합니다.
- **반복 실패 방지:** 정해진 응답 복구 횟수를 소진하면 원본을 보존하고 해당 문서의 같은 입력에 대한 자동 재시도를 중단합니다. 다른 문서를 재시도할 때도 이미 저장했거나 복구를 중단한 문서는 다시 요청하지 않으며, 원문이나 문서가 바뀌면 다시 처리합니다. 활동 내역에서 대상과 원인을 확인한 뒤 추가 분석을 실행할 수 있습니다. 네트워크 오류와 저장 충돌의 재시도 및 기존 저장 검증은 유지합니다.

## [안정성] 변경 단계의 저장 및 배포 검증

- **운영체제별 조기 확인:** 저장 경로를 변경하면 Windows와 Linux에서 외부 편집 반영, 저장 충돌과 불필요한 에셋 읽기 회귀를 미리 확인합니다.
- **배포 입력 누락 확인:** 의존성이나 배포 구성을 변경하면 포터블 설치와 Docker 의존성 빌드를 확인해, 릴리스 때 필요한 파일이 빠지는 문제를 더 일찍 찾습니다.
