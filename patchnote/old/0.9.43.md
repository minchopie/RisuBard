# RisuBard v0.9.43

바드페인터로 대화 속 장면을 삽화로 만들고 관리할 수 있습니다. 대용량 채팅 저장과 페이지별 턴 이동 오류를 수정하고, 바드챗 컨텍스트 메뉴를 개선했습니다.

## [기능] 바드페인터: 대화 속 장면을 삽화로

원하는 장면을 골라 NovelAI V5로 삽화를 만들고 본문에 넣을 수 있습니다. 바드위키의 OOC 메모장 왼쪽에 있는 바드페인터에서 시작하세요.

- **화풍과 인물 준비:** 상단의 `화풍`, `캐릭터`, `생성 설정`에서 그림의 스타일과 참고할 정보를 정합니다. 인물별 외형과 의상을 프리셋으로 저장해 재사용하고, 의상은 현재 챗 전용 또는 봇 공용으로 관리할 수 있습니다.
- **장면 선택과 프롬프트 작성:** 본문에서 그리고 싶은 구간을 드래그한 뒤 `프롬프트 작성`을 누르면 AI가 해당 장면의 프롬프트를 만듭니다. 프롬프트 대화로 원하는 방향을 요청하거나 초안을 다듬을 수 있습니다.
- **확인 후 이미지 생성:** 메인 프롬프트와 인물별 블록을 확인하고 필요하면 직접 수정한 뒤 `이미지 생성`을 누르세요. 생성된 그림은 원본 해상도를 유지한 WebP로 압축해 저장합니다.
- **본문에 삽화 넣기:** `위에 삽입`과 `아래에 삽입`으로 선택한 구간 앞뒤에 넣거나, `지정 삽입`을 누르고 본문을 클릭해 가까운 문단 사이에 넣을 수 있습니다. 텍스트 선택을 해제해도 삽입 위치는 기억합니다.
- **그림 갤러리에서 관리:** 왼쪽 `캐릭터 디스플레이 > 그림 갤러리`에서 모든 그림을 챗별로 찾아보고, 확대하거나 생성 프롬프트를 복사할 수 있습니다. 챗을 삭제해도 그림은 `삭제한 챗` 분류에 남으며, 필요하면 갤러리에서 분류별로 일괄 삭제할 수 있습니다.
- **다음 삽화에 외형 참고:** 갤러리에서 그림을 확대한 뒤 `참고 삽화 지정`을 누르면 현재 챗의 다음 프롬프트 작성에 외형과 의상 정보를 참고합니다. 지정한 그림은 `생성 설정`에서 확인하거나 `비우기`로 해제할 수 있습니다.

## [UI] 바드챗 컨텍스트 메뉴

- **누르기 쉬운 컨텍스트 선택:** 항목과 체크박스를 넓히고 글씨를 키웠습니다. 아래 공간이 부족하면 위로 열리며, 작은 화면에서는 메뉴 안에서 스크롤해 모든 항목을 선택할 수 있습니다.

## [안정성] 대용량 채팅 저장

- **큰 채팅 저장과 불러오기:** 긴 채팅 전체를 하나의 문자열로 만들다가 `Invalid string length` 오류로 서버 저장이 중단되던 문제를 수정했습니다. 메시지별로 나눠 기록하고 읽으며, 기존 저장 검증과 중단 후 복구 절차를 유지합니다.

## [안정성] 플러그인 응답 처리

- **플러그인 응답 전달:** 플러그인에 전달할 데이터를 복사할 때 큰 문자열을 생성하지 않도록 개선했습니다. 복사에 실패해도 채팅 응답의 나머지 후처리가 중단되지 않도록 했습니다.

## [안정성] 페이지와 턴 이동

- **정확한 턴 이동:** 다른 페이지의 턴으로 점프할 때, 본문이 뒤늦게 표시되면서 지정한 턴 대신 페이지 중간으로 이동하던 문제를 수정했습니다.
