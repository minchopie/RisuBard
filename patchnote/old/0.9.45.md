# RisuBard v0.9.45

바드페인터에 태그 자동완성과 가중치 표시를 추가하고, 생성 설정을 봇별로 고정하거나 전역 기본값으로 공유할 수 있게 했습니다. 외부 이미지 본문 삽입과 작업 정리를 개선하고, Pagefold 등 플러그인의 JSON 응답 호환 문제를 수정했습니다.

## [기능] 프롬프트 태그 자동완성과 가중치 표시

- **Danbooru 태그 자동완성:** 바드페인터의 프롬프트, 프리셋 편집창과 프롬프트 대화 입력창에서 로컬 태그 후보를 검색하고 방향키, Enter, Tab 또는 클릭으로 삽입합니다. 한국어와 일본어 별칭은 정규 태그로 입력되며 가중치와 주변 태그를 보존하고 실행 취소를 지원합니다.
- **자동완성 설정:** 화면 설정의 기타 탭이나 단축키 설정에서 사용 여부, 최소 글자 수, 커서 왼쪽 또는 태그 전체 치환과 전용 단축키를 변경할 수 있습니다. 자동완성 후보 선택과 IME 조합 입력 중에는 프롬프트 요청이 함께 전송되지 않습니다.
- **프롬프트 가중치 표시:** NovelAI 가중치가 높으면 붉게, 낮으면 푸르게 배경을 표시합니다. 숫자 가중치와 중괄호 및 대괄호 강조를 지원하며 강도에 따라 색이 진해집니다.

## [기능] 외부 이미지 본문 삽입

- **이미지 지정 삽입:** 메시지 입력창 왼쪽 메뉴의 `파일 업로드` 아래에 `이미지 삽입`을 추가했습니다. 파일을 선택한 뒤 본문의 원하는 위치를 왼클릭하면 삽입되고, Esc나 우클릭으로 취소할 수 있습니다. 삽입한 이미지는 해당 캐릭터의 `그림 갤러리`에도 표시됩니다.
- **삽입 위치선 유지:** 삽입 모드 진입 시 자동 스크롤이나 이미지 로딩, 창 크기 변경으로 위치선이 사라지던 문제를 수정했습니다. 선택한 본문 위치를 유지하면서 선의 화면 좌표를 갱신합니다.

## [편의성] 바드페인터 생성 설정 공유

- **봇 고정과 전역 기본값:** 생성 설정에 `이 봇에 고정`, `전역값으로 설정`, `전역값 사용`을 추가했습니다. 모델, 이미지 크기, 시드와 참고 자료 옵션을 공유하며, 요청문과 화풍, 선택한 위키 항목과 참고 그림은 현재 챗에서 유지합니다. 기존 챗의 개별 설정도 보존합니다.

## [편의성] 바드페인터 작업과 그림 정리

- **작업 리셋:** `화풍` 왼쪽의 `리셋`으로 그릴 장면, 초안, 프롬프트 대화와 현재 그림 표시를 초기화할 수 있습니다. 생성 설정과 프리셋, 갤러리 이미지와 본문에 삽입한 그림은 유지됩니다.
- **프롬프트 원문 복사:** `프롬프트 초안` 옆의 `원문 카피`로 메인 블록, 화풍과 추가 표현, 인물 블록과 네거티브 프롬프트를 한 번에 복사합니다. 설정이나 메타정보 없이 프롬프트만 줄을 나눠 복사합니다.
- **프롬프트 대화 비우기:** `프롬프트 대화` 제목 옆의 `대화 비우기`로 현재 챗의 바드페인터 대화 기록만 삭제할 수 있습니다. 선택한 장면, 초안, 생성한 삽화와 프리셋은 유지됩니다.
- **갤러리 개별 삭제:** 그림 카드 오른쪽 위의 휴지통 버튼으로 확인창 없이 해당 그림을 삭제할 수 있습니다. 본문에 삽입한 같은 그림과 관련 생성 기록, 참고 삽화 지정도 함께 정리합니다.

## [UI] 바드페인터 선택과 프리셋 편집

- **그릴 장면 선택 버튼:** `그릴 장면` 영역에 선택 버튼을 항상 표시합니다. 현재 챗의 본문을 드래그하면 활성화되며, 기존 초안의 장면을 바꿀 때는 확인을 거칩니다.
- **프리셋 원문 붙여넣기:** 캐릭터나 의상을 선택해도 기존 프롬프트를 자동으로 덮어쓰지 않습니다. 각 드롭다운 오른쪽의 정사각형 붙여넣기 아이콘으로 마지막 커서 위치에 원문을 넣거나 선택한 텍스트만 교체합니다. 반복 설명을 제거해 인물 편집창을 간소화했습니다.
- **도구 버튼 구분:** `화풍`, `캐릭터`, `생성 설정` 버튼을 강조 스타일로 표시합니다.

## [안정성] 바드페인터를 연 상태에서 채팅 전환

- **채팅 전환 오류 수정:** 바드페인터를 열어 둔 채 다른 봇이나 채팅으로 이동할 때 `이 챗을 먼저 열어 주세요.` 오류가 뜨던 문제를 수정했습니다. 채팅을 불러오는 동안 대기 화면을 표시하고, 로딩이 끝나면 바드페인터가 자동으로 열립니다.

## [호환성] 플러그인 JSON 응답 처리

- **JSON 이스케이프 복구:** Pagefold 등 플러그인이 JSON 문자열의 줄바꿈 이스케이프를 실제 줄바꿈으로 바꿔 응답을 읽지 못하던 문제를 리스바드 공통 응답 처리에서 보완했습니다. 바드페인터와 바드위키 등 JSON 사용 기능에 적용되며 스트리밍 완료 응답도 처리합니다.
- **기존 응답 보존:** 정상 JSON과 일반 문장은 유지하며, 잘린 응답이나 다른 문법 오류는 임의로 복구하지 않습니다.
