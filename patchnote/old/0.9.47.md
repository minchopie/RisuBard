# RisuBard v0.9.47

백업을 반복 복원할 때 봇과 프리셋이 누락되거나 재시작이 실패하던 문제를 수정했습니다. 바드페인터의 장면 분석을 개선하고 프리셋 카드 첨부 선택 기능을 추가했으며, 이미지 저장 대기를 줄였습니다.

## [기능] 바드페인터 장면 분석

- **장면 계획:** AI가 등장인물, 인물 사이의 행동, 화면 배치, 자세와 표정, 카메라를 구분해 분석하고, 앱이 이를 장면과 인물별 프롬프트로 조립합니다.
- **구체적인 연출:** 장소, 구도, 시선과 행동에 짧은 자연어 설명을 사용할 수 있어 복잡한 장면을 더 구체적으로 지시할 수 있습니다.
- **생성 문구 편집:** 장면 분석 결과로 만든 문구는 기존 프롬프트 입력창에서 그대로 수정할 수 있습니다.

## [기능] 바드페인터 프리셋 첨부

- **첨부 선택:** 캐릭터 프리셋과 봇 공용 의상에 `봇에 첨부` 체크박스를 추가했습니다. 기본값은 미첨부이며, 체크 후 저장하면 CHARX 파일을 내보낼 때 함께 포함됩니다. 의상은 해당 인물의 외형도 첨부로 선택해야 합니다.
- **일괄 설정:** `모든 항목 첨부`와 `모든 항목 미첨부` 버튼으로 외형과 봇 공용 의상을 한 번에 설정할 수 있습니다.

## [안정성] 전체 백업 복원

- **체크섬 오류 수정:** 앱이 생성한 내부 검사 파일을 이미지로 백업하던 문제를 수정했습니다. 이미 해당 파일이 포함된 백업도 내부 검사 파일을 제외하고 복원합니다.
- **반복 복원 누락 수정:** 같은 설치에 백업을 다시 가져올 때 봇과 프리셋이 누락되거나 진단 로그 충돌로 복원이 실패하던 문제를 수정했습니다. 폴더 매핑 누락으로 재시작이 실패하던 원인도 함께 해결했습니다.
- **중단 후 복구 개선:** 백업 복원 도중 종료된 경우 이미 이동한 폴더를 다시 이동하려다 복구가 막히지 않도록 수정했습니다. 이전 버전에서 이미 누락된 데이터는 정상 백업으로 다시 복원해야 합니다.

## [안정성] 구형 채팅 실시간 동기화

- **동기화 오류 수정:** ID가 없는 구형 채팅이 남아 있을 때 실시간 파일 동기화에서 `Legacy chat ID migration required` 오류가 발생하던 문제를 수정했습니다. 기존 대화 내용과 정상 로딩 시의 호환 처리는 유지됩니다.

## [성능] 바드페인터 이미지 저장

- **생성 대기 단축:** 생성 전 저장 대기와 PNG 원본의 중간 저장을 없애고, 생성한 이미지를 WebP로 변환한 뒤 최종 저장을 한 번만 확인하도록 개선했습니다. 저장 실패 시에는 이미 완료한 변환과 업로드를 반복하지 않고 이어서 재시도합니다.
