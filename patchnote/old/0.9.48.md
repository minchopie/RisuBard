# RisuBard v0.9.48

바드위키가 인물 정보를 놓치던 문제를 수정하고, 위키가 답변에 포함되지 않은 이유를 로그에서 확인할 수 있게 했습니다. 바드페인터의 장면 선택과 이미지 관리를 개선했으며, Termux에서는 외부 파일 자동 감지를 기본으로 꺼 파일 감시 부담을 줄였습니다.

## [편의성] 바드페인터 기본 화풍과 생성 설정

- **기본 화풍 지정:** 자주 쓰는 화풍을 기본으로 지정할 수 있습니다. 새 채팅에서 바드페인터를 처음 사용할 때 적용되며, 기존 채팅에서 선택한 화풍은 유지됩니다.
- **현재 설정 확인:** `그림 만들기` 화면에서 선택한 화풍 이름과 이미지의 가로형, 세로형, 정사각형 구분을 바로 확인할 수 있습니다.

## [편의성] 채팅 본문에서 이미지 삭제

- **이미지 삭제 버튼:** 본문에 삽입된 이미지에 마우스를 올리면 삭제 버튼이 나타납니다. 모바일에서는 버튼이 항상 표시되며, 본문에서만 제거하고 원본 이미지 파일은 보존합니다.

## [UI] 메시지 크기 안내

- **본문과 전체 크기 구분:** 메시지 정보에 `본문 크기`와 `메시지 전체 크기`를 나누어 표시합니다. 전체 크기에는 저장된 프롬프트와 번역 기록 등의 부가 정보가 포함되며, AI에 보내는 토큰 수와는 다릅니다.

## [안정성] 바드위키 인물 검색과 조회 진단

- **이름을 생략한 대화의 검색 복구:** 활성 캐릭터 로어의 이름 정보가 위키 검색에 전달되지 않던 문제를 수정했습니다. 대화에서 이름을 반복하지 않거나 `이 위키로 새 챗 시작`을 사용한 경우에도 이 정보를 검색 단서로 활용합니다.
- **위키 누락 원인 확인:** 새 응답의 로그와 내보낸 보고서에서 검색 대상, 후보, 선택한 위키와 프롬프트에 포함된 수를 확인할 수 있습니다. 검색 결과가 없는 경우와 조회 실패, 프리셋 적용 과정에서 내용이 변경되거나 빠진 경우를 구분합니다.
- **조회 오류 안내:** 서버 오류가 발생하면 필수 위키의 문서 수 또는 토큰 상한 초과, 문서 형식 오류, 파일 읽기 실패 등 확인 가능한 원인을 표시합니다. 새 진단은 응답에 저장되며, 보고서에 위키 본문이나 서버의 절대경로는 포함하지 않습니다.

## [안정성] 채팅 전송 준비와 재시도

- **중복 전송 방지:** 입력 번역이나 전송 준비 중에는 진행 상태를 표시하고 중복 전송을 막습니다. 입력 처리에 실패해도 작성한 내용은 남아 있어 다시 시도할 수 있습니다.
- **동기화 대기 취소:** 전송 전 파일 동기화를 기다리는 동안 취소할 수 있습니다. 30초가 지나면 안내 후 다시 시도할 수 있으며, 취소하거나 다른 채팅으로 이동한 요청이 뒤늦게 전송되지 않도록 했습니다.
- **읽던 위치 유지:** 메시지를 보낼 때 화면이 직전 답변의 첫 줄로 튀는 문제를 수정했습니다.

## [안정성] 바드페인터 장면 선택

- **선택한 본문 반영:** 본문 끝까지 드래그하거나 선택 직후 버튼을 눌렀을 때 이전 장면이 남는 문제를 수정했습니다. 선택 범위에 걸친 편집 버튼 등의 문구는 장면에서 제외합니다.

## [호환성] PageFold Gemini 위키 분석

- **분석 재시도 지연 완화:** PageFold Gemini의 Vertex와 OpenRouter 연결에서 출력 형식 거부로 위키 분석을 재시도하던 과정을 줄였습니다. 분석 결과는 계속 검증한 뒤 위키에 저장합니다.

## [성능] 외부 파일 변경 자동 감지

- **Termux 기본값 변경:** Termux에서는 외부 파일 변경 자동 감지를 기본으로 끕니다. 일반 채팅과 저장은 그대로 사용할 수 있으며, 외부 편집기로 바꾼 파일을 자동 반영하려면 `설정 > 개발자 > 외부 파일 변경 자동 감지`를 켜 주세요.
- **필요할 때 동기화:** 변경 여부를 짧은 간격으로 계속 확인하던 방식을 서버의 변경 알림 방식으로 바꿨습니다. 감지가 켜져 있으면 주기적인 누락 확인과 연결 복구 시 동기화도 함께 수행합니다.
- **서버별 설정 유지:** 자동 감지 설정은 재시작 후에도 유지되며, 같은 서버에 연결된 다른 화면에도 적용됩니다.
