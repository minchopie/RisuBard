# RisuBard v0.9.5

이번 버전은 **BardWiki 분석·리부트의 가시성과 안정성, 확정 채팅 이력 관리, 외부 파일 편집 보호와 환경설정 동선 정리**에 초점을 맞췄습니다.

## BardWiki AI 분석 출력 한도

- 사건 분석과 위키 리부트에 고정되어 있던 4,096토큰 출력 한도를 제거했습니다.
- 이제 환경설정의 `AI 분석 토큰 상한`이 사건 분석·리부트·정본 재작성 요청의 입력과 출력에 함께 적용됩니다.
- 기본 상한을 8,192토큰으로 조정했으며, 사용하는 모델의 컨텍스트와 출력 한도에 맞춰 환경설정에서 더 크게 지정할 수 있습니다.

## 확정된 과거 메시지 삭제

- BardWiki 사건에 이미 반영되어 확정된 과거 메시지도 채팅에서 삭제할 수 있습니다.
- 삭제 확인창에 실제로 삭제될 메시지 수를 표시합니다.
  - 한 개를 삭제할 때도 `1개`라고 명시합니다.
  - 특정 지점부터 이후 메시지를 삭제할 때는 연쇄 삭제되는 전체 개수를 표시합니다.
- 삭제되는 메시지에 연결된 활성 사건 요약은 채팅을 지우기 전에 함께 삭제 처리합니다.
  - 사건 요약 삭제에 실패하면 채팅 삭제도 중단하여 서로 다른 상태가 남지 않도록 했습니다.
  - 삭제 범위가 길어도 연결된 메시지를 누락하지 않고 확인합니다.
- 인물·장소·아이템 등 사건 외 정본 문서는 자동으로 과거 상태로 되돌리지 않으며, 정확한 시점으로 다시 맞추려면 BardWiki 리부트가 필요하다는 안내를 확인창에 표시합니다.

## BardWiki 리부트 진행률

- 리부트 중 BardWiki 상단에 진행 막대를 표시합니다.
- 완료한 턴 수와 전체 처리 턴 수, 퍼센티지를 `2/10턴 · 20%` 형식으로 함께 표시합니다.
- 각 턴의 처리가 끝날 때마다 진행률을 갱신하며, 일시정지 중에는 현재 진행 상태를 그대로 유지합니다.
- 진행 막대는 화면 읽기 도구와 모션 감소 설정을 지원합니다.

## BardWiki 끊어진 링크 표시

- 끊어진 `[[링크]]`가 있는 문서를 파일 트리에서 빨간색으로 표시합니다.
- 건강도에 표시되는 끊어진 링크 수와 함께 문제가 있는 문서를 바로 찾을 수 있습니다.
- 진단 결과가 위키 원문을 자동으로 수정하거나 임의의 문서에 연결하지는 않습니다.

## BardWiki 편집기 도구 모음 정리

- `저장`, `되돌리기`, `삭제` 버튼에서 텍스트 라벨을 제거하고 아이콘만 표시합니다.
  - 각 버튼의 설명과 접근성 이름은 유지합니다.
- 기존 `모두 바꾸기` 버튼의 이름을 `찾기/바꾸기`로 변경했습니다.
- `찾기/바꾸기` 버튼을 편집기 내부 도구 모음에서 BardWiki 상단의 `추가 분석` 버튼 오른쪽으로 옮겼습니다.

## RisuBard 환경설정 통합

- 별도로 나뉘어 있던 RisuBard 공통 설정과 채팅 설정을 하나의 공통 설정 화면으로 통합했습니다.
- 설정 항목을 `채팅 응답`, `BardWiki 분석`, `BardWiki 집필`, `저장 및 불러오기` 순서로 정리했습니다.
- 기존 채팅 설정 링크와 설정 검색 결과도 통합된 공통 설정 화면으로 연결됩니다.
- AI 설정에서 페르소나 관리 바로가기를 가장 먼저 찾을 수 있도록 배치했습니다.

## 외부 파일 편집 보호

- RisuBard가 사용하는 정본 데이터 파일을 앱 밖에서 수정한 경우 변경 내용을 감지합니다.
- 유효한 외부 변경이 있으면 오래된 앱 메모리로 파일을 덮어쓰지 않고, 최신 파일 내용을 반영한 뒤 화면을 새로고침합니다.
- 외부 변경을 반영했을 때는 최신 파일을 유지했다는 알림을 표시합니다.
- 형식이 잘못되었거나 검증에 실패한 외부 데이터는 정본으로 반영하지 않습니다.
- 백업에서 함께 복원된 정본 파일을 외부 충돌로 잘못 판단해 재가져오기가 실패하던 문제를 수정했습니다.

## 모듈 자산 안정화

- 자산이 많은 모듈을 가져오거나 자산 목록을 열 때 브라우저가 멈추는 문제를 완화했습니다.
- 자산 디코딩 배치를 작게 나누고, 미리보기는 현재 보이는 항목부터 지연해서 불러옵니다.
- 긴 자산 목록은 `더 불러오기`로 나누어 표시합니다.
