# RisuBard v0.9.53

동적 분석 토큰의 모델 출력 한도 초과와 과거 턴 재분석 후 사건 순서가 뒤섞이는 문제를 수정했습니다. 중복되는 인물 연대기 탭을 제거하고 위키 기본 지시문의 현재 상태 갱신을 보완했습니다.

## [안정성] 동적 분석 토큰과 모델 출력 상한

- **출력 상한 적용:** 장기기억 동적 한도가 늘어나도 모델 프리셋에 등록된 출력 상한 이내로 요청합니다. 상한 정보가 없는 이전 프리셋은 실제 모델과 일치하는 기본 제공 정보로 보완해 Vertex Gemini의 과도한 출력 토큰 요청 오류를 방지하며, 저장된 기본값은 유지합니다.
- **기본값과 동적값 구분:** 숫자 입력칸은 편집 전후 모두 기본값을 표시하고 동적 계산값은 아래에 따로 표시합니다. 분석값에는 모델 출력 상한에 따라 줄어들 수 있음을 안내해, 값을 낮췄는데 다시 커지거나 고정된 것처럼 보이던 혼란을 줄였습니다.

## [안정성] 재분석한 사건의 대화 순서 유지

- **원본 턴 기준 정렬:** 누락된 과거 사건을 나중에 생성하거나 재분석해도 이야기 목록과 사건 폴더는 원본 대화 순서를 따릅니다. 원본 위치는 메시지 ID로 확인하며, 위치를 확인할 수 없는 사건은 뒤에 표시합니다.
- **분석 순서 일치:** 다음 사건의 직전 사건 선택과 새 아크플롯 묶음에도 같은 순서를 적용합니다. 위키를 계승한 새 챗에서는 이전 아크플롯의 체크포인트를 이어갑니다. 이미 작성된 아크플롯 본문을 소급해서 다시 쓰지는 않습니다.
- **기존 사건 정보 유지:** 같은 출처의 사건을 재분석할 때 원래 생성 시각을 유지하고 수정 시각만 갱신합니다.

## [UI] 인물 연대기 탭 제거

- **인물 연대기 제거:** 기존 사건을 인물별로 모아 보여주던 탭을 제거했습니다. 인물 문서, 사건 문서, 작중 행적과 원본 채팅은 그대로 유지됩니다.

## [편의성] 위키 기본 지시문의 현재 상태 갱신

- **종료된 지시 정리:** 완료나 만료가 확인된 과제와 임시 지시를 인물 문서에서 정리하도록 기본 지시문을 수정했습니다. 아직 받지 못한 보상과 남은 의무는 유지합니다.
- **인물별 지식 유지:** 만남 여부와 습득한 지식, 비밀의 공유 범위는 유지하고 같은 대상에 대한 반복 기록을 통합하도록 했습니다. 다른 인물의 지식이나 문서 링크를 해당 인물의 지식으로 간주하지 않습니다.
- **이전 지시문 백업:** 수정 전 기본 지시문은 `공식기본-260930`으로 선택할 수 있습니다. 기존 공식기본의 선택과 장비 및 압축 옵션은 유지하며 개인 프리셋은 변경하지 않습니다.
