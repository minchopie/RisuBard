# RisuBard v0.9.54

리스렐름과 파일 가져오기에서 일부 CHARX 봇을 설치하지 못하던 문제를 수정했습니다. 설치 결과에 맞게 화면을 이동하고, 실패 원인을 오류창에서 확인할 수 있습니다.

## [안정성] 캐릭터 가져오기

- **CHARX 설치 호환성:** JPEG 이미지가 앞에 붙은 CHARX 파일을 정상적으로 가져올 수 있도록 수정했습니다.
- **설치 후 화면 이동:** 리스렐름 설치를 취소하거나 모듈로 설치했을 때 기존 목록의 마지막 캐릭터로 이동하던 문제를 수정했습니다.
- **가져오기 오류 안내:** 리스렐름 가져오기 실패 시 실제 오류 원인과 상세 정보를 오류창에 표시합니다.
