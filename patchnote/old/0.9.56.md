# RisuBard v0.9.56

설치 중 진행도 표시가 바뀌어도 진행 창 크기가 안정적으로 유지됩니다. 설치나 롤백이 막혔을 때 기존 데이터를 보존하면서 해당 설치를 초기화할 수 있습니다.

## [UI] 설치 진행 창 크기 유지

- **진행도 영역 유지:** 진행도 바가 없는 단계에서도 표시 공간을 확보해, 설치 중 창이 반복해서 커졌다 작아지거나 취소 버튼이 위아래로 움직이던 문제를 수정했습니다.

## [안정성] 실패한 설치 복구

- **설치 초기화:** 설치 중이나 롤백 중, 복구 실패 화면에서 `설치 초기화`를 선택할 수 있습니다. 확인 후 새로고침해 멈춘 작업을 중단하고 해당 설치가 추가한 캐릭터와 모듈을 제거하며, 기존 캐릭터와 대화, 설정은 보존합니다.
- **초기화 재시도:** 서버 연결 문제로 초기화를 마치지 못하면 요청을 보관해 다시 시도할 수 있습니다. 초기화는 에셋 파일을 보존하므로 설치 제한은 해제되지만 사용한 디스크 용량이 모두 반환되지는 않습니다.
- **롤백 반복 실패 수정:** 불러오지 않은 캐릭터나 채팅 때문에 `Unloaded character data prevents asset cleanup` 오류가 반복되던 문제를 수정했습니다. 이 경우 에셋을 보존한 채 롤백을 마쳐 다시 설치할 수 있습니다.
