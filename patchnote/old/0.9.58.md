# RisuBard v0.9.58

바드페인터에서 글로벌 공용 의상을 봇별로 선택해 사용할 수 있습니다. 위키 조회와 리부트, 전송 준비 중 발생하던 지연과 중단을 줄이고, Windows 소스 설치에서 일반 화면과 개발 화면을 각각 실행할 수 있도록 했습니다.

## [기능] 바드페인터 글로벌 공용 의상과 캐릭터 프리셋 화면 개선

- **글로벌 공용 의상:** 새 공용 의상은 글로벌 보관함에 저장하고, 봇마다 `글로벌에서 선택`으로 쓸 의상만 고릅니다. 선택한 의상만 각 인물의 `사용할 의상` 목록에 나타나며, 글로벌에서 수정하면 이 의상을 선택한 모든 봇에 반영됩니다.
- **선택 해제:** 봇에서 제외해도 인물 연결과 기본 의상은 남아, 다시 선택하면 그대로 복원됩니다.
- **봇 전용 의상:** 기존 봇 공용 의상과 카드에서 가져온 의상은 `봇 전용`으로 유지되며, `글로벌에 복사`로 글로벌 보관함에 옮길 수 있습니다.
- **카드 첨부:** 글로벌 의상도 봇별로 첨부를 선택하며, 카드를 내보낼 때 현재 내용이 카드에 복사됩니다.
- **화면 정리:** 설명문을 각 제목 옆 도움말 버튼으로 옮기고, 입력란과 의상 목록을 촘촘한 반응형 배치로 바꿨습니다.

## [안정성] 위키 조회와 리부트 중단 감소

- **항상 포함 위키 조회 중단 수정:** 위키가 갱신된 직후 응답을 생성하면 `항상 포함할 바드위키를 확인하지 못해 응답 생성을 중단했습니다`가 가끔 뜨던 문제를 수정했습니다. 조회 시간이 초과되면 리롤 없이 최대 1분까지 다시 기다립니다. 서버는 동시에 들어온 위키 문서 읽기를 한 번으로 합칩니다.
- **항상 포함 문서 한도 초과로 생성이 막히던 문제 수정:** 항상 포함으로 지정한 문서가 길어져 위키 조회 예산을 넘거나 12개를 넘으면 매 응답 생성과 위키 분석이 중단되던 문제를 수정했습니다. 응답 생성에는 지정한 문서를 그대로 포함하고 추가 위키 검색만 건너뜁니다. 위키 분석과 플러그인 조회는 예산에 맞는 문서만 사용합니다.
- **위키 검색 재정렬 실패 시 문맥 유지:** 바드쨩 재정렬 뒤의 두 번째 위키 조회가 실패하면 이미 찾은 위키 문맥까지 버리던 문제를 수정했습니다.
- **위키 리부트 자동 재시도와 막힘 방지:** 리부트 배치가 네트워크나 공급자 오류로 실패하면 5초와 10초 간격으로 두 번까지 자동으로 다시 시도합니다. 특정 문서의 갱신만 계속 실패하는 경우에는 리부트 전체를 멈추지 않고, 일반 분석처럼 그 문서를 보류 경고로 남긴 뒤 계속 진행합니다.
- **로어북 분석 출력 상한 자동 조정:** 그리모어 로어북 분석도 공급자가 출력 토큰 값을 거절하면 허용 상한으로 다시 요청합니다.

## [안정성] 전송 준비 지연 오류 감소

- **서버 인증 갱신 대기 제거:** 인증 토큰을 만료 2분 전에 미리 갱신합니다. 갱신이 늦어져도 아직 유효한 토큰을 그대로 사용하므로, 전송 중 `서버 인증 응답이 지연되어 중단했습니다`와 `파일 동기화 대기가 30초를 넘었습니다`가 뜨던 상황이 줄어듭니다.
- **비활성 탭의 연결 정리:** 다른 탭이 활성화되어 일시정지된 탭이 파일 변경 알림 연결을 닫습니다. 브라우저가 한 서버에 동시에 여는 연결 수 한도를 덜 차지해, 위키 분석 같은 긴 요청과 함께 쓸 때 다른 요청이 밀리지 않습니다.

## [편의성] 일반 실행과 개발 실행 분리

- **별도 실행 파일:** Windows 소스 설치에서 일반 실행은 기존 빌드 결과를 열고, 개발 실행은 소스 변경이 반영되는 화면을 엽니다. 실행 중인 서버를 재사용하여 같은 세이브로 두 화면을 이용할 수 있습니다.
