# RisuBard v0.9.59

위키 리부트가 스토리 아크 플롯 링크 검사 때문에 특정 구간에서 멈추던 문제를 고쳤습니다.

## [안정성] 스토리 아크 플롯 링크 검사로 리부트가 멈추던 문제 수정

- **링크 판정 완화:** 사건 제목에 `|`, `#`가 들어 있거나 별칭으로 연결한 링크도 현재 구간의 사건 링크로 인정합니다. 이전에는 이런 사건에 AI가 링크를 제대로 달아도 `Story arc plot must link at least one event from the current checkpoint`로 거부되어, 리부트가 같은 구간에서 더 진행되지 않았습니다.
- **누락된 링크 자동 보완:** AI가 사건 링크를 빠뜨리면 다시 요청하지 않고, 프로그램이 해당 구간의 최신 사건 링크를 `주요 전환점`에 직접 추가해 플롯을 저장합니다.
