# RisuBard v0.9.61

앱을 잠깐 벗어났다 돌아온 뒤 전송하면 "앞선 저장이 서버 응답을 기다리고 있어" 또는 "파일 동기화 대기가 30초를 넘었습니다" 오류로 응답이 나오지 않던 문제와, 큰 봇을 캐릭터로 설치하면 2분 뒤 설치가 취소되던 문제를 고쳤습니다.

## [수정] 대용량 봇 캐릭터 설치 실패

- **설치 확정 시간 제한 제거:** 봇을 캐릭터로 설치할 때 마지막 저장 확정 단계가 2분 안에 끝나지 않으면 "서버의 저장 완료 응답을 확인하지 못했습니다" 오류와 함께 설치가 되돌려지던 문제를 고쳤습니다. 수백 MB 봇이나 느린 디스크에서는 이 단계가 2분을 넘을 수 있습니다. 이제 서버가 저장을 마칠 때까지 기다립니다. v0.9.57부터 생긴 문제입니다.
- **기다리는 중 설치 취소:** 이 단계에서 `설치 취소 및 롤백`을 누르면 기다림을 바로 멈추고 설치를 되돌립니다. 이전에는 이 단계에서 눌러도 서버 응답이 올 때까지 반응이 없었습니다.

## [수정] 화면 전환 뒤 전송 실패

- **화면을 벗어날 때 서버 정지 제거:** 탭 전환, 창 최소화, 휴대폰 화면 끄기 때 보내는 저장이 데이터베이스 전체 호환 파일을 다시 만들지 않습니다. 이 작업은 데이터가 크면 수십 초 동안 서버 전체를 멈춰, 그동안의 저장과 전송 준비가 30초 제한을 넘었습니다. 대화 파일 저장은 이전처럼 즉시 끝나며, 호환 파일은 백업 등 실제로 필요할 때와 서버 종료 때 만듭니다.

## [추가] 빈 전송 대체 문자열

- **'say nothing' 대신 보낼 문자열:** 고급 설정의 응답 처리에서 `어떤 문자열도 입력되지 않을 시 'say nothing' 입력` 바로 아래에 입력칸을 추가했습니다. 이 옵션이 켜져 있고 빈 메시지를 보내면 `*says nothing*` 대신 입력한 문자열을 보냅니다. `{{user}}` 같은 매크로를 쓸 수 있고, 비워 두면 기존처럼 `*says nothing*`을 보냅니다. 입력칸은 오른쪽 아래 모서리를 끌어 높이를 조절할 수 있습니다.

## [추가] 위키 프롬프트 프리셋 목록에서 삭제

- **목록에서 바로 삭제:** 위키 프롬프트의 프리셋 선택 창에서 직접 만든 프리셋마다 휴지통 버튼이 생겼습니다. 누르면 확인을 거쳐 삭제하며, 사용 중인 프리셋을 지우면 남은 첫 프리셋으로 바뀝니다. 기본 제공 프리셋은 삭제할 수 없어 버튼이 나오지 않습니다.

## [개선] 바드페인터 캐릭터 프리셋 자동 불러오기

- **프리셋을 로어북처럼 읽기:** 프롬프트를 작성할 때 AI가 캐릭터 프리셋 목록을 읽고, 장면에 나온 인물을 로어 연결, 이름과 별칭, 식별 메모 순서로 알아봅니다. 알아본 인물에는 저장된 기본 외형과 의상 문구를 고쳐 쓰지 않고 그대로 넣으므로, 초안을 받은 뒤 외형과 의상을 일일이 붙여넣지 않아도 됩니다. 장면에 다른 옷이 묘사되면 의상은 장면을 따르고, 젖음이나 찢어짐 같은 일시적 상태는 저장된 문구 뒤에 덧붙습니다.
- **식별 메모:** 캐릭터 프리셋에 `식별 메모`를 추가했습니다. "세베루스 스네이프의 여동생"처럼 관계, 호칭, 구별되는 사실을 적어 두면 이름이 나오지 않는 장면에서도 AI가 그 인물을 알아봅니다. 단서가 두 사람 이상에게 맞으면 연결하지 않습니다.
- **불러온 프리셋 표시:** 인물 블록 위에 어떤 프리셋과 의상을 불러왔는지, 그리고 로어 연결, 이름 일치, 식별 메모로 판단 중 무엇으로 찾았는지 표시합니다. 식별 메모로 판단한 연결은 확인이 필요하도록 강조합니다.
- **입력칸 도움말:** 프리셋 편집기의 이름, 별칭, 식별 메모, 기본 외형, 의상 프롬프트, 의상 상태에 각각 도움말 버튼을 달았습니다.

## [개선] 공식기본 위키 프리셋 업데이트

- **주요 전환이 사건 일지로 늘어나지 않도록:** 캐릭터 문서의 `주요 전환`에는 행동이나 장면이 아니라 상태, 관계, 역할, 목표, 소속, 제약이 지속적으로 바뀐 결과만 남깁니다. 여러 턴에 걸친 하나의 장면은 하나의 전환으로 묶고, 새 사건이 직전 전환의 연장이면 새 줄을 덧붙이지 않고 기존 항목을 고칩니다.
- **분량 압축 기본 켜짐:** 분량 압축 블록이 기본으로 켜지며, 기존에 공식기본을 쓰던 경우에도 업데이트 후 켜집니다. 압축은 이미 사건마다 한 줄씩 쌓인 전환 항목도 합치고, 전환마다 대표 사건 링크를 한두 개만 남깁니다. 이미 길어진 문서는 해당 인물이 다음에 갱신될 때 정리됩니다. 장비와 소지품 켬/끔 설정과 직접 만든 프리셋은 그대로 유지됩니다.
- **위키 작성 언어별 정확한 절 제목:** 인물 핵심, 현재 상태, 관계와 신뢰, 지식과 비밀, 주요 전환, 장비와 소지품의 제목을 영어, 일본어, 중국어 위키에서도 정해진 이름으로 씁니다. 갱신할 때마다 번역이 달라져 같은 절이 중복되는 일을 막고, 일본어와 중국어 위키에서도 `주요 전환` 절을 평소 답변 문맥에서 빼 토큰을 아낍니다.
- **이전 프리셋 선택 가능:** 이전 공식 프리셋은 `공식기본-261003`으로 남겨 두었습니다. 프리셋 선택 창에서 고르면 이전 작성 방식을 그대로 쓸 수 있습니다.
