# RisuBard v0.9.62

**[핫픽스]** 서버 응답이 늦을 때 전송이 막히거나 봇 설치 중 "응답 지연" 오류가 뜨던 문제를 고쳤습니다. 저장과 동기화에 걸려 있던 시간 제한을 모두 없애, 서버가 바빠도 오류 없이 끝날 때까지 기다립니다.

## [수정] 서버 응답 시간 제한 제거

- **전송 대기 제거:** 저장이 오래 걸리는 환경에서 "앞선 저장이 서버 응답을 기다리고 있어 AI 요청을 보내지 않았습니다" 오류와 함께 전송이 반복해서 실패하던 문제를 고쳤습니다. 진행 중인 저장이 있으면 그 저장이 외부 파일 변경을 먼저 반영하므로, 전송은 저장을 기다리지 않고 바로 시작합니다.
- **시간 제한 제거:** 저장, 로그인 확인, 외부 파일 동기화 확인, 전송 준비에 걸려 있던 시간 제한(8초, 12초, 30초, 120초)을 모두 없앴습니다. 서버가 큰 봇 설치나 저장으로 바빠 응답이 늦어도 오류를 띄우지 않고 끝날 때까지 기다립니다. 서버도 요청을 받는 데 5분이 넘게 걸려도 끊지 않습니다. 기다리는 중에는 기존 취소 버튼으로 멈출 수 있습니다.

## [수정] 봇 리스트 3열 표시

- **최대 너비 확대:** 스크롤바가 항상 보이는 환경(Windows의 "스크롤 막대 항상 표시" 등)에서 봇 리스트를 끝까지 늘려도 2열까지만 표시되던 문제를 고쳤습니다. 스크롤바가 차지하는 폭 때문에 3열에 필요한 너비가 부족했습니다. 최대 너비를 240px에서 260px로 늘려 이제 이런 환경에서도 3열로 볼 수 있습니다.

## [개선] 바드페인터 프롬프트 작성 안정성

- **성인 장면 거부 감소:** 신체 접촉, 노출, 성행위, 체액, 구속 같은 요소를 AI가 직접 문장으로 쓰지 않고 정해진 항목 중에서 고르게 바꿨습니다. 실제 이미지 태그는 바드페인터가 넣으며, 인물별로 행동하는 쪽과 받는 쪽이 구분된 동작 태그로 들어갑니다. 성인 항목을 고르면 장면 태그 앞에 `nsfw`가 자동으로 붙습니다. AI가 노골적인 묘사를 직접 쓸 필요가 없어져 작성을 거부하는 경우가 줄어듭니다.
- **1인칭 장면 보완:** 1인칭 시점에서 화자와의 접촉 동작이 상대 인물의 태그에 그대로 남아, 화자를 그리지 않아도 장면이 제대로 표현됩니다.
- **응답 실패 자동 복구:** AI 응답이 중간에 잘리거나, JSON 형식이 깨지거나, 작성을 거절하면 한 번 더 고쳐 쓰도록 자동으로 요청합니다. 응답 길이 상한도 두 배로 늘려 긴 장면에서 응답이 잘리는 일을 줄였습니다.

## [추가] 바드페인터 이미지 크기 AI 결정

- **AI 결정 옵션:** 생성 설정의 이미지 크기에 "AI 결정"이 추가되었고 기본값이 되었습니다. 프롬프트를 작성할 때 AI가 장면의 배치, 동작, 시선, 배경, 구도를 보고 크기를 고르며, 고른 크기는 생성 버튼 옆에 "AI: 가로"처럼 표시됩니다. AI가 크기를 고르지 못하면 세로 832 × 1216으로 생성합니다.
- **선택 가능한 크기 확대:** 고정 크기를 세로 832 × 1216, 가로 1216 × 832, 세로 896 × 1152, 가로 1152 × 896, 정사각 1024 × 1024의 다섯 가지로 늘렸습니다. 모두 약 100만 화소라 생성 비용은 같습니다. 고정 크기를 고르면 AI도 그 크기에 맞춰 구도를 잡습니다.
- **기존 설정 유지:** 이전에 세로 832 × 1216 외의 크기를 고른 경우 그 크기가 그대로 유지됩니다. 기존 기본값인 세로 832 × 1216을 쓰던 경우에는 AI 결정으로 바뀝니다.
