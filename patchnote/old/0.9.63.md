# RisuBard v0.9.63

전송이 끊긴 채팅을 다시 열 때마다 같은 전송이 자동으로 반복되어 리스바드가 다시 멈추던 문제, 봇 이름의 대소문자만 바꾸면 앱이 열리지 않던 문제, update.bat이 업데이트를 반복하던 문제를 고쳤습니다.

## [수정] 중단된 전송 자동 재전송 제거

- **채팅을 열어도 다시 보내지 않음:** 서버 측 요청 모드에서 전송이 중간에 끊기면, 해당 채팅을 다시 열 때 같은 전송을 자동으로 다시 실행하던 기능을 없앴습니다. 전송 중 리스바드가 멈춘 채팅은 재시작 후 들어갈 때마다 같은 전송이 반복되어 다시 멈출 수 있었고, 이를 끌 수 있는 설정도 없었습니다. 이제 끊긴 전송은 마지막 사용자 메시지만 남긴 채 그대로 두며, 다시 보낼지는 직접 결정할 수 있습니다. 이미 서버에서 응답을 받고 있던 요청을 화면에 이어 붙이는 복구 기능은 그대로 유지됩니다.

## [수정] 봇 이름의 대소문자만 바꾸면 앱이 열리지 않던 문제

- **Windows와 macOS에서 대소문자 이름 변경 지원:** `Fate/Stay Night`을 `Fate/stay night`처럼 대소문자만 바꾸면 저장 폴더를 옮기지 못해 저장이 실패하고, 이후 실행할 때마다 "getItem Error"로 앱이 열리지 않던 문제를 고쳤습니다. 이제 봇과 채팅 폴더 이름의 대소문자도 그대로 바뀝니다. 이 문제로 열리지 않던 데이터도 이 버전으로 실행하면 정상적으로 열립니다.

## [수정] update.bat 업데이트 반복

- **이전 버전 되돌림 방지:** update.bat으로 업데이트를 마친 뒤 임시 폴더 `.update-tmp` 정리가 조용히 실패하면, 다음 실행 때 남은 백업을 "중단된 설치"로 판단해 이전 버전으로 되돌린 뒤 같은 버전을 다시 내려받던 문제를 고쳤습니다. 이제 설치가 이미 끝난 상태로 확인되면 남은 백업을 복원하지 않고 정리합니다. 이 문제를 겪던 설치본도 이 버전으로 한 번 업데이트하면 다음 실행부터 반복되지 않습니다.

## [수정] 봇 자체 BGM이 겹치거나 멈추지 않던 문제

- **Firefox에서 첫 메시지 음악 중첩 해결:** 첫 메시지에 자동 재생 음악을 넣은 봇에서, 화면이 다시 그려질 때마다 보이지 않는 사본이 함께 재생되던 문제를 고쳤습니다. 모듈을 껐다 켤 때 음악이 처음부터 겹쳐 재생되거나, 다른 봇으로 바꿔도 이전 봇 음악이 멈추지 않던 증상이 사라집니다.

## [개선] 그리모어 대량 목록 준비

- **대량 목록은 AI 분석에서 기본 제외:** NPC, 세력, 아이템처럼 많은 항목이 담긴 목록은 예상 출력량을 보고 새 분석의 기본 선택에서 제외합니다. 제외 이유와 예상량을 표시하며, 개별 체크로 다시 포함할 수 있습니다. 대화에서의 로어 활성화 설정은 바꾸지 않습니다.
- **AI 없는 로컬 분할:** 이름별 목록이나 제목으로 구분된 원문을 개별 검색 항목으로 나눌 수 있습니다. 미리보기에서 확인하고 적용하면 관련 인물이나 물건의 설명을 따로 검색하며, 원래 로어북은 보존합니다. 공통 제목은 보조 문맥으로 함께 보존하고, 경계가 애매하거나 공통 설명이 남으면 적용 전에 알립니다.
- **불필요한 출력량 추정 개선:** NPC의 머리카락이나 성격 같은 속성 줄을 별도 인물로 세지 않도록 보강하고, 영어 `npc list` 같은 목록 제목도 인식합니다.

## [개선] 위키 프롬프트 프리셋 화면

- **채팅 프롬프트 프리셋과 같은 탭 구성:** 상단 메뉴를 `기본 정보`, `프롬프트`, `프롬프트 V2` 순서로 바꿨습니다. `프롬프트` 탭에서는 블록을 카드 목록으로 한눈에 보며 이름, 사용 여부, 적용 단계, 내용을 바로 고치고 순서를 옮기거나 삭제할 수 있습니다. `프롬프트 V2` 탭은 기존 3분할 에디터이며, 두 탭은 같은 프리셋을 편집합니다.
- **프리셋 목록에서 바로 관리:** 활성 위키 프롬프트 프리셋 목록의 각 줄에 복제, 내보내기, 삭제 버튼을 두었고, 위쪽에 새 프리셋, 가져오기, 이름 편집 버튼을 추가했습니다. 공식 프리셋은 잠금 표시와 함께 삭제와 이름 변경이 막혀 있으며 복제해서 수정할 수 있습니다.

## [개선] 백그라운드 설치 속도

- **다른 창을 보고 있어도 설치 유지:** 모듈이나 봇을 설치하는 동안 리스바드 탭이나 창을 벗어나면 브라우저가 작업을 늦춰 수천 개 에셋 설치가 수십 분까지 늘어나던 문제를 고쳤습니다. 이제 화면을 보고 있지 않아도 에셋 가져오기와 압축 파일 처리가 같은 속도로 진행됩니다.

## [개선] 일반 서버를 창으로 실행

- **보이는 서버 창:** `risubard-normal.bat`으로 시작한 서버가 백그라운드에 숨지 않고 '리스바드 일반서버'라는 제목의 창으로 열립니다. 창에서 서버 기록을 볼 수 있고, 창을 닫거나 Ctrl+C를 누르면 저장 중인 데이터를 마무리한 뒤 종료됩니다. 서버가 오류로 멈추면 창이 열린 채로 남아 오류 내용을 확인할 수 있습니다. `risubard-stop.bat`도 그대로 쓸 수 있습니다.

## [개선] 플러그인 API `parseRisuChat` 지원

- **모듈 상태를 바로 반영하는 BGM 플러그인:** 현재 캐릭터와 채팅 기준으로 CBS를 해석하는 `parseRisuChat`을 플러그인 API v3에 추가했습니다. 이 API를 쓰는 BGM 플러그인(예: Fate/stay night BGM 플레이어)은 모듈을 켜고 끌 때 플레이어 표시와 재생이 즉시 따라갑니다. 이전에는 새로고침 전까지 모듈이 꺼진 것으로 판단해 BGM과 플레이어가 나오지 않거나, 반대로 꺼도 계속 재생되는 경우가 있었습니다.
