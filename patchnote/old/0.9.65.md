# RisuBard v0.9.65

## [수정] 도커 재시작 후 서버가 켜지지 않는 문제

- **남은 잠금 자동 정리:** 도커에서 업데이트하거나 컨테이너가 비정상 종료된 뒤 다시 켜면 `DATA_ROOT_IN_USE` 오류로 서버가 시작되지 않는 문제를 고쳤습니다. 컨테이너 안의 서버는 매번 같은 프로세스 번호로 실행되어서 이전 실행이 남긴 잠금을 지금 실행 중인 다른 서버로 잘못 판단했습니다. 이제 이런 잠금은 자동으로 정리하므로 저장 폴더의 `.risubard-server.lock` 폴더를 직접 지우지 않아도 됩니다.

## [수정] 0.9.64 업데이트 직후 첫 로딩이 매우 느린 문제

- **의미 검색 벡터 이동 가속:** 0.9.64는 서버를 켜면 바드위키 의미 검색 벡터를 공용 저장소(KV)에서 `bardwiki-vectors` 폴더로 자동으로 옮깁니다. 이때 벡터 256개마다 저장소 목록 전체를 다시 써서, 벡터가 많거나 휴대폰처럼 저장 속도가 느린 환경에서는 이동이 끝날 때까지 "로컬 저장 파일을 불러오는 중..."에서 오래 멈춰 있었습니다. 이제 목록은 벡터 4,096개마다 한 번만 다시 씁니다. 중간에 서버를 껐다 켜도 이미 옮긴 벡터는 다시 옮기지 않습니다.

## [추가] 바드위키 의미 검색 캐시 삭제

- **저장소 대시보드에서 삭제:** 설정 > 시스템 > 대시보드에 `바드위키 의미 검색 캐시` 항목을 추가했습니다. 저장된 벡터 수와 용량을 보여 주고, `캐시 모두 삭제`로 한 번에 지울 수 있습니다. 의미 검색 벡터는 캐릭터나 위키 문서를 지워도 자동으로 정리되지 않아 계속 쌓이기 때문입니다.
- **지워도 되는 캐시:** 삭제해도 위키 문서와 채팅은 그대로 남습니다. 벡터는 다음에 필요할 때 다시 계산하며, 사용하는 임베딩 모델에 따라 이때 API 비용이 들 수 있습니다. `고아 데이터 모두 정리`는 이 캐시를 지우지 않습니다.
