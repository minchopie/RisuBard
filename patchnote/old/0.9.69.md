# RisuBard v0.9.69

## [기능] 외부 파일 변경 확인

앱이 열려 있는 동안 다른 프로그램(편집기, 봇 제작 도구 등)이 데이터 폴더의 파일을 고치면, 바뀐 내용을 보여 주고 어느 쪽을 남길지 고르게 합니다. 고를 때까지 저장을 멈춰서 어느 쪽 내용도 조용히 사라지지 않습니다.

- **확인하는 파일:** 캐릭터, 전역 로어북, 설정, 프리셋, 모듈, 페르소나, 채팅 등 데이터 폴더의 모든 파일입니다. 파일을 고치면서 체크섬까지 함께 고치는 도구로 바꾼 경우도 찾아냅니다.
- **바뀐 내용 보기:** 캐릭터마다 바뀐 필드와 추가, 삭제, 수정된 로어 항목을 보여 줍니다. 설정, 프리셋, 모듈, 페르소나는 바뀐 필드를, 채팅과 그 밖의 파일은 바뀐 파일을 보여 줍니다. API 키 같은 인증 정보는 값을 숨기고 바뀐 항목 이름만 보여 줍니다. 항목을 펼치면 앱 내용과 외부 파일을 줄 단위로 비교합니다. 형식이 깨진 파일은 몇 번째 줄, 몇 번째 칸이 잘못됐는지 알려 줍니다.
- **외부 변경 받아들이기:** 캐릭터와 로어북만 바뀌었으면 그 항목만 외부 내용으로 바꿉니다. 이 창에서 아직 저장하지 않은 다른 편집은 그대로 남고, 같은 항목을 고친 내용은 브라우저 복구 기록에 보관합니다. 다른 파일도 바뀌었으면 모든 파일을 외부 내용으로 다시 불러온 뒤 페이지를 새로고침합니다. 이때 이 창에서 저장하지 않은 편집은 사라집니다.
- **앱 내용 유지:** 바뀐 외부 파일을 모두 데이터 폴더의 `trash/external-changes-*`에 백업한 뒤 앱 내용으로 덮어씁니다.
- **옵션:** `설정 > 공통 설정 > 저장 및 불러오기 > 외부 파일 변경 확인`. 기본값은 꺼짐입니다. 켜면 앱이 화면에 보이는 동안 몇 초마다 확인합니다. 데이터 폴더 전체를 감시하지 않고 파일 정보만 확인하므로 0.9.66에서 없앤 자동 감지처럼 서버를 붙잡지 않습니다.

## [안정성] 열린 앱이 외부 수정을 덮어쓰던 문제

- **증상:** 0.9.66부터 앱이 열려 있는 동안 캐릭터 파일을 외부에서 고치면, 앱이 다음에 저장할 때 외부에서 고친 내용을 조용히 덮어썼습니다.
- **원인:** 저장 직전에 서버는 외부 파일을 반영했지만, 앱 화면은 그 내용을 받아 오지 못한 채 자기가 가진 이전 캐릭터 내용으로 다시 저장했습니다.
- **변경:** 외부 파일 변경 확인 옵션을 꺼 두어도, 저장할 때 외부 변경을 발견하면 덮어쓰지 않고 저장을 멈춘 뒤 위의 확인 창을 띄웁니다. 앱을 닫은 상태에서 고친 파일은 이전처럼 다시 열 때 그대로 반영합니다.

## [안정성] 자동 업데이트가 임시 폴더에 파일을 남기던 문제

- **증상:** 윈도우에서 앱 안의 자동 업데이트를 쓸 때마다 `%TEMP%\risu-update-*` 폴더에 압축을 푼 파일 약 3만 개가 남았습니다. 업데이트를 여러 번 하면 수십만 개가 쌓여 윈도우 로그인이 1분 넘게 멈출 수 있었습니다. 업데이트 도우미가 쓰는 `%TEMP%\risubard-updater-*` 폴더도 지워지지 않았습니다.
- **원인:** 서버가 임시 폴더 삭제를 시작한 직후 바로 종료되어 삭제가 중간에 끊겼습니다.
- **변경:** 업데이트 도우미가 서버 종료 후 설치를 마치고 나서 다운로드 폴더를 지웁니다. 또 서버를 켜고 1분 뒤 별도 프로세스가 이전 업데이트에서 남은 이 두 종류의 폴더를 정리합니다. 다른 설치본이 업데이트 중일 수 있으므로 하루 이상 변경이 없는 폴더만 지우고, 실행 중인 업데이트 도우미의 폴더는 건드리지 않습니다. 이미 쌓인 폴더도 이 업데이트 후 서버를 켜면 정리됩니다.

## [성능] 채팅 변수를 많이 쓰는 카드의 채팅 파일이 계속 커지던 문제

- **증상:** 인물 호감도, 관계, 일정 등을 채팅 변수에 많이 저장하는 카드에서 채팅 하나가 수십 MB까지 커지고, 이런 채팅을 열면 브라우저 탭이 메모리 부족으로 꺼질 수 있었습니다.
- **원인:** 0.9.37부터 리롤할 때 채팅 변수를 응답 전 상태로 되돌리려고, AI 응답마다 채팅 변수 전체를 응답 전과 응답 후로 두 번 복사해 저장했습니다. 리롤한 응답에는 스와이프마다 복사본이 더 붙었고, 지난 메시지의 기록도 지우지 않아 계속 쌓였습니다.
- **변경:** 리롤할 수 있는 마지막 AI 응답에만 이 기록을 남기고, 새 응답이 오면 이전 메시지의 기록은 모두 지웁니다. 이미 커진 채팅도 다음 응답을 받을 때 줄어듭니다. 대화 내용, 이미지, 위키와 현재 채팅 변수는 그대로입니다. 단, 메시지를 지워 이전 응답이 다시 마지막이 된 경우에는 그 응답을 리롤해도 채팅 변수가 되돌아가지 않습니다. 이렇게 되돌리는 방식은 위키와 어긋날 수 있어 원래 권장하지 않습니다.
