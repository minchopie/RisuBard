# RisuBard v0.9.7

이번 버전은 **BardWiki 정본 갱신 비용과 원본 웹 Risu 백업 가져오기 안정성**을 개선합니다.

## BardWiki 정본 절 단위 갱신

- 캐릭터·장소·설정 정본을 자동 갱신할 때 문서 전체를 모델이 다시 쓰지 않고, 변경이 필요한 절만 생성하고 적용하도록 변경했습니다.
- 기존 정본의 제목, 수정 대상이 아닌 절, 서식과 원문은 그대로 보존합니다.
- 정본 갱신 모델 입출력에서 매번 전체 문서를 왕복시키지 않아 긴 캐릭터 문서일수록 토큰 사용량을 줄입니다.
- 변경할 내용이 없는 정본은 저장 작업을 건너뛰며, 절 추가·수정·삭제만 명시적으로 처리합니다.
- 중복 절 제목, 잘못된 제목 계층, 코드 블록 안의 제목 등 비정상적인 패치를 검증해 정본 손상을 방지합니다.

## 원본 웹 Risu 백업 가져오기

- 원본 웹 Risu의 계정 환경에서 내보낸 암호화 `.bin` 백업을 RisuBard로 가져올 수 있도록 수정했습니다.
- 암호화된 데이터베이스를 일반 백업으로 해석하면서 `invalid block type` 오류가 발생하던 문제를 해결했습니다.
- 백업에 포함된 암호화 정보를 인식하고 원본 Risu의 계정 백업 방식에 맞춰 데이터베이스를 복호화합니다.
- 계정 백업을 복호화하려면 가져오기 시 원본 Risu 키 서버에 연결할 수 있어야 합니다.

## 백업 실패 시 기존 데이터 보호

- 가져온 데이터베이스를 활성 데이터에 반영하기 전에 복호화와 형식 검증을 완료하도록 변경했습니다.
- 손상된 백업, 잘못된 암호화 정보 또는 복호화할 수 없는 백업은 기존 데이터를 교체하지 않고 안전하게 중단합니다.
- 가져오기 오류 이후 `getItem Error`가 이어지며 RisuBard를 사용할 수 없게 되던 문제를 방지했습니다.
