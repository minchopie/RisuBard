# RisuBard v0.9.8

이번 버전은 **일반 백업 다운로드가 100%에서 실패하던 문제를 수정하는 핫픽스**입니다.

## 일반 백업 다운로드 핫픽스

- 전체 백업 데이터를 모두 받은 뒤 파일 저장을 마무리하는 단계에서 `Failed`가 표시되던 문제를 수정했습니다.
- Chrome·Edge 계열 브라우저에서는 백업 생성을 시작하기 전에 저장 위치를 선택하고, 생성된 데이터를 해당 파일에 직접 스트리밍합니다.
- 대용량 백업을 브라우저 메모리에 통째로 올리지 않고 저장하며, 기존 StreamSaver 종료 오류를 우회합니다.
- 파일 저장을 취소했을 때 실패 오류를 표시하지 않으며, 실제 저장 오류가 발생하면 원인을 확인할 수 있는 메시지를 표시합니다.
