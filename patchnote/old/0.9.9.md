# RisuBard v0.9.9

이번 버전은 **BardWiki 분석 안정성과 플러그인 provider의 비스트리밍 호환성을 개선하는 핫픽스**입니다.

## 위키 리부트 응답 형식 핫픽스

- AI에 안내하던 `canonicalUpdateCandidates` 필드 계약이 실제 검증 스키마보다 세 필드 부족해, 정상적인 모델도 검증에 반복 실패할 수 있던 충돌을 수정했습니다.
- 프롬프트 계약을 실제 필수 필드인 `type`, `title`, `reason`, `action`, `targetDocumentId`, `confidence`와 일치시켜 브라우저나 모델·프로바이더를 바꿔도 같은 오류가 이어지던 원인을 제거했습니다.
- 필드 계약과 최소 분석 token 예산을 함께 검증하는 회귀 테스트를 추가해 같은 문제가 다시 생기지 않도록 했습니다.

## 플러그인 provider 비스트리밍 호환성

- BardWiki처럼 비스트리밍 응답을 요청한 내부 작업에서 플러그인 provider가 스트림을 반환하면 빈 오류로 실패하던 문제를 수정했습니다.
- 플러그인 스트림을 끝까지 안전하게 수집해 일반 문자열 응답으로 변환하므로 Yumi Provider Manager 등 스트리밍을 사용하는 플러그인 모델을 내부 작업에도 사용할 수 있습니다.
- 스트리밍 표시가 필요한 일반 채팅의 기존 동작은 유지하며, 비스트리밍 요청에서만 응답을 한 번에 반환합니다.
